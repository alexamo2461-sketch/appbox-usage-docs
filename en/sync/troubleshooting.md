# Sync Unavailable?

The data synchronization feature requires the user to be signed in to iCloud on their current device with iCloud sync enabled. First, check the **iCloud Status** on the AppBox **Data Sync** page to see if it is marked as **Available**.

![iCloud Status Check](/sync-icloud-status-en.png)

If it shows as **Unavailable** or sync fails to function, please ensure both of the following settings are turned **ON**:

### 1. System Settings → [Your Name] → iCloud → Show All → Apps Using iCloud → AppBox

![AppBox iCloud Setting](/sync-appbox-en.png)

### 2. System Settings → [Your Name] → iCloud → iCloud Drive → Turn on "iCloud Drive"

![iCloud Drive Setting](/sync-icloud-drive.png)
