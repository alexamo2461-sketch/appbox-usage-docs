# Tags

AppBox supports adding custom tags to apps for flexible categorization and quick searching.

## Overview

Tags provide a flexible way to categorize your apps. Unlike collections, a single app can have multiple tags, and the same tag can be applied to multiple apps. Tags let you quickly filter and find apps across different collections.

## Adding Tags

In the app description editing page, you can add one or more tags to an app.

**Steps**: Open app details → Tap edit description → Enter or select tags in the tag area

## Managing Tags

You can manage all tags in Settings:

**Steps**: Settings → Apps → Tag Management

In the tag management page, you can:

- View all tags in use
- Search tags
- Rename tags
- Delete unwanted tags

## Filtering Apps by Tags

### Home Page Tag Area

The home page shows all tags at the bottom. Tap a tag to view all apps with that tag.

### Filtering Within a Collection

In the collection details page filter panel, you can filter apps by tags. See [Filtering Within a Collection](/app-management/filtering) for details.

## Tag Display Settings

**Steps**: Settings → General → Display Configuration → App Details Page

You can configure how tags are displayed on the app details page:

- **Show Tags**: Toggle tag display on the app details page
- **Show Icon**: Toggle whether a tag icon appears before each tag
- **Single Line**: Toggle whether tags are displayed in a single line

::: info
Tag data supports sync and import/export — your tags won't be lost when switching devices.
:::
