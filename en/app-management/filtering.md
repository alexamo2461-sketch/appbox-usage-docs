# In-Collection Filtering

The collection details page in AppBox offers powerful filtering capabilities to help you quickly locate the apps you need.

## Overview

On the collection details page, tap the **Filter** icon in the top-right corner to open the filter panel, where you can filter apps in the current collection by various criteria.

## Filter Criteria

| Criteria | Description |
| --- | --- |
| **Keyword** | Search keywords in app name, description, and subscription notes (up to 50 characters) |
| **Rating** | Filter by your rating, including "No Rating" and 1–5 stars |
| **Tags** | Filter by app tags, supporting multiple selection |
| **Category** | Filter by App Store primary category |
| **Source** | Filter by app source: App Store apps or custom apps |
| **Platform** | Filter by supported platform: iPhone, iPad, Mac |
| **Region** | Filter by App Store region (only shows regions that actually appear in the current collection) |

## Steps

1. Open a collection
2. Tap the **Filter** icon in the top-right corner
3. Set the criteria you need in the filter panel
4. Multiple criteria are combined with "AND" (all must be met simultaneously)
5. Once set, the app list updates automatically

## Clear Filters

Tap the **Clear** button in the filter panel to reset all filter criteria and display all apps.

## Tips

- The region filter only shows regions that actually exist in the current collection — no empty options
- Combine multiple criteria for precise filtering, e.g. "Tag: Productivity + Platform: iPhone"
- Keyword search matches both app names and description content
