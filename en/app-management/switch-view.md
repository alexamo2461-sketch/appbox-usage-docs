# Switching App Views

The collection details page provides 2 views for displaying apps: "Icon View" and "List View".

The view switch button in the top-right action menu is a "temporary" button — you can toggle between the two views freely. To set a fixed default view, go to Settings → General → App View. This way, the app layout will always use your preferred view when entering the collection details page.
