# Switching App Views

The collection details page provides 3 views for displaying apps, catering to different usage scenarios.

## Three Views

| View | Description |
| --- | --- |
| **List View** | Displays apps in a compact list format, showing icon, name, and description per row — ideal for quick browsing with many apps |
| **Icon View** | Displays app icons in a grid layout — visually appealing and ideal for fewer apps or icon-based recognition |
| **Card View** | Displays apps as cards showing ratings, descriptions, tags, and more — ideal for detailed app management |

## Quick Switch

On the collection details page, tap the **Switch View** button in the top-right action menu to quickly toggle between the three views.

## Set Default View

If you want to use the same view every time you enter a collection, you can set it in the settings:

**Settings → General → Display Configuration → Collection Page**, choose your preferred default view.

> **Tip**: The switch button in the top-right corner is for "temporary" switching; the setting in the configuration is for "permanent" view.

::: info
Card View is a Pro feature and requires an AppBox Pro subscription. Custom sorting supports drag-and-drop only in List View and Icon View; Card View and grid layouts display items in custom sort order but do not support drag-and-drop.
:::
