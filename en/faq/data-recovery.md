# Data Recovery: Restoring Lost Data

:::: info
**Important Prerequisites for Data Recovery:**

+ The app must **not** have been uninstalled and reinstalled.
+ Data must still be present under **Settings > General > iPhone Storage > AppBox > Documents & Data**.

If you encounter any issues, please go to **Settings > Feedback** to contact me at any time.
::::

Tap **Settings** → **FAQ** → **Data Loss** → **Tap to Repair** → open the **Scan Results** page → check how many databases are currently detected. If two databases are shown, it means the old database still exists. Tap the **Merge all available data into the primary database** button at the bottom to restore the data.
