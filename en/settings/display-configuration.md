# Display Configuration

The Display Configuration page lets you customize display options for collection pages and app detail pages.

**How to access**: Settings → General → Display Configuration

## Collection Page Configuration

### App Viewing Mode

Set the default behavior when tapping an app:

| Mode | Description |
| --- | --- |
| **Open App Store** | Tapping an app icon opens the App Store app page directly |
| **Preview in AppBox** | Tapping an app icon shows an app detail preview within AppBox |

### App View

Set the default view for collection detail pages (List, Icon, or Card).

## App Detail Page Configuration

### Detail Order

Customize the display order of sections on the app detail page, including:

- App Screenshots
- App Info
- More Info
- App Description
- Release Notes

Simply drag to reorder.

### App Description

- **Hide when empty**: When an app has no description, hide the description section (Pro feature)

### App Tags

- **Show tags**: Control whether tags are displayed on the app detail page
- **Show icons**: Control whether tag icons are displayed before tag names
- **Single line**: Control whether tags are arranged in a single line
