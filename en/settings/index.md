# ⚙️ Settings

AppBox's settings page offers a wide range of configuration options to personalize your experience and manage your data.

## General

- [Theme Settings (Color and Appearance)](/en/settings/theme): Set theme mode and theme color
- **Language**: Jump to system settings to change the app language
- [Display Configuration](/en/settings/display-configuration): Configure display options for collection pages and app detail pages

## Collections

- [Collection Management](/en/collection-management/): View and manage all collections with multi-select delete
- [Empty Collection Detection](/en/collection-management/empty-detect): Automatically detect and prompt to delete empty collections
- [Share Management](/en/settings/share-management): Manage shared collection links

## Apps

- **All Apps**: View all collected apps (deduplicated), with App Store jump support
- [App Regions](/en/region/): Manage App Store query region list
- [Tag Management](/en/tags/): Manage all app tags
- [App Properties](/en/settings/app-properties): Configure subscription and price property display

## Data

- [Data Sync](/en/sync/): iCloud data synchronization
- [Data Import](/en/backup-restore/data-import): Import AppBox data or Apple data
- [Data Export](/en/backup-restore/export): Export data as JSON or ZIP files
- [Data Management](/en/settings/data-management): Refresh app info, download icons, clear cache, reset data

## Others

- **User Guide**: Open online help documentation
- **FAQ**: In-app FAQ page
- **Feedback**: Send feedback via email
- **Rate AppBox**: Rate on the App Store
- **About AppBox**: View app version and developer info
