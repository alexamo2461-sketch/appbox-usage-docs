# App Properties

The App Properties settings control which attribute fields are displayed when editing app descriptions.

**How to access**: Settings → Apps → App Properties

## Configurable Properties

### Subscription Properties

When enabled, subscription-related fields are displayed when editing app descriptions:

- Subscription description
- Subscription price
- Currency
- Subscription type (monthly, yearly, etc.)
- Subscription start/end date

### Price Properties

When enabled, price-related fields are displayed when editing app descriptions, with support for automatically fetching app pricing from the App Store.

::: info
App Properties configuration is a Pro feature and requires an AppBox Pro subscription to modify. Non-Pro users have these properties enabled by default.
:::
