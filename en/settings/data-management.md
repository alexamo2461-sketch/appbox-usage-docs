# Data Management

The Data Management page provides features for refreshing app information, downloading icons, clearing caches, and resetting data.

**How to access**: Settings → Data → Data Management

## Download Icons for Offline Use

Download all app icons to your local device so they display properly even without an internet connection.

It's recommended to perform this operation with a good network connection. The download process may take some time depending on the number of apps you have.

## Refresh App Information

Re-fetch the latest app information from the App Store, including name, icon, screenshots, description, price, and more.

You'll see a list of apps pending refresh, with support for batch refreshing. The refresh process runs in the background and doesn't affect normal use.

> **Tip**: Refreshing does not overwrite your own ratings, descriptions, or tags.

## Clear Cache

### Clear Invalid Icon Cache

Delete cached icon files that are no longer valid or in use, freeing up storage space. Useful when icons display incorrectly or cache takes up too much space.

### Clear Invalid App Data

Clean up orphaned app data records. Useful when data anomalies occur or you need to free up space.

## Data Reset

> **Warning**: The following operations are irreversible. Please proceed with caution.

**Delete Local Data**: Erase all AppBox data on the device, including collections, app information, ratings, descriptions, and more. Make sure your data is backed up or synced to iCloud before proceeding.
