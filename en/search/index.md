# Search

AppBox provides a global search feature to quickly find your saved apps and collections.

## Overview

Tap the **Search** tab in the bottom navigation bar to open the search page. You can search across all your saved apps and collections. Search supports matching by name, description, and other keywords.

## Steps

1. Tap the **Search** tab in the bottom navigation bar
2. Enter keywords in the search box
3. Results appear in real time, including matching apps and collections
4. Tap a result to open the app details or collection details page

## Search Scope

- **App Name**: Matches the app's name
- **App Description**: Matches custom descriptions you added to apps
- **Collection Name**: Matches collection names

## Actions on Search Results

In the search results, you can perform the following actions:

- **App**: Tap to open the app details page
- **Collection**: Tap to open the collection details page
- **Long-press an app**: Opens a context menu with options to edit description, copy/move, delete, etc.
- **Long-press a collection**: Opens a context menu with options to edit, delete, etc.

## Tips

- Search filters in real time — results appear as you type
- Use shorter keywords for broader matches
- If you can't find an app, try searching keywords in its description
