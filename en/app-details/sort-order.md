# Display Order Sorting

This feature allows you to adjust the display order of the following sections on the app details page:

- **Screenshots**: Shows app screenshots, supporting multiple platforms simultaneously.
- **App Info**: Latest app information fetched from the App Store, including App ID, developer, price, size, etc.
- **Description**: App description fetched from the App Store.
- **Update History**: The latest update notes fetched from the App Store.
- **More Info**: The app's App Store region, time added to the collection, and source link.

**How to use**: Settings → App Display Order → Drag the list to reorder.
