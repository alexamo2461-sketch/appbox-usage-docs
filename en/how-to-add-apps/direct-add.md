# Direct Addition within AppBox

You can open the "Add App" interface through the following entries:

+ On the **App Sets** home page: Use the **Add App** button in the bottom right corner; if it is not displayed, click **"Add App"** in the menu at the top right.
+ On a specific **App Set Details** page: Click **Add App** (if you are only organizing the current list, the target app set will automatically point to the current one).

![Add App Entry](/assets/how-to-add-apps/entry-screenshot.png)

After opening, you can switch the top tabs as needed: **App Name**, **App Link**, or **Custom**. In the app preview area, clicking "Edit Description" will pop up a description editing page to quickly record ratings, descriptions, and other attribute information.

![Add App Interface](/assets/how-to-add-apps/add-app-interface.png)

# Search and Add by Name (Search Store within App)

## Feature Introduction
Under the **App Name** method, enter keywords to search and select apps from the App Store to add to your collection.

![Search by Name](/assets/how-to-add-apps/search-by-name.png)

## Use Cases
+ You only have the app name, not the link.
+ You want to compare apps with the same name and verify the icon before adding.

## Operation Steps
1. Open **Add App** and select **App Name**.
2. Enter the name or keyword in the input box and click **Search App Store**.
3. In the **Search Results**, you can switch the **Region** and search again (if necessary).
4. Tap **Add** on a specific row to select it; multiple selections are allowed.
5. Once selected, click confirm in the top right corner to return to the previous page.
6. Select the **Target App Set**; you can edit descriptions or tags in the preview area.
7. Click **Add** or **Continue Adding** at the bottom.

## Feature Notes
+ Search results come from the App Store of the selected region; lists may vary by region.
+ The preview area will display selected apps; verify before saving.

::: info
Supports text recognition from screenshots or images. It fills potential **App Names** into the search box. After recognition is complete, you can confirm or modify the recognized text on the results page.
:::

## Precautions
> **Note**: If an app cannot be found, it is often related to the currently selected **App Store Region**. You can change the region on this page or in settings and search again.

# Add by Inputting and Recognizing App Store Links

## Feature Introduction
By pasting a link to an App Store app page, AppBox retrieves information such as the icon and name, and adds the app to the selected app set.

![Add by Link](/assets/how-to-add-apps/add-by-link.png)

## Use Cases
+ You see a series of App Store links in a community, webpage, or memo and want to save them immediately.
+ You have already copied the link and don't want to search for the name in the store again.

## Operation Steps
1. Open the **Add App** page.
2. Click **App Link** in the top segment.
3. Paste the link into the input box (it usually **starts recognizing automatically** after pasting), or click **Recognize from Clipboard** to use the full text from the clipboard.
4. If a storage location hasn't been chosen, select one or more sets in **Target App Set**.
5. To query a specific regional store, adjust the **Region** on this page (consistent with "Settings → App → App Store Region").
6. Confirm if the entry is correct in **App Preview**; you can edit descriptions or select tags here.
7. Click **Add** at the bottom to save and close; or click **Continue Adding** to stay on this page for further operations.

::: info
Supports **multiple links**: In the same input box, use **line breaks** or **English semicolons** `;` to separate multiple App Store links. It will automatically attempt recognition when content changes; you can also use **Recognize from Clipboard**.
:::

## Feature Notes
+ A preview list will appear after successful recognition; if it fails, the page will provide a short reason, allowing you to check if the link is complete.
+ If the link contains regional information, it is usually recognized according to that region; you can also manually switch regions and try again. Regarding link recognition rules: [App Regions & Link Recognition](/en/region/)

## Recommended Usage
+ Put items into a default app set first, then organize them into classified sets later to reduce repetitive operations.
+ When batch-collecting "App Lists" from articles, you can paste multiple links at once and then confirm the previews together.

# Custom Add App (Manual Information Entry)

## Feature Introduction
Manually fill in information such as app name, icon, and source link. This is used for entries that cannot currently be found in the store or items where you want complete control over the display.

![Custom Add](/assets/how-to-add-apps/custom-add.png)

## Use Cases
+ Apps that are not yet listed, have been removed, or are distributed only through specific channels, but you still want to keep a record in your list.
+ You need to keep a custom icon and notes for a non-App Store app/software.

## Operation Steps
1. Open **Add App** and select **Custom**.
2. Click the icon area and follow prompts to get an icon from **Photo Library**, **Files**, or via an **Image Link** (`http`/`https`, PNG/JPG recommended).
3. Fill in the **App Name** (required).
4. Fill in the **Source Link** as needed (webpage or instruction address).
5. Select the **Target App Set**.
6. Edit related information such as description, rating, subscription, and tags in the app preview area.
7. Click **Add** at the bottom to save.

## Feature Notes
+ It is recommended to fill the source link with the official website or a trusted page for easier future review.
+ The display of custom entries depends on the content you provide; it will not automatically sync with store detail pages like store apps do.
+ If the app shows membership restrictions for this feature, follow the prompts to the membership description page if not unlocked.

## Precautions
+ Custom entries differ from store-added entries in update methods; store apps can be refreshed on the details page, while custom entries must be modified manually.
+ Try to choose high-resolution square icons; avoid enlarging small screenshots.

# Recognize App Name via Screenshot

## Feature Introduction
Recognize text from screenshots or images, fill potential **App Names** into the search box, and then complete the addition by combining with [Search and Add by Name (Search Store within App)](#search-and-add-by-name-search-store-within-app).

![Screenshot Recognize 1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## Use Cases
+ You only have an app screenshot without a copyable link. You want to quickly extract the title from the image as a search keyword.

![Screenshot Recognize 2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## Operation Steps
1. Open **Add App** → **App Name**.
2. To the right of the name input box, click **Recognize App in Image** (viewfinder style icon).
3. Select **Choose from Photos** or **Choose from Files**.
4. After recognition is complete, you can confirm or modify the recognized text on the results page before confirming the search.

## Feature Notes
+ The purpose of recognition is to reduce typing. It will recognize all text in the screenshot; in most scenarios, secondary user confirmation is required before searching.
