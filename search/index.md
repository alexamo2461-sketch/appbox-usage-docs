# 搜索功能

AppBox 提供全局搜索功能，让你快速查找收藏的应用和应用集。

## 功能简介

通过底部导航栏的 **搜索** 标签进入搜索页面，可以搜索你收藏的所有应用和应用集。搜索支持按名称、说明等关键词匹配。

## 操作步骤

1. 点击底部导航栏的 **搜索** 标签
2. 在搜索框中输入关键词
3. 搜索结果会实时显示，包括匹配的应用和应用集
4. 点击搜索结果可以直接进入应用详情或应用集详情

## 搜索范围

- **应用名称**：匹配应用的名字
- **应用说明**：匹配你为应用添加的自定义说明内容
- **应用集名称**：匹配应用集的名字

## 搜索结果操作

在搜索结果中，你可以对应用和应用集执行以下操作：

- **应用**：点击进入应用详情页面
- **应用集**：点击进入应用集详情页面
- **长按应用**：弹出快捷菜单，支持编辑说明、复制/移动、删除等操作
- **长按应用集**：弹出快捷菜单，支持编辑、删除等操作

## 使用技巧

- 搜索是实时过滤的，输入关键词后结果会立即显示
- 可以使用较短的关键词来获得更多匹配结果
- 如果找不到某个应用，可以尝试搜索应用说明中的关键词
