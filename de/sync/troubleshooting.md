# Synchronisation nicht verfügbar?

Die Datensynchronisationsfunktion erfordert, dass der Benutzer auf dem aktuellen Gerät bei iCloud angemeldet ist und die iCloud-Synchronisierung aktiviert hat. Überprüfen Sie zunächst auf der AppBox **Datensynchronisation**-Seite, ob der iCloud-Status als **Verfügbar** angezeigt wird.

![iCloud-Status prüfen](/sync-icloud-status-en.png)

Wenn **Nicht verfügbar** angezeigt wird oder die Synchronisierung nicht funktioniert, stellen Sie sicher, dass die folgenden 2 Einstellungen **eingeschaltet** sind:

### 1. Einstellungen → [Name] → iCloud → Alle anzeigen → Apps, die iCloud verwenden → AppBox

![AppBox iCloud-Einstellung](/sync-appbox-en.png)

### 2. Einstellungen → [Name] → iCloud → iCloud Drive → "iCloud Drive" einschalten

![iCloud Drive-Einstellung](/sync-icloud-drive.png)
