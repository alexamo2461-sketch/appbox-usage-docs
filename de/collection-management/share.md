# Sammlung teilen

AppBox ermöglicht es Ihnen, Sammlungen als Bilder und QR-Code-Links zu teilen. So können Sie Apps ganz einfach an Freunde weiterempfehlen oder auf andere Geräte importieren.

## Als Bild teilen

Tippen Sie auf der Detailseite der Sammlung oben rechts auf die Teilen-Schaltfläche und wählen Sie "Als Bild teilen". Die aktuelle Sammlung wird als ansprechendes Teilen-Bild generiert, das den Sammlungsnamen, die Beschreibung und alle App-Elemente enthält.

## Als QR-Code-Link teilen

Wählen Sie die Option "Als Link teilen". Das System generiert einen QR-Code. Andere können den QR-Code scannen oder den geteilten Link antippen, um die Sammlung in ihr eigenes AppBox zu importieren.

## Importieren geteilter Sammlungen

Wenn Sie einen geteilten Sammlungs-Link oder ein Bild von anderen erhalten, können Sie ihn wie folgt importieren:

1. Tippen Sie auf der AppBox-Startseite oben rechts auf die Menüschaltfläche
2. Wählen Sie "Von QR-Code oder Link importieren"
3. Scannen Sie den QR-Code oder fügen Sie den Link ein, um den Import abzuschließen
