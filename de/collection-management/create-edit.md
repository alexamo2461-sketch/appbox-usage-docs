# Sammlung erstellen und bearbeiten

## Neue Sammlung erstellen

Stellen Sie sich eine Sammlung als "Liste" oder "Ordner" vor. Tippen Sie auf der Startseite oben rechts auf das Symbol **Sammlung hinzufügen**, um die Erstellungsseite zu öffnen. Sie können einen Namen, eine Farbe und eine Beschreibung eingeben, um eine neue Sammlung zu erstellen.

![Sammlung erstellen](/collection-management/create-collection-en.png)

## Sammlung bearbeiten

Halten Sie eine Sammlung gedrückt, um das Kontextmenü zu öffnen, oder tippen Sie auf der Detailseite der Sammlung auf die Schaltfläche **Sammlung bearbeiten**. Hier können Sie den Namen, die Farbe und die Beschreibung der Sammlung ändern.

![Sammlung bearbeiten](/collection-management/edit-collection-en.png)

## Sammlungsfarben

Beim Hinzufügen oder Bearbeiten einer Sammlung können Sie eine Farbe festlegen. Diese Farbe wird hauptsächlich im Hintergrund der Sammlungsbeschreibung, beim Hinzufügen-Button, in den Aktionsmenüsymbolen oben rechts und in den Akzentfarben der App-Detailseiten dieser Sammlung angezeigt.

![Sammlungsfarbe](/collection-management/collection-color.png)
