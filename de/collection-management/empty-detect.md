# Leere Sammlungen erkennen

**Einstellungen -> Leere Sammlungen erkennen -> Automatische Erkennung leerer Sammlungen**

Wenn diese Funktion aktiviert ist, wird beim Löschen der letzten verbleibenden App auf der Sammlungsdetailseite automatisch eine Abfrage angezeigt, ob die leere Sammlung ebenfalls gelöscht werden soll.
