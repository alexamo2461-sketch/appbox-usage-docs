# Direkt in AppBox hinzufügen

Sie können die "App hinzufügen"-Oberfläche über die folgenden Einträge öffnen:

+ Auf der **App-Sets**-Startseite: Verwenden Sie die Schaltfläche **App hinzufügen** unten rechts; falls nicht angezeigt, klicken Sie im Menü oben rechts auf **"App hinzufügen"**.
+ Auf einer bestimmten **App-Set-Detailseite**: Klicken Sie auf **App hinzufügen** (wenn Sie nur die aktuelle Liste organisieren, wird das Ziel-App-Set automatisch auf das aktuelle gesetzt).

![App hinzufügen Eintrag](/assets/how-to-add-apps/entry-screenshot.png)

Nach dem Öffnen können Sie die oberen Registerkarten nach Bedarf wechseln: **App-Name**, **App-Link**, **Benutzerdefiniert**. Im Vorschaubereich können Sie durch Klicken auf "Beschreibung bearbeiten" eine Beschreibungsbearbeitungsseite öffnen, um schnell Bewertungen, Beschreibungen und andere Attribute zu erfassen.

![App hinzufügen Oberfläche](/assets/how-to-add-apps/add-app-interface.png)

# Nach Namen suchen und hinzufügen (Im App Store suchen)

## Funktionsvorstellung
Unter der **App-Name**-Methode geben Sie Schlüsselwörter ein, durchsuchen den App Store, wählen Apps aus und fügen sie Ihrer Sammlung hinzu.

![Nach Namen suchen](/assets/how-to-add-apps/search-by-name.png)

## Anwendungsfälle
+ Sie haben nur den App-Namen, nicht den Link.
+ Sie möchten Apps mit demselben Namen vergleichen und das Symbol vor dem Hinzufügen überprüfen.

## Vorgehen
1. Öffnen Sie **App hinzufügen** und wählen Sie **App-Name**.
2. Geben Sie den Namen oder ein Schlüsselwort in das Eingabefeld ein und klicken Sie auf **App Store durchsuchen**.
3. In den **Suchergebnissen** können Sie die **Region** wechseln und erneut suchen (falls erforderlich).
4. Tippen Sie auf **Hinzufügen** in einer bestimmten Zeile, um sie auszuwählen; Mehrfachauswahl ist möglich.
5. Nach der Auswahl klicken Sie oben rechts auf Bestätigen, um zur vorherigen Seite zurückzukehren.
6. Wählen Sie das **Ziel-App-Set**; im Vorschaubereich können Sie Beschreibungen oder Tags bearbeiten.
7. Klicken Sie unten auf **Hinzufügen** oder **Weiter hinzufügen**.

## Funktionshinweise
+ Suchergebnisse stammen aus dem App Store der ausgewählten Region; die Listen können je nach Region variieren.
+ Der Vorschaubereich zeigt die ausgewählten Apps an; überprüfen Sie vor dem Speichern.

::: info
Unterstützt Texterkennung aus Screenshots oder Bildern. Es füllt mögliche **App-Namen** in das Suchfeld ein. Nach Abschluss der Erkennung können Sie den erkannten Text auf der Ergebnisseite bestätigen oder ändern.
:::

## Vorsichtsmaßnahmen
> **Hinweis**: Wenn eine App nicht gefunden werden kann, hängt dies oft mit der aktuell ausgewählten **App Store-Region** zusammen. Sie können die Region auf dieser Seite oder in den Einstellungen ändern und erneut suchen.

# Durch Eingabe und Erkennung von App Store-Links hinzufügen

## Funktionsvorstellung
Durch Einfügen eines Links zu einer App Store-App-Seite ruft AppBox Informationen wie Symbol und Name ab und fügt die App dem ausgewählten App-Set hinzu.

![Per Link hinzufügen](/assets/how-to-add-apps/add-by-link.png)

## Anwendungsfälle
+ Sie sehen eine Reihe von App Store-Links in einer Community, Webseite oder Notiz und möchten sie sofort speichern.
+ Sie haben den Link bereits kopiert und möchten nicht erneut nach dem Namen im Store suchen.

## Vorgehen
1. Öffnen Sie die Seite **App hinzufügen**.
2. Klicken Sie im oberen Segment auf **App-Link**.
3. Fügen Sie den Link in das Eingabefeld ein (nach dem Einfügen beginnt normalerweise die **automatische Erkennung**), oder klicken Sie auf **Aus Zwischenablage erkennen**, um den gesamten Text der Zwischenablage zu verwenden.
4. Wenn noch kein Speicherort ausgewählt wurde, wählen Sie ein oder mehrere Sets unter **Ziel-App-Set** aus.
5. Um einen bestimmten regionalen Store zu durchsuchen, passen Sie die **Region** auf dieser Seite an (konsistent mit "Einstellungen → App → App Store-Region").
6. Bestätigen Sie im **App-Vorschau**-Bereich, ob der Eintrag korrekt ist; hier können Sie Beschreibungen bearbeiten oder Tags auswählen.
7. Klicken Sie unten auf **Hinzufügen**, um zu speichern und zu schließen; oder klicken Sie auf **Weiter hinzufügen**, um auf dieser Seite zu bleiben und weitere Vorgänge durchzuführen.

::: info
Unterstützt **mehrere Links**: Im selben Eingabefeld können Sie mehrere App Store-Links durch **Zeilenumbrüche** oder **englische Semikolons** `;` trennen. Bei Änderungen wird automatisch versucht, die Erkennung durchzuführen; Sie können auch **Aus Zwischenablage erkennen** verwenden.
:::

## Funktionshinweise
+ Nach erfolgreicher Erkennung erscheint eine Vorschauliste; bei Fehlschlag gibt die Seite einen kurzen Grund an, sodass Sie überprüfen können, ob der Link vollständig ist.
+ Wenn der Link Regionsinformationen enthält, wird er normalerweise entsprechend dieser Region erkannt; Sie können auch manuell die Region wechseln und es erneut versuchen. Informationen zu Link-Erkennungsregeln: [App-Regionen & Link-Erkennung](/de/region/)

## Empfohlene Verwendung
+ Legen Sie Einträge zuerst in einem Standard-App-Set ab und organisieren Sie sie später in klassifizierte Sets, um wiederholte Vorgänge zu reduzieren.
+ Beim Sammeln von "App-Listen" aus Artikeln können Sie mehrere Links auf einmal einfügen und dann gemeinsam in der Vorschau bestätigen.

# Benutzerdefiniertes App hinzufügen (Manuelle Eingabe)

## Funktionsvorstellung
Geben Sie manuell Informationen wie App-Name, Symbol und Quelllink ein. Dies wird für Einträge verwendet, die im Store nicht gefunden werden können oder bei denen Sie die Darstellung vollständig anpassen möchten.

![Benutzerdefiniert hinzufügen](/assets/how-to-add-apps/custom-add.png)

## Anwendungsfälle
+ Apps, die noch nicht gelistet, bereits entfernt oder nur über bestimmte Kanäle vertrieben werden, die Sie aber in Ihrer Liste festhalten möchten.
+ Sie möchten ein benutzerdefiniertes Symbol und Notizen für eine Nicht-App Store-App/Software behalten.

## Vorgehen
1. Öffnen Sie **App hinzufügen** und wählen Sie **Benutzerdefiniert**.
2. Klicken Sie auf den Symbolbereich und folgen Sie den Anweisungen, um ein Symbol aus der **Fotomediathek**, **Dateien** oder über einen **Bildlink** (`http`/`https`, PNG/JPG empfohlen) zu erhalten.
3. Geben Sie den **App-Namen** ein (erforderlich).
4. Geben Sie bei Bedarf den **Quelllink** ein (Webseite oder Anleitungsadresse).
5. Wählen Sie das **Ziel-App-Set** aus.
6. Bearbeiten Sie im Vorschaubereich verwandte Informationen wie Beschreibung, Bewertung, Abonnement und Tags.
7. Klicken Sie unten auf **Hinzufügen**, um zu speichern.

## Funktionshinweise
+ Es wird empfohlen, den Quelllink mit der offiziellen Website oder einer vertrauenswürdigen Seite zu füllen, um eine spätere Überprüfung zu erleichtern.
+ Die Darstellung benutzerdefinierter Einträge hängt von den von Ihnen bereitgestellten Inhalten ab; sie wird nicht automatisch mit Store-Detailseiten synchronisiert wie bei Store-Apps.
+ Wenn die App für diese Funktion Mitgliedschaftsbeschränkungen anzeigt, folgen Sie den Anweisungen zur Mitgliedschaftsseite, wenn sie nicht freigeschaltet ist.

## Vorsichtsmaßnahmen
+ Benutzerdefinierte Einträge unterscheiden sich von Store-Einträgen in der Aktualisierungsmethode; Store-Apps können auf der Detailseite aktualisiert werden, während benutzerdefinierte Einträge manuell geändert werden müssen.
+ Wählen Sie nach Möglichkeit hochauflösende quadratische Symbole; vermeiden Sie die Vergrößerung kleiner Screenshots.

# App-Namen per Screenshot erkennen

## Funktionsvorstellung
Erkennen Sie Text aus Screenshots oder Bildern, füllen Sie mögliche **App-Namen** in das Suchfeld und schließen Sie die Hinzufügung ab, indem Sie mit [Nach Namen suchen und hinzufügen (Im App Store suchen)](#nach-namen-suchen-und-hinzufügen-im-app-store-suchen) kombinieren.

![Screenshot-Erkennung 1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## Anwendungsfälle
+ Sie haben nur einen App-Screenshot ohne kopierbaren Link. Sie möchten schnell den Titel aus dem Bild als Suchbegriff extrahieren.

![Screenshot-Erkennung 2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## Vorgehen
1. Öffnen Sie **App hinzufügen** → **App-Name**.
2. Klicken Sie rechts neben dem Namenseingabefeld auf **App im Bild erkennen** (Sucher-Symbol).
3. Wählen Sie **Aus Fotos auswählen** oder **Aus Dateien auswählen**.
4. Nach Abschluss der Erkennung können Sie den erkannten Text auf der Ergebnisseite bestätigen oder ändern, bevor Sie die Suche bestätigen.

## Funktionshinweise
+ Der Zweck der Erkennung ist es, Tipparbeit zu reduzieren. Es erkennt den gesamten Text im Screenshot; in den meisten Fällen ist eine sekundäre Benutzerbestätigung vor der Suche erforderlich.
