# App-Eigenschaften

Die App-Eigenschafteneinstellungen steuern, welche Attributfelder beim Bearbeiten von App-Beschreibungen angezeigt werden.

**Zugriff**: Einstellungen → Apps → App-Eigenschaften

## Konfigurierbare Eigenschaften

### Abonnement-Eigenschaften

Wenn aktiviert, werden beim Bearbeiten von App-Beschreibungen abonnementbezogene Eingabefelder angezeigt:

- Abonnementbeschreibung
- Abonnementpreis
- Währung
- Abonnementtyp (monatlich, jährlich usw.)
- Abonnement-Start-/Enddatum

### Preis-Eigenschaften

Wenn aktiviert, werden beim Bearbeiten von App-Beschreibungen preisbezogene Eingabefelder angezeigt, mit Unterstützung für den automatischen Abruf von App-Preisen aus dem App Store.

::: info
Die Konfiguration der App-Eigenschaften ist eine Pro-Funktion und erfordert ein AppBox Pro-Abonnement zur Änderung. Nicht-Pro-Benutzer haben diese Eigenschaften standardmäßig aktiviert.
:::
