# Anzeige-Konfiguration

Die Anzeige-Konfigurationsseite ermöglicht es Ihnen, die Anzeigeoptionen für Sammlungsseiten und App-Detailseiten anzupassen.

**Zugriff**: Einstellungen → Allgemein → Anzeige-Konfiguration

## Sammlungsseite-Konfiguration

### App-Anzeigemodus

Legen Sie das Standardverhalten beim Tippen auf eine App fest:

| Modus | Beschreibung |
| --- | --- |
| **App Store öffnen** | Tippen auf ein App-Symbol öffnet direkt die App Store-Seite der App |
| **Vorschau in AppBox** | Tippen auf ein App-Symbol zeigt eine App-Detailvorschau in AppBox |

### App-Ansicht

Legen Sie die Standardansicht für Sammlungsdetailseiten fest (Liste, Symbol oder Karte).

## App-Detailseite-Konfiguration

### Detailreihenfolge

Passen Sie die Anzeigereihenfolge der Abschnitte auf der App-Detailseite an, einschließlich:

- App-Screenshots
- App-Informationen
- Weitere Informationen
- App-Beschreibung
- Versionshinweise

Ziehen Sie einfach, um die Reihenfolge anzupassen.

### App-Beschreibung

- **Ausblenden wenn leer**: Wenn eine App keine Beschreibung hat, wird der Beschreibungsabschnitt ausgeblendet (Pro-Funktion)

### App-Tags

- **Tags anzeigen**: Steuern Sie, ob Tags auf der App-Detailseite angezeigt werden
- **Symbole anzeigen**: Steuern Sie, ob Tag-Symbole vor den Tag-Namen angezeigt werden
- **Einzeilig anzeigen**: Steuern Sie, ob Tags in einer einzigen Zeile angeordnet werden
