# Tags

AppBox unterstützt das Hinzufügen benutzerdefinierter Tags zu Apps für flexible Kategorisierung und schnelle Suche.

## Überblick

Tags bieten eine flexible Kategorisierungsmethode. Im Gegensatz zu Sammlungen kann eine App mehrere Tags haben, und derselbe Tag kann für mehrere Apps verwendet werden. Mit Tags kannst du sammlungsübergreifend schnell filtern und Apps finden.

## Tags hinzufügen

Auf der Seite zum Bearbeiten der App-Beschreibung kannst du einen oder mehrere Tags hinzufügen.

**Vorgehensweise**: App-Details öffnen → Beschreibung bearbeiten tippen → Tags im Tag-Bereich eingeben oder auswählen

## Tags verwalten

In den Einstellungen kannst du alle Tags verwalten:

**Vorgehensweise**: Einstellungen → Apps → Tag-Verwaltung

In der Tag-Verwaltung kannst du:

- Alle verwendeten Tags anzeigen
- Tags suchen
- Tag-Namen ändern
- Unerwünschte Tags löschen

## Apps nach Tags filtern

### Tag-Bereich auf der Startseite

Die Startseite zeigt alle verwendeten Tags am unteren Rand. Tippe auf einen Tag, um alle Apps mit diesem Tag anzuzeigen.

### Filtern innerhalb einer Sammlung

Im Filterbereich der Sammlungsdetails kannst du Apps nach Tags filtern. Siehe [Filtern innerhalb einer Sammlung](/app-management/filtering) für Details.

## Tag-Anzeigeeinstellungen

**Vorgehensweise**: Einstellungen → Allgemein → Anzeigekonfiguration → App-Detailseite

Konfiguriere, wie Tags auf der App-Detailseite angezeigt werden:

- **Tags anzeigen**: Tag-Anzeige auf der App-Detailseite umschalten
- **Symbol anzeigen**: Symbol vor jedem Tag ein-/ausblenden
- **Einzeilig**: Tags einzeilig anzeigen

::: info
Tag-Daten unterstützen Sync und Import/Export — deine Tags werden beim Gerätewechsel nicht verloren.
:::
