# Datenwiederherstellung bei Verlust

:::: info
**Wichtige Voraussetzungen für die Datenwiederherstellung:**

+ Die App darf **nicht** deinstalliert und neu installiert worden sein.
+ Die Daten müssen noch unter **Einstellungen > Allgemein > iPhone-Speicher > AppBox > Dokumente & Daten** vorhanden sein.

Bei Problemen können Sie jederzeit über **Einstellungen > Feedback** Kontakt mit mir aufnehmen.
::::

Tippen Sie auf **Einstellungen** → **FAQ** → **Datenverlust** → **Zum Reparieren tippen** → öffnen Sie die Seite **Scan-Ergebnisse** → überprüfen Sie, wie viele Datenbanken erkannt werden. Wenn zwei Datenbanken angezeigt werden, existiert die alte Datenbank noch. Tippen Sie unten auf die Schaltfläche **Alle verfügbaren Daten in die primäre Datenbank zusammenführen**, um die Daten wiederherzustellen.
