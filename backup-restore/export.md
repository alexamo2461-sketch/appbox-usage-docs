# 数据备份（数据导出）

AppBox 支持将所有应用集数据导出为文件，方便备份或迁移到其他设备。

**操作方式**：设置 → 数据 → 数据导出

## 导出内容

导出文件包含所有应用集及其包含的应用信息，包括：

- 应用集名称、颜色、说明
- 应用名称、图标、链接、评分、说明
- 订阅属性、标签等自定义信息
- 应用集自定义排序顺序

## 导出格式

支持两种导出格式：

| 格式 | 说明 |
| --- | --- |
| **JSON** | 纯文本格式，便于阅读和编辑，适合技术用户 |
| **ZIP** | 压缩包格式，内含应用图标文件和 JSON 数据文件，适合完整备份 |

## 操作步骤

1. 进入 **设置 → 数据导出**
2. 点击底部的 **导出数据** 按钮
3. 在弹出的格式选择中选择 **JSON** 或 **ZIP**
4. 系统会通过分享功能导出文件，你可以选择保存到"文件"、发送到其他应用等

## 导出方式

- **JSON 格式**：通过系统分享功能保存，可发送到邮件、保存到 iCloud Drive 或其他位置
- **ZIP 格式**：通过系统文件保存功能直接保存为 `.zip` 文件

::: info
导出的数据可以用于后续的数据导入操作，也可以作为本地备份保存。详见 [数据导入](/backup-restore/data-import)。
:::

## 注意事项

> **注意**：数据导出为会员功能，需订阅 AppBox Pro 后使用。
