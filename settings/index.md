# ⚙️ 设置功能

AppBox 的设置页面包含丰富的配置选项，帮助你个性化使用体验和管理数据。

## 通用

- [设置主题（颜色与模式）](/settings/theme)：设置主题模式和主题颜色
- **语言**：跳转到系统设置更改应用语言
- [功能配置](/settings/display-configuration)：配置应用集页面和应用详情页面的显示选项

## 应用集

- [应用集管理](/collection-management/)：查看和管理所有应用集，支持多选删除
- [空应用集检测](/collection-management/empty-detect)：自动检测并提示删除空应用集
- [分享管理](/settings/share-management)：管理已分享的应用集链接

## 应用

- **全部应用**：查看所有收藏的应用（去重），支持跳转到 App Store
- [应用地区](/region/)：管理 App Store 查询地区列表
- [标签管理](/tags/)：管理所有应用标签
- [应用属性](/settings/app-properties)：配置订阅属性和价格属性的显示

## 数据

- [数据同步](/sync/)：iCloud 数据同步
- [数据导入](/backup-restore/data-import)：导入 AppBox 数据或 Apple 数据
- [数据导出](/backup-restore/export)：导出数据为 JSON 或 ZIP 文件
- [数据管理](/settings/data-management)：刷新应用信息、下载图标、清理缓存、数据重置

## 其他

- **使用指南**：打开在线帮助文档
- **常见问题**：应用内常见问题页面
- **使用反馈**：通过邮件发送反馈
- **评分 AppBox**：前往 App Store 评分
- **关于 AppBox**：查看应用版本和开发者信息
