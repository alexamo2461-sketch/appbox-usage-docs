# 功能配置

功能配置页面让你自定义应用集页面和应用详情页面的显示选项。

**操作方式**：设置 → 通用 → 功能配置

## 应用集页配置

### 查看应用方式

设置点击应用时的默认行为：

| 方式 | 说明 |
| --- | --- |
| **打开 App Store** | 点击应用图标直接跳转到 App Store 应用页面 |
| **AppBox 内预览** | 点击应用图标在 AppBox 内弹出应用详情预览 |

### 应用视图

设置应用集详情页面的默认视图（列表、图标或卡片）。

## 应用详情页配置

### 详情排序

自定义应用详情页面各板块的显示顺序，包括：

- 应用截图
- 应用信息
- 更多信息
- 应用介绍
- 更新记录

拖动调整顺序即可。

### 应用说明

- **无说明时隐藏显示**：当应用没有添加说明时，隐藏应用说明板块（需会员）

### 应用标签

- **开启标签显示**：控制是否在应用详情页显示标签
- **显示图标**：控制标签前是否显示标签小图标
- **单行显示**：控制标签是否以单行方式排列
