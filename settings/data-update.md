# 数据更新

数据更新功能用于将 AppBox 中的数据从 App Store 获取最新信息，保持应用信息的时效性。

**操作方式**：设置 → 数据 → 数据管理

## 刷新应用信息

从 App Store 重新获取应用的名称、图标、截图、介绍、价格等最新信息。

**操作方式**：设置 → 数据 → 数据管理 → 刷新应用信息

进入后可以看到所有待刷新的应用列表，可以选择全部刷新或逐个刷新。刷新过程在后台执行，不影响正常使用。

> **提示**：刷新操作会获取最新的应用信息，但不会覆盖你自定义的评分和说明内容。

## 离线下载图标

将应用图标下载到本地设备，这样在没有网络的环境下也能正常显示应用图标。

**操作方式**：设置 → 数据 → 数据管理 → 离线下载图标

建议在网络良好的环境下执行此操作。

## 清理缓存

- **清理无效图标缓存**：删除已不存在或无效的图标缓存文件，释放存储空间
- **清理无效应用数据**：清理孤立的应用数据记录

## 数据重置

> **注意**：以下操作不可恢复，请谨慎操作。

**删除本地数据**：清除设备上所有 AppBox 数据。执行前请务必确认数据已备份或已同步到 iCloud。
