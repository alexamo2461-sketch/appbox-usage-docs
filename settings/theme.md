# 设置主题（颜色与模式）

AppBox 支持自定义主题模式和主题颜色，让你的使用体验更加个性化。

**操作方式**：设置 → 通用 → 主题

## 主题模式

提供三种模式可选：

- **浅色模式**：始终使用浅色界面
- **深色模式**：始终使用深色界面
- **跟随系统**：根据系统设置自动切换浅色或深色模式

选择后即刻生效，无需重启应用。

## 主题颜色

提供 9 种主题颜色可选：

| 颜色 | 说明 |
| --- | --- |
| 橙色 | 温暖活力 |
| 黄色 | 明亮轻快 |
| 绿色 | 清新自然 |
| 薄荷绿 | 清爽舒适 |
| 蓝色 | 默认推荐 |
| 靛蓝 | 沉稳优雅 |
| 粉色 | 甜美可爱 |
| 紫色 | 神秘高贵 |
| 棕色 | 质朴温暖 |

主题颜色会影响以下位置的颜色显示：

- 首页界面颜色
- 新增应用集时的默认颜色
- 各处按钮和高亮颜色

::: info
主题设置修改后会自动保存，下次打开应用时保持你选择的主题。
:::
