# 统计功能

AppBox 提供丰富的数据统计功能，帮助你全面了解自己的应用收藏情况。

## 功能简介

通过底部导航栏的 **统计** 标签进入统计页面，可以查看各种数据图表和分析结果。

::: info
统计功能为会员功能，需订阅 AppBox Pro 后使用。未订阅时会展示示例数据供预览。
:::

## 关键指标

统计页面顶部展示四个核心指标卡片：

| 指标 | 说明 |
| --- | --- |
| **收藏应用** | 去重后的应用总数（可点击查看全部应用列表） |
| **应用集数** | 已创建的应用集总数 |
| **订阅总支出** | 所有订阅应用的费用总计（可点击查看详情） |
| **应用总数** | 不去重的应用总条目数（可点击查看原始列表） |

## 统计图表

### 评分分布
展示你为应用打出的评分分布情况，直观了解你的评分偏好。

### 订阅数据统计
展示当前订阅数量、按币种的月支出、年度成本预估等订阅相关信息。点击可进入详细的订阅数据页面。

### 应用说明覆盖率
展示已添加说明的应用数量与占比，帮助你了解哪些应用还没有添加说明。

### 添加行为趋势
按月统计你收藏应用的数量变化趋势，了解你的收藏习惯。

### 平台分布
展示应用支持的平台分布情况（iPhone、iPad、Mac）。

### 地区分布
展示应用所属的 App Store 国家/地区分布。

### 应用分类分布
展示应用按 App Store 主分类的分布情况。

## 统计范围

默认统计所有应用集的数据，你也可以自定义统计范围：

1. 点击统计页面右上角的 **范围** 按钮
2. 选择 **全部应用集** 或勾选特定的应用集
3. 可以开启 **跨应用集去重**，合并不同应用集中的相同应用

## 自定义统计

你可以自定义统计卡片的显示顺序和可见性：

1. 点击统计页面右上角的 **自定义** 按钮
2. 拖动调整卡片的显示顺序
3. 点击眼睛图标切换卡片的显示/隐藏
4. 点击 **恢复默认** 可以重置为默认布局

## 订阅数据详情

点击"订阅总支出"或"订阅数据统计"卡片可以进入详细的订阅数据页面，包括：

- 月度支出统计
- 年度支出统计
- 总支出趋势
- 订阅构成明细
- 费用分布图表
- 时间与续费分析
