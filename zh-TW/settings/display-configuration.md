# 功能配置

功能配置頁面讓你自訂應用集頁面和應用詳情頁面的顯示選項。

**操作方式**：設定 → 通用 → 功能配置

## 應用集頁配置

### 查看應用方式

設定點擊應用時的預設行為：

| 方式 | 說明 |
| --- | --- |
| **打開 App Store** | 點擊應用圖示直接跳轉到 App Store 應用頁面 |
| **AppBox 內預覽** | 點擊應用圖示在 AppBox 內彈出應用詳情預覽 |

### 應用視圖

設定應用集詳情頁面的預設視圖（列表、圖示或卡片）。

## 應用詳情頁配置

### 詳情排序

自訂應用詳情頁面各板塊的顯示順序，包括：

- 應用截圖
- 應用資訊
- 更多資訊
- 應用介紹
- 更新記錄

拖動調整順序即可。

### 應用說明

- **無說明時隱藏顯示**：當應用沒有添加說明時，隱藏應用說明板塊（需會員）

### 應用標籤

- **開啟標籤顯示**：控制是否在應用詳情頁顯示標籤
- **顯示圖示**：控制標籤前是否顯示標籤小圖示
- **單行顯示**：控制標籤是否以單行方式排列
