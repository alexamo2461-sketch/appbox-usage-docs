# ⚙️ 設定功能

AppBox 的設定頁面包含豐富的配置選項，幫助你個性化使用體驗和管理數據。

## 通用

- [設定主題（顏色與模式）](/zh-TW/settings/theme)：設定主題模式和主題顏色
- **語言**：跳轉到系統設定更改應用語言
- [功能配置](/zh-TW/settings/display-configuration)：配置應用集頁面和應用詳情頁面的顯示選項

## 應用集

- [應用集管理](/zh-TW/collection-management/)：查看和管理所有應用集，支援多選刪除
- [空應用集檢測](/zh-TW/collection-management/empty-detect)：自動檢測並提示刪除空應用集
- [分享管理](/zh-TW/settings/share-management)：管理已分享的應用集連結

## 應用

- **全部應用**：查看所有收藏的應用（去重），支援跳轉到 App Store
- [應用地區](/zh-TW/region/)：管理 App Store 查詢地區列表
- [標籤管理](/zh-TW/tags/)：管理所有應用標籤
- [應用屬性](/zh-TW/settings/app-properties)：配置訂閱屬性和價格屬性的顯示

## 數據

- [數據同步](/zh-TW/sync/)：iCloud 數據同步
- [數據導入](/zh-TW/backup-restore/data-import)：導入 AppBox 數據或 Apple 數據
- [數據導出](/zh-TW/backup-restore/export)：導出數據為 JSON 或 ZIP 檔案
- [數據管理](/zh-TW/settings/data-management)：刷新應用資訊、下載圖示、清理快取、數據重置

## 其他

- **使用指南**：打開線上說明文件
- **常見問題**：應用內常見問題頁面
- **使用反饋**：透過郵件傳送反饋
- **評分 AppBox**：前往 App Store 評分
- **關於 AppBox**：查看應用版本和開發者資訊
