# 新建與編輯應用集

## 新建應用集

將應用集想像成一個「清單」或者「資料夾」，在首頁應用集頁面中點擊右上角新增應用集圖示按鈕彈出新增應用集頁面，可以輸入應用名稱、顏色和說明來新增應用集。

![新建應用集](/collection-management/create-collection.png)

## 編輯應用集

長按應用集彈出快捷選單或在應用詳情頁面中點擊編輯應用集按鈕彈出應用集編輯頁面，可以修改應用集的名稱、顏色和應用集說明。

![編輯應用集](/collection-management/edit-collection.png)

## 應用集顏色

在新增/編輯應用集時可以設定該應用集的顏色，這個顏色主要表現在應用集詳情頁面中應用集說明背景、新增按鈕、右上角操作選單圖示以及在該應用集詳情頁面中點擊進入的應用詳情頁面高亮顏色。如下圖所示：
