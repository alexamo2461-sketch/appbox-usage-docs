# 應用標籤

AppBox 支援為應用新增自訂標籤，幫助你更靈活地分類和尋找應用。

## 功能簡介

標籤是一種靈活的分類方式。與應用集不同，一個應用可以新增多個標籤，同一個標籤也可以用於多個應用。透過標籤，你可以跨應用集快速篩選和尋找應用。

## 新增標籤

在編輯應用說明頁面中，可以為應用新增一個或多個標籤。

**操作方式**：進入應用詳情 → 點擊編輯說明 → 在標籤區域輸入或選擇標籤

## 標籤管理

在設定中可以統一管理所有標籤：

**操作方式**：設定 → 應用 → 標籤管理

在標籤管理頁面中，你可以：

- 查看所有已使用的標籤
- 搜尋標籤
- 修改標籤名稱
- 刪除不需要的標籤

## 透過標籤篩選應用

### 首頁標籤區域

首頁底部會顯示所有已使用的標籤。點擊某個標籤，可以查看所有使用該標籤的應用列表。

### 應用集內篩選

在應用集詳情頁面的篩選面板中，可以按標籤篩選應用。詳見 [應用集內篩選](/app-management/filtering)。

## 標籤顯示設定

**操作方式**：設定 → 通用 → 功能配置 → 應用詳情頁

可以配置標籤在應用詳情頁的顯示方式：

- **開啟標籤顯示**：控制是否在應用詳情頁顯示標籤
- **顯示圖示**：控制標籤前是否顯示標籤圖示
- **單行顯示**：控制標籤是否以單行方式顯示

::: info
標籤資料支援同步和匯入匯出，換裝置後標籤不會遺失。
:::
