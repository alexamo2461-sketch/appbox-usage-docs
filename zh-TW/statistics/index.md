# 統計功能

AppBox 提供豐富的資料統計功能，幫助你全面了解自己的應用收藏情況。

## 功能簡介

透過底部導覽列的 **統計** 分頁進入統計頁面，可以查看各種資料圖表和分析結果。

::: info
統計功能為會員功能，需訂閱 AppBox Pro 後使用。未訂閱時會展示範例資料供預覽。
:::

## 關鍵指標

統計頁面頂部展示四個核心指標卡片：

| 指標 | 說明 |
| --- | --- |
| **收藏應用** | 去重後的應用總數（可點擊查看全部應用列表） |
| **應用集數** | 已建立的應用集總數 |
| **訂閱總支出** | 所有訂閱應用的費用總計（可點擊查看詳情） |
| **應用總數** | 不去重的應用總條目數（可點擊查看原始列表） |

## 統計圖表

### 評分分佈
展示你為應用打出的評分分佈情況，直觀了解你的評分偏好。

### 訂閱資料統計
展示目前訂閱數量、按幣別的月支出、年度成本預估等訂閱相關資訊。點擊可進入詳細的訂閱資料頁面。

### 應用說明覆蓋率
展示已新增說明的應用數量與佔比，幫助你了解哪些應用還沒有新增說明。

### 新增行為趨勢
按月統計你收藏應用的數量變化趨勢，了解你的收藏習慣。

### 平台分佈
展示應用支援的平台分佈情況（iPhone、iPad、Mac）。

### 地區分佈
展示應用所屬的 App Store 國家/地區分佈。

### 應用分類分佈
展示應用按 App Store 主分類分佈情況。

## 統計範圍

預設統計所有應用集的資料，你也可以自訂統計範圍：

1. 點擊統計頁面右上角的 **範圍** 按鈕
2. 選擇 **全部應用集** 或勾選特定的應用集
3. 可以開啟 **跨應用集去重**，合併不同應用集中的相同應用

## 自訂統計

你可以自訂統計卡片的顯示順序和可見性：

1. 點擊統計頁面右上角的 **自訂** 按鈕
2. 拖動調整卡片的顯示順序
3. 點擊眼睛圖標切換卡片的顯示/隱藏
4. 點擊 **恢復預設** 可以重置為預設版面

## 訂閱資料詳情

點擊「訂閱總支出」或「訂閱資料統計」卡片可以進入詳細的訂閱資料頁面，包括：

- 月度支出統計
- 年度支出統計
- 總支出趨勢
- 訂閱構成明細
- 費用分佈圖表
- 時間與續訂分析
