# 在 AppBox 內直接添加

您可以通過如下入口打開「新增應用」界面：

+ 在 **應用集** 主頁：使用右下角 **新增應用** 按鈕；若未顯示，請點右上角菜單中的 **「新增應用」**。
+ 在某個 **應用集詳情** 頁：點 **新增應用**（若僅整理當前清單，目標應用集會自動指向當前應用集）。

![新增應用入口](/assets/how-to-add-apps/entry-screenshot.png)

打開後，頂部可按需切換：**應用名稱**、**應用鏈接**、**自定義**。在預覽應用區域點擊編輯說明可以彈出應用說明編輯頁面，用以快速記錄評分、說明等屬性信息。

![新增應用界面](/assets/how-to-add-apps/add-app-interface.png)

# 按名稱搜索並添加（在 App 內搜索商店）

## 功能簡介
在 **應用名稱** 方式下輸入關鍵字，從 App Store 搜索並勾選應用，加入收藏。

![按名稱搜索](/assets/how-to-add-apps/search-by-name.png)

## 使用場景
+ 只有應用名字，沒有鏈接。
+ 想對比同名應用，核對圖標再添加。

## 操作步驟
1. 打開 **新增應用**，選擇 **應用名稱**。
2. 在輸入框輸入名稱或關鍵字，點 **搜索 App Store**。
3. 在 **搜索結果** 中可切換 **地區** 後重新搜索（如需）。
4. 輕點某一行的 **添加** 進行選擇；可勾選多個。
5. 選好以後點右上角確認，返回上一頁。
6. 選擇 **目標應用集**，在預覽區可編輯說明或標籤。
7. 點底部 **添加** 或 **繼續添加**。

## 功能說明
+ 搜索結果來自所選地區的 App Store；地區不同，列表可能不同。
+ 預覽區會顯示已選中的應用，確認無誤後再保存。

::: info
支持從截圖或圖片中識別文字，把可能的 **應用名稱** 填入搜索框，識別完成後，可在結果頁確認或修改識別出的文字。
:::

## 注意事項
> **注意**：搜索不到某應用，常與當前所選 **應用商店地區** 有關，可在本頁或設置裡更換地區後再搜。

# 輸入並識別 App Store 鏈接添加

## 功能簡介
通過粘貼 App Store 應用頁面的鏈接，讓 AppBox 獲取圖標與名稱等信息，並把應用加入所選應用集。

![通過鏈接添加](/assets/how-to-add-apps/add-by-link.png)

## 使用場景
+ 在社區、網頁或備忘錄裡看到一串 App Store 鏈接，想馬上收藏。
+ 已經複製了鏈接，不想再去商店裡搜索名稱。

## 操作步驟
1. 打開 **新增應用** 頁面。
2. 點頂部分段中的 **應用鏈接**。
3. 將鏈接粘貼到輸入框（粘貼後一般會 **自動開始識別**），也可點 **從剪貼板識別** 使用剪貼板全文。
4. 若尚未選好存放位置，在 **目標應用集** 中選擇一個或多個應用集。
5. 如需按特定地區商店查詢，可在本頁調整 **地區**（與「設置 → 應用 → 應用商店地區」一致）。
6. 在 **應用預覽** 中確認條目是否正確，可在此編輯說明或選擇標籤。
7. 點底部 **添加** 保存並關閉；或點 **繼續添加** 保留在本頁繼續操作。

::: info
支持 **多條鏈接**：在同一輸入框中，用 **換行** 或 **英文分號** `;` 分隔多條 App Store 鏈接；內容變化後會自動嘗試識別，也可使用 **從剪貼板識別**。
:::

## 功能說明
+ 識別成功後會出現預覽列表；失敗時頁面會給出簡短原因提示，可檢查鏈接是否完整。
+ 若鏈接帶地區信息，通常會按鏈接中的商店區域識別；也可手動切換地區後再試。關於鏈接識別規則：[應用地區與APP連結識別](/zh-TW/region/)

## 推薦用法
+ 先放進默認應用集，之後再整理到分類應用集，減少重複操作。
+ 批量收藏文章裡的「應用清單」時，可一次性粘貼多條鏈接再統一確認預覽。

# 自定義添加應用（手動填寫信息）

## 功能簡介
手動填寫應用名稱、圖標與來源鏈接等信息，用於商店暫時搜不到、或你希望完全自定義展示方式的條目。

![自定義添加](/assets/how-to-add-apps/custom-add.png)

## 使用場景
+ 尚未上架、已下架或僅限特定渠道分發的應用，但仍想在清單裡佔位記錄。
+ 需要為某個非 AppStore 應用/軟件保留自定義圖標與備註。

## 操作步驟
1. 打開 **新增應用**，選擇 **自定義**。
2. 點圖標區域，按提示從 **照片圖庫**、**文件** 或通過 **圖片鏈接**（`http`/`https`，建議 PNG/JPG）獲取圖標。
3. 填寫 **應用名稱**（必填）。
4. 按需填寫 **鏈接來源**（網頁或說明地址）。
5. 選擇 **目標應用集**。
6. 應用預覽區域可編輯說明、評分、訂閱、標籤等相關信息。
7. 點底部 **添加** 保存。

## 功能說明
+ 來源鏈接建議填官網或可信頁面，日後復查更方便。
+ 自定義條目的展示依賴你填寫的內容；不會像商店應用那樣自動同步商店詳情頁。
+ 若 App 內對本功能顯示會員限制，未解鎖時按提示前往會員說明頁。

## 注意事項
+ 自定義條目與從商店添加的條目在更新方式上不同；商店應用可在詳情頁執行刷新，自定義條目需自行修改信息。
+ 盡量選擇分辨率較高的正方形圖標；避免過小截圖放大。

# 通過截圖識別應用名稱

## 功能簡介
從截圖或圖片中識別文字，把可能的 **應用名稱** 填入搜索框，再結合[按名稱搜索並添加（在 App 內搜索商店）](#按名稱搜索並添加在-app-內搜索商店)完成添加。

![截圖識別1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## 使用場景
+ 只有應用截圖，沒有可複製鏈接，想快速提取圖上標題作為搜索關鍵詞。

![截圖識別2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## 操作步驟
1. 打開 **新增應用** → **應用名稱**。
2. 在名稱輸入框右側，點 **識別圖片中的應用**（取景框樣式圖標）。
3. 選擇 **從照片中選擇** 或 **從文件中選擇**。
4. 識別完成後，可在結果頁確認或修改識別出的文字，再確認搜索。

## 功能說明
+ 識別目的是減少打字，會識別截圖中的全部文字，大多數場景下都需要用戶二次確認後再搜索。
