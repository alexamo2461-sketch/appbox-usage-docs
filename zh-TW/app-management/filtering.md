# 應用集內篩選

AppBox 的應用集詳情頁面提供強大的篩選功能，幫助你快速定位需要的應用。

## 功能簡介

在應用集詳情頁面，點擊右上角的 **篩選** 圖示，可以打開篩選面板，按多種條件過濾目前應用集中的應用。

## 篩選條件

| 條件 | 說明 |
| --- | --- |
| **關鍵詞** | 在應用名稱、說明、訂閱說明中搜尋關鍵詞（最多 50 字） |
| **評分** | 按你給出的評分篩選，包括「無評分」和 1～5 星 |
| **標籤** | 按應用標籤篩選，支援多選 |
| **分類** | 按 App Store 主分類篩選 |
| **來源** | 按應用來源篩選：App Store 應用或自訂應用 |
| **平台** | 按支援平台篩選：iPhone、iPad、Mac |
| **地區** | 按 App Store 地區篩選（僅顯示目前應用集中實際出現的地區） |

## 操作步驟

1. 打開某個應用集
2. 點擊右上角的 **篩選** 圖示
3. 在篩選面板中設定你需要的條件
4. 多個條件之間為「且」的關係（同時滿足）
5. 設定完成後，應用列表會自動過濾

## 清除篩選

點擊篩選面板中的 **清除** 按鈕，可以重置所有篩選條件，顯示全部應用。

## 使用技巧

- 地區篩選僅顯示目前應用集中實際存在的地區，不會出現空選項
- 可以組合多個條件進行精確篩選，例如「標籤為效率 + 平台為 iPhone」
- 關鍵詞搜尋會同時匹配應用名稱和說明內容
