# 切換應用視圖

應用集詳情頁面提供了 3 種視圖方式展示應用，滿足不同使用場景。

## 三種視圖

| 視圖 | 說明 |
| --- | --- |
| **列表視圖** | 以緊湊的列表形式展示應用，每行顯示圖示、名稱和說明，適合應用較多時快速瀏覽 |
| **圖示視圖** | 以網格形式展示應用圖示，直觀美觀，適合應用較少或注重圖示識別的場景 |
| **卡片視圖** | 以卡片形式展示應用的評分、說明、標籤等更多資訊，適合詳細管理應用 |

## 快速切換

在應用集詳情頁面，點擊右上角操作選單中的 **切換視圖** 按鈕，可以在三種視圖之間快速切換。

## 設定預設視圖

如果你希望每次進入應用集詳情時都使用同一種視圖，可以在設定中固定：

**設定 → 通用 → 功能配置 → 應用集頁**，選擇你偏好的預設視圖。

> **提示**：右上角的切換按鈕是「臨時」切換，設定中的配置才是「固定」視圖。

::: info
卡片視圖為會員功能，需訂閱 AppBox Pro 後使用。自訂排序僅在列表視圖和圖示視圖下支援拖曳排序，卡片視圖和網格視圖會按照自訂排序的順序顯示但不支援拖曳。
:::
