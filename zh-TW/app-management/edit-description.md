# 編輯應用說明

可以為應用集中的應用自訂評分和加入備註說明文字，評分和說明文字將顯示在應用資訊中應用圖示和標題的下方。

**操作方式**：該頁面可以有多個入口觸發：

1. 在應用詳情頁面點擊左上角編輯按鈕
2. 底部操作欄新增模組的新增應用後的應用預覽區域
3. 應用集詳情頁面新增按鈕識別應用後的應用預覽區域

![編輯應用說明](/app-management/edit-description.png)

> **注意**：不同應用集之間的（相同名字的）說明內容是相互獨立的。例如在應用集 A 中有個「抖音」，在應用集 B 中也有個「抖音」，這兩者的評分、應用說明以及訂閱等屬性都是互相獨立且不會同步的。這是功能特性，而不是軟體 Bug。如果要實現兩者的應用說明相同，可以使用複製功能手動將應用複製到另一個應用集中。當然，此後編輯任一個應用集中的該應用說明，另一個也不會同步。
