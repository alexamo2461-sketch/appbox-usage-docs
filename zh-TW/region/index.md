# 應用地區怎麼使用
**應用地區**指的是：AppBox 在向 App Store **查詢 App 介紹、圖示等資訊**時，所使用的 **國家或地區商店**。

它可以幫助你：**搜尋該地區上架的 App**、**依照該地區顯示名稱與圖示**、以及 **批次統一查詢地區資訊**。

:::info
**注意：** App 是否上架、名稱翻譯等資訊，皆 **以該地區的 App Store 為準**；若提示該地區無此 App，代表是商店端回傳的結果，並不表示收藏遺失。
:::

## 什麼情況下會用到
+ **搜尋不到 App 名稱** → 可切換地區重新搜尋（部分 App 僅於特定商店上架）。  
+ **同名 App 難以分辨** → 可透過地區區分顯示資訊。  
+ **連結本身帶有地區資訊** → AppBox 會 **優先依照連結** 進行辨識（見下方說明）。  
+ **多國 App 清單** → 可使用 **篩選 · 地區** 查看，或先 **批次修改地區** 後再重新整理。

## 在「設定」中管理應用地區
**設定 → App → 應用地區**

這裡是 **「地區查詢列表」**：已啟用的國家或地區，**由上到下** 代表優先順序（排在前面的會優先查詢；需要嘗試多個地區時，也會參考此順序）。

| 操作 | 說明 |
| --- | --- |
| **新增地區** | 點擊「新增地區」，從清單中選擇；**最多可新增 10 個**，超過時會顯示提示。 |
| **刪除** | 在項目上 **向左滑動** 即可刪除；**至少需保留 1 個地區**。 |
| **排序** | 點擊右上角 **排序**，拖曳完成後 **勾選** 儲存。通常 **最上方** 的地區會作為預設優先（特別是無法從連結判斷地區時）。 |
| **列表為空** | 頁面會提示：請透過「新增地區」進行選擇。 |

### 與「選擇地區」列表的差異
在 **新增 App**、**App 詳情頁** 等位置彈出的 **「選擇地區」** 中，通常只會顯示你已在設定中 **啟用** 的地區（也就是上方的「地區查詢列表」），方便快速切換。

而設定中的 **新增地區**，則是從 **完整地區目錄** 中挑選，用來擴充這份已啟用清單。

## App Store 連結與地區：辨識規則
當你貼上或分享 **App Store App 連結** 時，AppBox 會盡可能從連結中解析出 **國家或地區**，例如：

+ 若連結中包含類似 `…/cn/app/…`、`…/us/app/…` 這類 **兩位字母代碼**（通常為小寫），系統一般會辨識為對應地區（例如 cn → 中國大陸商店、us → 美國商店等）。

| 情況 | 系統行為 |
| --- | --- |
| **連結中可辨識地區** | 在 **新增 App → App 連結** 中，通常 **不會顯示**「國家或地區」欄位（因為地區已由連結指定）。即使調整設定中的地區順序，也 **不會改變** 此類連結優先依照連結解析的邏輯。 |
| **連結中無法辨識地區** | 系統會顯示 **「國家或地區」**（例如「中國大陸 (cn)」），並使用你目前在設定中所選擇的地區。 |
| **一次貼上多個連結** | 若整段內容 **無法** 被解析為「單一帶有地區的連結」，通常會 **顯示**「國家或地區」選項；多個連結會 **共用** 本次選擇的地區策略。 |

**簡單來說：** 若連結已明確標示地區，就以連結為準；若無法判斷，則依照你在 AppBox 中所選擇的地區處理。

## App 詳情頁：查看與修改地區

![](../../assets/region/app-detail-region.png)

### 查看地區
在 App 詳情頁中開啟 **「更多資訊」**，其中的 **「地區」** 欄位會顯示此收藏目前所對應的商店代碼名稱。

### 修改地區（僅限商店來源 App）
1. 在 App 詳情頁右上角的 **「⋯」** 選單中，點擊 **「修改地區」**。  
2. 在 **「選擇地區」** 中任選一個地區並確認。  
3. AppBox 會 **重新向商店查詢** 該 App 是否存在於新的地區商店中；  
    - **成功**：會更新名稱、圖示等資訊（若商店有提供），並顯示 **修改成功**；  
    - **失敗**：例如提示 **「目前所選地區商店無此 App」**，系統會自動 **恢復為修改前的地區**，避免留下錯誤狀態。

> **自訂 App** 目前不會顯示 **「修改地區」** 功能，因為其資訊是由你自行填寫。
>

### 批次修改地區
當你在 **同一個應用集** 中，已 **多選** 多個來自商店的 App 時，可一次切換至相同地區，並嘗試更新顯示資訊。

#### 操作步驟
1. 開啟某個 **應用集**。  
2. 點擊右上角 **「⋯」** → **「選擇 App」**。  
3. 勾選多個 App。  
4. 點擊底部工具列中的 **「地區」**（地球圖示）。  
5. 在 **「選擇地區」** 中點選目標地區；App 會逐一嘗試取得商店資訊。  
6. 完成後可查看 **「批次修改地區結果」**：成功、失敗或略過的 App 都會分別列出說明。

### 篩選（只顯示特定地區）
在應用集詳情頁右上角點擊 **篩選** 圖示 → 表單中的 **「地區」** → 可多選，只顯示目前應用集中符合條件的 App。可選地區僅限於 **目前應用集中實際出現過的地區**。

## 資料匯入中的「Apple Data」

**設定 → 資料匯入 → Apple Data**  
在準備匯入時，可選擇 1–10 個地區，系統會依照列表順序自動取得 App 資訊，直到成功命中或用盡所有策略。

請注意，若選擇過多地區，匯入速度會明顯變慢，建議勾選 1–3 個地區即可。
