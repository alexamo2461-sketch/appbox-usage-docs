# 顯示順序排序功能

該功能用於調整應用詳情頁面中以下區塊的顯示順序：

- **應用截圖**：顯示應用的截圖，可同時顯示多平台。
- **應用資訊**：從 AppStore 取得的最新應用資訊，包括 App ID、開發者、價格、大小等資訊。
- **應用介紹**：從 AppStore 取得的應用介紹。
- **更新記錄**：從 AppStore 取得的最新一筆更新記錄。
- **更多資訊**：目前應用的 AppStore 地區、加入到應用集的時間以及來源連結。

**操作方式**：設定 → 應用顯示順序 → 拖動列表即可完成排序。
