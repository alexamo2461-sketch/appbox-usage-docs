# 購買相關說明

> 相關連結：[會員功能說明](/zh-TW/membership/feature-overview)

## 購買須知

- 隨著功能的不斷改善，價格可能會有所調整。開發者同時承諾：不會把買斷用戶轉為訂閱，買斷之後不再需要二次付費；
- 在會員期內，所有功能都可以使用；購買後，不支援退款操作，請謹慎思考後再購買。
- 不支援 Apple ID 帳戶之間的購買/訂閱遷移；也不支援多個 App ID 共享會員。

## 恢復購買

如果使用過程或重新安裝時已經購買了會員但是不能使用會員功能，可以前往設定 - AppBox Pro 頁面，手動點擊恢復購買的按鈕，即可恢復之前的會員身份（需要和購買時使用的 Apple ID 保持一致）。如果 AppBox Pro 頁面沒有「恢復購買」的按鈕，則說明目前會員功能是生效的。
