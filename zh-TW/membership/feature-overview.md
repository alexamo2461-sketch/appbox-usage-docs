# 會員功能說明

> 相關內容：[購買相關說明](/zh-TW/membership/purchase)

這款產品會持續被認真對待，而你的支持，是我繼續投入時間和精力的理由。

AppBox 部分高級功能需要訂閱 AppBox Pro（以下簡稱為「會員」）才能使用。目前會員為一次性買斷制，一次買斷後可以永久使用，包括後續增加的更多高級功能。會員功能包括：

::: info
- **資料同步**：將資料上傳到 iCloud（需要用戶有可用的 iCloud 帳號）並實現資料的雲端同步功能。
- **分享應用集**：將應用集分享為圖片和二維碼連結功能，以及透過分享的連結/圖片導入到自己的軟體中。
- **記錄應用屬性**：支援記錄訂閱相關屬性（包括訂閱說明、價格、幣種、訂閱類型和日期）以及應用價格屬性。
- **新增自訂應用**：支援透過上傳圖示、填寫應用說明、來源等資訊來自訂應用資訊，以及自訂應用的導入和匯出功能。
- **批量導入**：支援多個連結長文字批量識別和導入應用到應用集中。
- **數據統計**：提供豐富的數據統計圖表，包括評分分布、訂閱支出、平台分布、地區分布、分類分布等。
- **應用標籤功能**：為應用添加自訂標籤，支援標籤管理、篩選和同步。
- **應用卡片檢視**：應用集詳情頁面增加卡片檢視：透過卡片展示應用評分、說明、標籤等更多欄位資訊。
- **數據導出**：支援將數據導出為 JSON 或 ZIP 格式檔案。
- **數據導入**：支援導入 AppBox 導出的數據以及 Apple 數據與隱私下載的應用商店記錄。
- **應用顯示配置**：自訂應用說明的顯示/隱藏和標籤顯示方式。
:::

上面開發中的功能代表目前暫時沒有，但是後續版本一定會有的功能。
