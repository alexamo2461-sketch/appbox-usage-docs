# 📖 AppBox 使用指南

AppBox 顧名思義「用來放應用的盒子」，是一個用來收藏和管理應用的工具軟體，可以通過創建「應用集」的方式將喜歡的應用記錄下來並提供應用集說明、應用說明、記錄自定義的屬性資訊等功能。
