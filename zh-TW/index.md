# 如何添加應用到收藏

目前 AppBox 提供了 3 種方式，每一種都適用於不同的導入場景：

- [在 AppBox 內直接添加](https://www.yuque.com/u291034/fz7nr2/rtasb6rnnqshtula)（支援搜索名稱、識別連結、添加自定義、批量添加）

- 從二維碼或連結導入「他人分享的應用集清單」
- [數據導入：AppBox導出的數據](https://www.yuque.com/u291034/fz7nr2/gmco3thciffi8gbe)
