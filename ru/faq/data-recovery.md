# Восстановление потерянных данных

:::: info
**Важные предварительные условия для восстановления данных:**

+ Приложение **не должно** быть удалено и переустановлено.
+ Данные должны присутствовать в **Настройки > Основные > Хранилище iPhone > AppBox > Документы и данные**.

Если у вас возникли проблемы, перейдите в **Настройки > Обратная связь**, чтобы связаться со мной в любое время.
::::

Нажмите **Настройки** → **Часто задаваемые вопросы** → **Потеря данных** → **Нажмите для восстановления** → откройте страницу **Результаты сканирования** → проверьте, сколько баз данных обнаружено. Если отображаются две базы данных, это означает, что старая база данных все еще существует. Нажмите кнопку **Объединить все доступные данные в основную базу данных** внизу, чтобы восстановить данные.
