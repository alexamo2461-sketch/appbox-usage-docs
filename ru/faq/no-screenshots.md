# У некоторых приложений нет скриншотов на странице сведений

На странице сведений о приложении у некоторых приложений не отображаются скриншоты. Это не проблема сети и не ошибка AppBox. Информация, возвращаемая API App Store, просто не содержит скриншотов для этих приложений. Проще говоря, Apple их не предоставляет, поэтому они не отображаются (я тоже не знаю, почему в приложении App Store скриншоты есть, а в API для разработчиков они не возвращаются).

Согласно моему тестированию, закономерность такова: для нишевых приложений или приложений с очень малым количеством загрузок скриншоты не возвращаются; для основных приложений скриншоты есть всегда.
