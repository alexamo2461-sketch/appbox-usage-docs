# Поиск

AppBox предоставляет глобальную функцию поиска для быстрого поиска сохранённых приложений и коллекций.

## Обзор

Нажмите вкладку **Поиск** в нижней панели навигации, чтобы открыть страницу поиска. Вы можете искать среди всех сохранённых приложений и коллекций. Поиск поддерживает совпадение по названию, описанию и другим ключевым словам.

## Порядок действий

1. Нажмите вкладку **Поиск** в нижней панели навигации
2. Введите ключевые слова в поле поиска
3. Результаты отображаются в реальном времени (приложения и коллекции)
4. Нажмите на результат, чтобы открыть страницу подробностей приложения или коллекции

## Область поиска

- **Название приложения**: Совпадение по имени приложения
- **Описание приложения**: Совпадение по пользовательским описаниям
- **Название коллекции**: Совпадение по названию коллекции

## Действия с результатами

В результатах поиска доступны следующие действия:

- **Приложение**: Нажмите, чтобы открыть страницу подробностей
- **Коллекция**: Нажмите, чтобы открыть страницу подробностей коллекции
- **Долгое нажатие на приложение**: Контекстное меню с опциями редактирования описания, копирования/перемещения, удаления
- **Долгое нажатие на коллекцию**: Контекстное меню с опциями редактирования и удаления

## Советы

- Поиск фильтрует в реальном времени — результаты появляются по мере ввода
- Используйте короткие ключевые слова для более широких результатов
- Если не можете найти приложение, попробуйте поискать ключевые слова в его описании
