# Копирование/перемещение приложения

На странице сведений о коллекции нажмите и удерживайте приложение, затем нажмите кнопку «Копировать/Переместить» во всплывающем меню, чтобы скопировать или переместить приложение в другую коллекцию. При копировании можно выбрать несколько целевых коллекций, при перемещении — только одну.

Вы также можете использовать множественный выбор для копирования/перемещения нескольких приложений одновременно: [Множественный выбор](/ru/app-management/multi-select)
