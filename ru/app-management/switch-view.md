# Переключение вида приложения

Страница сведений о коллекции предлагает 2 вида для отображения приложений: «Вид значков» и «Вид списка».

Кнопка переключения вида в меню действий в правом верхнем углу является «временной» кнопкой — вы можете свободно переключаться между двумя видами. Чтобы установить фиксированный вид по умолчанию, перейдите в Настройки → Общие → Вид приложения. Таким образом, при входе на страницу сведений о коллекции макет приложений всегда будет использовать выбранный вами вид.
