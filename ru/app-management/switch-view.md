# Переключение вида приложения

Страница сведений о коллекции предлагает 3 вида для отображения приложений, подходящих для различных сценариев использования.

## Три вида

| Вид | Описание |
| --- | --- |
| **Вид списка** | Отображает приложения в компактном формате списка, показывая значок, название и описание в каждой строке — идеально для быстрого просмотра при большом количестве приложений |
| **Вид значков** | Отображает значки приложений в виде сетки — визуально привлекательно и идеально для небольшого количества приложений или распознавания по значкам |
| **Карточный вид** | Отображает приложения в виде карточек с рейтингом, описанием, тегами и другим — идеально для детального управления приложениями |

## Быстрое переключение

На странице сведений о коллекции нажмите кнопку **Переключить вид** в меню действий в правом верхнем углу, чтобы быстро переключаться между тремя видами.

## Установить вид по умолчанию

Если вы хотите использовать один и тот же вид каждый раз при входе в коллекцию, вы можете зафиксировать его в настройках:

**Настройки → Общие → Настройка отображения → Страница коллекции**, выберите предпочитаемый вид по умолчанию.

> **Совет**: Кнопка переключения в правом верхнем углу — это «временное» переключение; настройка в конфигурации — это «постоянный» вид.

::: info
Карточный вид — функция подписки, требуется подписка AppBox Pro. Пользовательская сортировка поддерживает перетаскивание только в виде списка и виде значков; карточный вид и сеточные макеты отображают элементы в порядке пользовательской сортировки, но не поддерживают перетаскивание.
:::
