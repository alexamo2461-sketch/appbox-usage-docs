# Фильтрация в коллекции

На странице сведений о коллекции в AppBox доступны мощные функции фильтрации, которые помогут быстро найти нужные приложения.

## Обзор

На странице сведений о коллекции нажмите значок **Фильтр** в правом верхнем углу, чтобы открыть панель фильтрации и отфильтровать приложения в текущей коллекции по различным критериям.

## Критерии фильтрации

| Критерий | Описание |
| --- | --- |
| **Ключевое слово** | Поиск по ключевым словам в названии приложения, описании и заметках о подписке (до 50 символов) |
| **Рейтинг** | Фильтрация по вашей оценке, включая «Без рейтинга» и 1–5 звёзд |
| **Теги** | Фильтрация по тегам приложения с поддержкой множественного выбора |
| **Категория** | Фильтрация по основной категории App Store |
| **Источник** | Фильтрация по источнику приложения: приложения из App Store или пользовательские приложения |
| **Платформа** | Фильтрация по поддерживаемой платформе: iPhone, iPad, Mac |
| **Регион** | Фильтрация по региону App Store (отображаются только регионы, фактически присутствующие в текущей коллекции) |

## Шаги

1. Откройте коллекцию
2. Нажмите значок **Фильтр** в правом верхнем углу
3. Установите нужные критерии в панели фильтрации
4. Несколько критериев объединяются через «И» (все должны выполняться одновременно)
5. После настройки список приложений обновится автоматически

## Сброс фильтров

Нажмите кнопку **Сбросить** в панели фильтрации, чтобы сбросить все критерии и отобразить все приложения.

## Советы

- Фильтр по региону показывает только регионы, фактически присутствующие в текущей коллекции — пустых вариантов не будет
- Комбинируйте несколько критериев для точной фильтрации, например: «Тег: Продуктивность + Платформа: iPhone»
- Поиск по ключевым словам выполняется как по названиям приложений, так и по содержимому описаний
