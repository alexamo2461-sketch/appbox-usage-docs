# Как добавить приложения в избранное

В настоящее время AppBox предлагает 3 способа, каждый из которых подходит для разных сценариев импорта:

- [Прямое добавление в AppBox](https://www.yuque.com/u291034/fz7nr2/rtasb6rnnqshtula) (поиск по имени, распознавание ссылок, пользовательское добавление, пакетный импорт)

- Импорт «списка коллекций, опубликованных другими» по QR-коду или ссылке
