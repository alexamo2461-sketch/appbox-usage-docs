# Свойства приложения

Настройки свойств приложения управляют тем, какие поля атрибутов отображаются при редактировании описаний приложений.

**Доступ**: Настройки → Приложения → Свойства приложения

## Настраиваемые свойства

### Свойства подписки

При включении, при редактировании описания приложения отображаются поля, связанные с подпиской:

- Описание подписки
- Цена подписки
- Валюта
- Тип подписки (ежемесячная, ежегодная и т.д.)
- Дата начала/окончания подписки

### Свойства цены

При включении, при редактировании описания приложения отображаются поля, связанные с ценой, с поддержкой автоматического получения рыночной цены приложения из App Store.

::: info
Настройка свойств приложения — функция подписки, для изменения требуется подписка AppBox Pro. Пользователи без подписки имеют эти свойства включёнными по умолчанию.
:::
