# Настройка отображения

Страница настройки отображения позволяет настроить параметры отображения для страниц коллекций и страниц сведений о приложениях.

**Доступ**: Настройки → Общие → Настройка отображения

## Настройка страницы коллекции

### Режим просмотра приложений

Установите поведение по умолчанию при нажатии на приложение:

| Режим | Описание |
| --- | --- |
| **Открыть App Store** | Нажатие на значок приложения открывает страницу приложения в App Store |
| **Предпросмотр в AppBox** | Нажатие на значок приложения показывает предпросмотр сведений в AppBox |

### Вид приложений

Установите вид по умолчанию для страниц деталей коллекции (Список, Значки или Карточки).

## Настройка страницы сведений о приложении

### Порядок деталей

Настройте порядок отображения разделов на странице сведений о приложении:

- Скриншоты приложения
- Информация о приложении
- Дополнительная информация
- Описание приложения
- История обновлений

Просто перетащите для изменения порядка.

### Описание приложения

- **Скрывать при отсутствии**: Если у приложения нет описания, скрыть раздел описания (функция подписки)

### Теги приложения

- **Показывать теги**: Управляйте отображением тегов на странице сведений о приложении
- **Показывать значки**: Управляйте отображением значков тегов перед названиями тегов
- **Одна строка**: Управляйте расположением тегов в одну строку
