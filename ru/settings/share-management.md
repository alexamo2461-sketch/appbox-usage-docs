# Управление общим доступом

Страница управления общим доступом предназначена для управления вашими общими ссылками на коллекции.

**Доступ**: Настройки → Коллекции → Управление общим доступом

## Обзор

После создания общих ссылок через функцию «Поделиться коллекцией» вы можете управлять всеми активными общими ссылками в одном месте.

## Операции управления

### Просмотр общих ссылок

В списке отображаются все активные общие ссылки, включая название коллекции и статус общего доступа.

### Отключить отдельный общий доступ

Нажмите на общую ссылку, чтобы отключить её. После отключения другие пользователи не смогут импортировать коллекцию по этой ссылке.

### Отключить все общие доступы

Отключите все активные общие ссылки одним нажатием.

### Автоматическое отключение при удалении коллекции

При включении этой опции удаление коллекции автоматически отключает связанные с ней общие ссылки, предотвращая появление недействительных ссылок.

## Параметры общего доступа

Настройте содержимое, включаемое при общем доступе:

- **Включить описания приложений**: Включить пользовательские описания каждого приложения при общем доступе
- **Включить описание коллекции**: Включить текст описания коллекции при общем доступе
- **Включить информацию о подписке**: Включить атрибуты, связанные с подпиской, при общем доступе
- **Включить теги приложений**: Включить информацию о тегах приложений при общем доступе

::: info
Управление общим доступом — функция подписки, требуется подписка AppBox Pro.
:::
