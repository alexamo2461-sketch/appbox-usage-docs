# Теги

AppBox поддерживает добавление пользовательских тегов к приложениям для гибкой классификации и быстрого поиска.

## Обзор

Теги — это гибкий способ классификации. В отличие от коллекций, одно приложение может иметь несколько тегов, а один и тот же тег можно применить к нескольким приложениям. С помощью тегов можно быстро фильтровать и находить приложения в разных коллекциях.

## Добавление тегов

На странице редактирования описания приложения можно добавить один или несколько тегов.

**Порядок**: Открыть подробности приложения → Нажать редактировать описание → Ввести или выбрать теги в области тегов

## Управление тегами

В настройках можно управлять всеми тегами:

**Порядок**: Настройки → Приложения → Управление тегами

На странице управления тегами можно:

- Просмотреть все используемые теги
- Искать теги
- Переименовать теги
- Удалить ненужные теги

## Фильтрация по тегам

### Область тегов на главной странице

На главной странице внизу отображаются все используемые теги. Нажмите на тег, чтобы просмотреть все приложения с этим тегом.

### Фильтрация в коллекции

В панели фильтрации на странице подробностей коллекции можно фильтровать по тегам. Подробнее см. [Фильтрация в коллекции](/app-management/filtering).

## Настройки отображения тегов

**Порядок**: Настройки → Общие → Конфигурация отображения → Страница подробностей

Настройте отображение тегов на странице подробностей приложения:

- **Показать теги**: Включить/выключить отображение тегов
- **Показать значок**: Показать значок перед каждым тегом
- **В одну строку**: Отображать теги в одну строку

::: info
Данные тегов поддерживают синхронизацию и импорт/экспорт — ваши теги не будут потеряны при смене устройства.
:::
