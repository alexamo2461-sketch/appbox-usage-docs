# Статистика

AppBox предоставляет подробную статистику для полного понимания вашей коллекции приложений.

## Обзор

Нажмите вкладку **Статистика** в нижней панели навигации для просмотра различных графиков и результатов анализа.

::: info
Статистика — это Pro-функция, требующая подписки AppBox Pro. Без подписки отображается предварительный просмотр с примерами данных.
:::

## Ключевые показатели

Четыре основные карточки с показателями отображаются вверху страницы:

| Показатель | Описание |
| --- | --- |
| **Сохранённые приложения** | Общее количество уникальных приложений (нажмите для полного списка) |
| **Коллекции** | Общее количество созданных коллекций |
| **Расходы на подписки** | Общая стоимость всех подписочных приложений (нажмите для подробностей) |
| **Всего приложений** | Общее количество без дедупликации (нажмите для исходного списка) |

## Статистические графики

### Распределение оценок
Показывает распределение оценок, которые вы ставили приложениям.

### Данные о подписках
Отображает текущее количество подписок, месячные расходы по валютам, оценочные годовые затраты и другое.

### Покрытие описаниями
Показывает количество и процент приложений с описаниями.

### Тенденции добавления
Ежемесячная статистика сохранённых приложений для понимания ваших привычек.

### Распределение по платформам
Показывает распределение поддерживаемых платформ (iPhone, iPad, Mac).

### Распределение по регионам
Показывает распределение по странам/регионам App Store.

### Распределение по категориям
Показывает распределение по основным категориям App Store.

## Область статистики

По умолчанию учитываются все коллекции. Вы можете настроить область:

1. Нажмите кнопку **Область** в правом верхнем углу страницы
2. Выберите **Все коллекции** или конкретные коллекции
3. Включите **Дедупликацию между коллекциями** для объединения дубликатов

## Настройка статистики

Настройте порядок отображения и видимость карточек:

1. Нажмите кнопку **Настроить** в правом верхнем углу
2. Перетащите для изменения порядка карточек
3. Нажмите на значок глаза для переключения видимости
4. Нажмите **Сбросить** для восстановления стандартной раскладки

## Подробности подписок

Нажмите «Расходы на подписки» или «Данные о подписках» для перехода на детальную страницу:

- Статистика месячных расходов
- Статистика годовых расходов
- Тренды общих расходов
- Разбивка подписок
- Графики распределения затрат
- Анализ сроков и продлений
