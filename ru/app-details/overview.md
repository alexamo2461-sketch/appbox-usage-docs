# Страница сведений о приложении

Страница сведений о приложении включает следующее содержимое:

- **Основная информация**: Значок приложения, название приложения и кнопка перехода
- **Заметки о приложении**: Отображает вашу пользовательскую оценку, заметки и атрибуты, связанные с подпиской.
- **Скриншоты**: Показывает скриншоты приложения, может отображать несколько платформ одновременно.
- **Информация о приложении**: Последняя информация о приложении, полученная из App Store, включая ID приложения, разработчика, цену, размер и т.д.
- **Описание**: Описание приложения, полученное из App Store.
- **История обновлений**: Последние заметки об обновлении, полученные из App Store.
- **Дополнительная информация**: Регион App Store приложения, время добавления в коллекцию и ссылка на источник.
