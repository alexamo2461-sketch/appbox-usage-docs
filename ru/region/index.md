# Как использовать регионы приложений
**Регион приложения** — это **страна или регион App Store**, который AppBox использует при **получении информации о приложении, такой как описание, иконка и другие данные**.

Эта функция позволяет:
**находить приложения, доступные в определённом регионе**, **отображать названия и иконки в соответствии с выбранным регионом**, а также **выполнять массовые запросы информации по регионам**.

:::info
**Примечание:** Доступность приложений, переводы названий и другая информация полностью зависят от App Store выбранного региона. Если приложение недоступно в конкретном регионе, это результат, возвращённый магазином, а не потеря ваших коллекций.
:::

## Когда эта функция может пригодиться
+ **Приложение не находится по названию** → Попробуйте сменить регион и выполнить поиск снова (некоторые приложения доступны только в определённых магазинах).  
+ **Сложно отличить приложения с одинаковыми названиями** → Используйте регионы для различия отображаемой информации.  
+ **Ссылка уже содержит регион** → AppBox будет **в первую очередь определять регион по ссылке** (см. ниже).  
+ **Списки приложений из разных стран** → Используйте **Фильтр · Регион** для просмотра или сначала выполните **массовое изменение региона**, а затем обновите данные.

## Управление регионами приложений в «Настройках»
**Настройки → Приложения → Регион приложения**

<!-- Это изображение, OCR-содержимое: -->
![](../../assets/region/region-settings.png)

Здесь находится **«Список регионов для запросов»** — активированные страны и регионы. Порядок **сверху вниз** определяет приоритет (верхние регионы проверяются первыми; этот порядок также используется при попытке поиска по нескольким регионам).

| Действие | Описание |
| --- | --- |
| **Добавить регион** | Нажмите «Добавить регион» и выберите страну или регион из списка. Можно добавить **до 10 регионов**; при достижении лимита появится уведомление. |
| **Удалить** | **Смахните строку влево**, чтобы удалить её. Необходимо оставить **минимум 1 регион**. |
| **Сортировка** | Нажмите **«Сортировка»** в правом верхнем углу, измените порядок элементов и подтвердите сохранение. Обычно **верхний регион** используется как регион по умолчанию (особенно если регион невозможно определить по ссылке). |
| **Пустой список** | Страница предложит добавить регионы через «Добавить регион». |

### Отличие от списка «Выбрать регион»
Во всплывающем окне **«Выбрать регион»** в разделах **Добавить приложение** или **Информация о приложении** обычно отображаются только регионы, уже активированные в настройках (то есть регионы из «Списка регионов для запросов»). Это упрощает быстрое переключение.

Функция **Добавить регион** в настройках, напротив, позволяет выбирать регионы из **полного списка регионов**, чтобы расширить список активированных.

## Ссылки App Store и регионы: правила распознавания
Когда вы вставляете или делитесь **ссылкой на приложение App Store**, AppBox старается автоматически определить **страну или регион** из самой ссылки. Например:

+ Если ссылка содержит что-то вроде `…/cn/app/…` или `…/us/app/…` — обычно это **двухбуквенный код** (как правило, в нижнем регистре) — система распознаёт его как соответствующий регион (например, cn → материковый Китай, us → США).

| Ситуация | Поведение системы |
| --- | --- |
| **Регион можно определить из ссылки** | В разделе **Добавить приложение → Ссылка App** строка «Страна или регион» обычно **не отображается**, поскольку регион уже указан в ссылке. Изменение порядка регионов в настройках **не влияет** на эту логику приоритета ссылки. |
| **Регион невозможно определить из ссылки** | Появится поле **«Страна или регион»** (например, «Материковый Китай (cn)»), при этом будет использоваться регион, выбранный в настройках. |
| **Одновременная вставка нескольких ссылок** | Если весь текст **не может** быть распознан как одна ссылка с указанием региона, поле «Страна или регион» обычно **отображается**. Все ссылки будут использовать выбранную в этот раз региональную стратегию. |

**Проще говоря:** если ссылка явно указывает регион, AppBox использует регион из ссылки. В противном случае используется регион, выбранный в настройках.

## Просмотр и изменение региона на странице приложения
<!-- Это изображение, OCR-содержимое: -->
![](../../assets/region/app-detail-region.png)

### Просмотр региона
На странице приложения откройте раздел **«Дополнительная информация»**. В строке **«Регион»** отображается название магазина, соответствующее текущему коду региона для сохранённого приложения.

### Изменение региона (только для приложений из App Store)
1. В меню **«⋯»** в правом верхнем углу страницы приложения выберите **«Изменить регион»**.  
2. В разделе **«Выбрать регион»** выберите нужный регион и подтвердите действие.  
3. AppBox повторно выполнит запрос к App Store, чтобы проверить наличие приложения в новом регионе.  
    - **Успешно:** название, иконка и другие данные будут обновлены (если они доступны в магазине), после чего появится сообщение **«Изменения успешно применены»**.  
    - **Ошибка:** например, если отображается сообщение **«Это приложение недоступно в выбранном регионе App Store»**, система автоматически вернёт предыдущий регион, чтобы избежать некорректного состояния.

> Для **пользовательских приложений** функция **«Изменить регион»** в настоящее время не отображается, так как информация о них заполняется вручную.
>

## Управление регионами внутри коллекции приложений
<!-- Это изображение, OCR-содержимое: -->
![](../../assets/region/collection-region.png)

### Массовое изменение регионов
Если в одной **коллекции приложений** выбрано несколько приложений из App Store, вы можете одновременно переключить их на один регион и обновить отображаемую информацию.

#### Шаги
1. Откройте **коллекцию приложений**.  
2. Нажмите **«⋯»** в правом верхнем углу → **«Выбрать приложения»**.  
3. Выберите несколько приложений.  
4. Нажмите **«Регион»** (иконка глобуса) на нижней панели инструментов.  
5. В разделе **«Выбрать регион»** укажите нужный регион; AppBox начнёт поочерёдно получать данные из магазина для каждого приложения.  
6. После завершения можно открыть страницу **«Результаты массового изменения региона»**, где отдельно отображаются успешно изменённые, пропущенные и неудачные элементы.

### Фильтрация (показ только определённых регионов)
На странице коллекции нажмите значок **Фильтр** в правом верхнем углу → поле **«Регион»** → выберите один или несколько регионов, чтобы отображались только соответствующие приложения. Доступны только те регионы, которые фактически присутствуют в данной коллекции.

## «Apple Data» при импорте данных

В разделе **Настройки → Импорт данных → Apple Data** перед началом импорта можно выбрать от 1 до 10 регионов. Информация о приложениях будет автоматически запрашиваться в соответствии с порядком списка, пока не будет найдено совпадение или не будут исчерпаны все стратегии.

Обратите внимание: выбор слишком большого количества регионов значительно замедляет импорт. Обычно рекомендуется выбирать только 1–3 региона.
