## V1.5

> Дата: 2025-12-26

**0. Важные примечания:**

- По сравнению с V1.4 в этой версии обновлена модель данных, поэтому требуется операция обновления данных. Появится соответствующее уведомление — просто подтвердите для продолжения
- После обновления вы можете проверить статус в Настройки → Обновление данных → История обновлений. Неудачные данные удалите вручную и добавьте заново
- Пользователи, которые еще не восстановили старые данные, могут использовать инструменты разработчика для попытки восстановления. Инструкции находятся в Настройки → Руководство пользователя → Часто задаваемые вопросы

**1. Изменения:**

- Поддержка импорта ссылок для эксклюзивного программного обеспечения Mac
- Ограничение на количество символов в описании приложения увеличено с 200 до 2000
- Изменен макет главной страницы, добавлена нижняя панель действий; сортировка и переключение видов перемещены в меню действий в правом верхнем углу
- Информация о подписке теперь синхронизируется при копировании/перемещении приложений

**2. Новые функции:**

- Сортировка коллекций: по имени (A-Z и Z-A) или по дате создания (сначала новые и сначала старые)
- Пользовательский импорт: пользователи могут вводить значок, название, источник и другую информацию
- Поиск и добавление приложений непосредственно по имени в AppBox
- На странице сведений о приложении добавлен раздел «Дополнительная информация» с указанием времени импорта, региона и ссылки на источник
- Экспорт данных теперь выполняется в виде полного сжатого пакета, содержащего файлы значков приложений и JSON-файл
- На странице сведений отображается App ID приложения; добавлены кнопки перевода в разделах описания и истории обновлений
- Выбор региона приложения: поддержка выбора региона при добавлении новых приложений, поддержка сортировки регионов (Настройки → Регионы приложений)
- На странице результатов поиска добавлены меню длительного нажатия (редактировать, копировать/перемещать, удалять) для коллекций и приложений
- Предоставлены полные шаблоны и описания полей, поддержка массового импорта через файлы шаблонов
- Кэширование значков: загрузка значков приложений локально для офлайн-отображения
- Поддержка редактирования описаний приложений во время импорта (поддерживается как в модуле добавления на главной странице, так и на странице сведений о коллекции)
- Добавлены инструменты разработчика для восстановления старых версий базы данных

**3. Прочее:**

- Оптимизация всей логики импорта приложений: AppBox извлекает числовые ID (например, `id1234567890`) из ссылок и запрашивает информацию о приложении в App Store. Стратегия выбора региона: приоритет отдается явному коду региона в ссылке (например, `/cn/`, `/us/`); если код региона отсутствует, приложение проходит по списку регионов в Настройки → Регионы приложений сверху вниз. «Универсальный» означает не конкретную страну/регион, а автоматическое определение сервером Apple на основе среды запроса (в основном США). Подробнее см. Настройки → Руководство пользователя → Часто задаваемые вопросы → Правила распознавания ссылок на приложения и использование функции регионов
