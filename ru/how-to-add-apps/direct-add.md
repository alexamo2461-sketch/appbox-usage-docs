# Прямое добавление в AppBox

Вы можете открыть интерфейс «Добавить приложение» через следующие пункты:

+ На главной странице **Наборов приложений**: используйте кнопку **Добавить приложение** в правом нижнем углу; если она не отображается, нажмите **«Добавить приложение»** в меню в правом верхнем углу.
+ На странице **Детали набора приложений**: нажмите **Добавить приложение** (если вы просто организуете текущий список, целевой набор приложений автоматически укажет на текущий).

![Вход Добавить приложение](/assets/how-to-add-apps/entry-screenshot.png)

После открытия вы можете переключать верхние вкладки по мере необходимости: **Название приложения**, **Ссылка на приложение**, **Пользовательский**. В области предварительного просмотра нажмите «Редактировать описание», чтобы открыть страницу редактирования описания для быстрой записи оценок, описаний и других атрибутов.

![Интерфейс Добавить приложение](/assets/how-to-add-apps/add-app-interface.png)

# Поиск и добавление по названию (Поиск в магазине внутри приложения)

## Описание функции
При использовании метода **Название приложения** введите ключевые слова для поиска и выбора приложений из App Store, чтобы добавить их в коллекцию.

![Поиск по названию](/assets/how-to-add-apps/search-by-name.png)

## Сценарии использования
+ У вас есть только название приложения, но нет ссылки.
+ Вы хотите сравнить приложения с одинаковыми названиями и проверить значок перед добавлением.

## Шаги
1. Откройте **Добавить приложение** и выберите **Название приложения**.
2. Введите название или ключевое слово в поле ввода и нажмите **Поиск в App Store**.
3. В **Результатах поиска** вы можете переключить **Регион** и выполнить поиск снова (при необходимости).
4. Нажмите **Добавить** на конкретной строке, чтобы выбрать её; возможен множественный выбор.
5. После выбора нажмите «Подтвердить» в правом верхнем углу, чтобы вернуться на предыдущую страницу.
6. Выберите **Целевой набор приложений**; в области предварительного просмотра вы можете редактировать описания или теги.
7. Нажмите **Добавить** или **Продолжить добавление** внизу.

## Примечания
+ Результаты поиска поступают из App Store выбранного региона; списки могут различаться в зависимости от региона.
+ В области предварительного просмотра отображаются выбранные приложения; проверьте перед сохранением.

::: info
Поддерживает распознавание текста из скриншотов или изображений. Он заполняет возможные **Названия приложений** в поле поиска. После завершения распознавания вы можете подтвердить или изменить распознанный текст на странице результатов.
:::

## Меры предосторожности
> **Примечание**: Если приложение не найдено, это часто связано с текущим выбранным **Регионом App Store**. Вы можете изменить регион на этой странице или в настройках и выполнить поиск снова.

# Добавление через ввод и распознавание ссылок App Store

## Описание функции
Вставив ссылку на страницу приложения в App Store, AppBox получает информацию, такую как значок и название, и добавляет приложение в выбранный набор.

![Добавить по ссылке](/assets/how-to-add-apps/add-by-link.png)

## Сценарии использования
+ Вы видите серию ссылок App Store в сообществе, на веб-странице или в заметке и хотите немедленно их сохранить.
+ Вы уже скопировали ссылку и не хотите снова искать название в магазине.

## Шаги
1. Откройте страницу **Добавить приложение**.
2. Нажмите **Ссылка на приложение** в верхнем сегменте.
3. Вставьте ссылку в поле ввода (обычно после вставки начинается **автоматическое распознавание**) или нажмите **Распознать из буфера обмена**, чтобы использовать весь текст из буфера обмена.
4. Если место хранения ещё не выбрано, выберите один или несколько наборов в **Целевой набор приложений**.
5. Для запроса к конкретному региональному магазину настройте **Регион** на этой странице (согласуется с «Настройки → Приложение → Регион App Store»).
6. Подтвердите правильность записи в **Предварительном просмотре приложения**; здесь вы можете редактировать описания или выбирать теги.
7. Нажмите **Добавить** внизу, чтобы сохранить и закрыть; или нажмите **Продолжить добавление**, чтобы остаться на этой странице для дальнейших операций.

::: info
Поддерживает **несколько ссылок**: в одном поле ввода используйте **переводы строк** или **английские точки с запятой** `;` для разделения нескольких ссылок App Store. При изменении содержимого автоматически предпринимается попытка распознавания; вы также можете использовать **Распознать из буфера обмена**.
:::

## Примечания
+ После успешного распознавания появляется список предварительного просмотра; в случае сбоя страница предоставляет краткую причину, позволяя проверить, полная ли ссылка.
+ Если ссылка содержит информацию о регионе, она обычно распознается в соответствии с этим регионом; вы также можете вручную переключить регион и повторить попытку. О правилах распознавания ссылок: [Регионы приложений и распознавание ссылок](/ru/region/)

## Рекомендации
+ Сначала помещайте элементы в набор приложений по умолчанию, а затем организуйте их в классифицированные наборы позже, чтобы сократить повторяющиеся операции.
+ При массовом сборе «списков приложений» из статей вы можете вставить несколько ссылок сразу, а затем вместе подтвердить предварительный просмотр.

# Пользовательское добавление приложения (Ручной ввод информации)

## Описание функции
Вручную заполните информацию, такую как название приложения, значок и ссылка на источник. Это используется для записей, которые временно не найдены в магазине, или для тех, где вы хотите полностью контролировать отображение.

![Пользовательское добавление](/assets/how-to-add-apps/custom-add.png)

## Сценарии использования
+ Приложения, которые ещё не выпущены, уже удалены или распространяются только через определённые каналы, но вы всё равно хотите сохранить запись в списке.
+ Вам нужно сохранить пользовательский значок и заметки для приложения/программного обеспечения не из App Store.

## Шаги
1. Откройте **Добавить приложение** и выберите **Пользовательский**.
2. Нажмите на область значка и следуйте подсказкам, чтобы получить значок из **Фотоплёнки**, **Файлов** или через **Ссылку на изображение** (`http`/`https`, рекомендуется PNG/JPG).
3. Заполните **Название приложения** (обязательно).
4. При необходимости заполните **Ссылку на источник** (веб-страница или адрес инструкции).
5. Выберите **Целевой набор приложений**.
6. В области предварительного просмотра приложения отредактируйте связанную информацию, такую как описание, оценка, подписка и теги.
7. Нажмите **Добавить** внизу, чтобы сохранить.

## Примечания
+ Рекомендуется указывать ссылку на источник как официальный сайт или доверенную страницу для более удобной последующей проверки.
+ Отображение пользовательских записей зависит от предоставленного вами содержимого; оно не будет автоматически синхронизироваться со страницами сведений магазина, как это делают приложения из магазина.
+ Если в приложении отображаются ограничения по подписке для этой функции, следуйте инструкциям на страницу описания подписки, если она не разблокирована.

## Меры предосторожности
+ Пользовательские записи отличаются от записей, добавленных из магазина, по методам обновления; приложения из магазина можно обновить на странице сведений, в то время как пользовательские записи необходимо изменять вручную.
+ Старайтесь выбирать квадратные значки с высоким разрешением; избегайте увеличения маленьких скриншотов.

# Распознавание названия приложения по скриншоту

## Описание функции
Распознайте текст из скриншотов или изображений, заполните возможные **Названия приложений** в поле поиска, затем завершите добавление, комбинируя с [Поиск и добавление по названию (Поиск в магазине внутри приложения)](#поиск-и-добавление-по-названию-поиск-в-магазине-внутри-приложения).

![Распознавание по скриншоту 1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## Сценарии использования
+ У вас есть только скриншот приложения без копируемой ссылки. Вы хотите быстро извлечь заголовок из изображения в качестве ключевого слова для поиска.

![Распознавание по скриншоту 2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## Шаги
1. Откройте **Добавить приложение** → **Название приложения**.
2. Справа от поля ввода названия нажмите **Распознать приложение на изображении** (значок в виде видоискателя).
3. Выберите **Выбрать из фото** или **Выбрать из файлов**.
4. После завершения распознавания вы можете подтвердить или изменить распознанный текст на странице результатов перед подтверждением поиска.

## Примечания
+ Цель распознавания — сократить ввод текста. Он распознает весь текст на скриншоте; в большинстве случаев требуется повторное подтверждение пользователем перед поиском.
