# 데이터 손실 복구/찾기

:::: info
데이터 복구의 전제 조건은 앱이 **제거 후 재설치되지 않았어야 하며**, 휴대폰의 **설정 > 일반 > iPhone 저장 공간 > AppBox > 문서 및 데이터**에 데이터가 남아 있어야 합니다. 문제가 있으면 언제든지 **설정 > 피드백**을 통해 연락해 주세요.
::::

【설정】→【자주 묻는 질문】→【데이터 손실】→【탭하여 복구】를 탭 → 스캔 결과 페이지 열기 → 현재 감지된 데이터베이스 수를 확인합니다. 두 개의 데이터베이스가 표시되면 이전 데이터베이스가 존재하는 것입니다. 하단의 【사용 가능한 모든 데이터를 현재 메인 데이터베이스에 병합】 버튼을 탭하여 데이터를 복원하세요.
