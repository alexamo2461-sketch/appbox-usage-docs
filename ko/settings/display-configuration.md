# 표시 설정

표시 설정 페이지에서는 컬렉션 페이지와 앱 상세 페이지의 표시 옵션을 사용자 정의할 수 있습니다.

**접근 방법**: 설정 → 일반 → 표시 설정

## 컬렉션 페이지 설정

### 앱 보기 모드

앱을 탭할 때의 기본 동작을 설정합니다:

| 모드 | 설명 |
| --- | --- |
| **App Store 열기** | 앱 아이콘을 탭하면 App Store 앱 페이지로 바로 이동 |
| **AppBox에서 미리보기** | 앱 아이콘을 탭하면 AppBox 내에서 앱 상세 미리보기 표시 |

### 앱 보기

컬렉션 상세 페이지의 기본 보기를 설정합니다(목록, 아이콘 또는 카드).

## 앱 상세 페이지 설정

### 상세 순서

앱 상세 페이지의 각 섹션 표시 순서를 사용자 정의합니다:

- 앱 스크린샷
- 앱 정보
- 추가 정보
- 앱 소개
- 업데이트 기록

드래그하여 순서를 조정하면 됩니다.

### 앱 설명

- **설명 없을 때 숨기기**: 앱에 설명이 추가되지 않은 경우 설명 섹션을 숨깁니다(멤버십 기능)

### 앱 태그

- **태그 표시**: 앱 상세 페이지에서 태그 표시 여부를 제어
- **아이콘 표시**: 태그 이름 앞에 태그 아이콘 표시 여부를 제어
- **한 줄 표시**: 태그를 한 줄로 배치할지 여부를 제어
