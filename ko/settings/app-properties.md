# 앱 속성

앱 속성 설정은 앱 설명을 편집할 때 표시되는 속성 필드를 제어합니다.

**접근 방법**: 설정 → 앱 → 앱 속성

## 구성 가능한 속성

### 구독 속성

활성화하면 앱 설명 편집 시 구독 관련 입력 항목이 표시됩니다:

- 구독 설명
- 구독 가격
- 통화
- 구독 유형(월간, 연간 등)
- 구독 시작/종료일

### 가격 속성

활성화하면 앱 설명 편집 시 가격 관련 입력 항목이 표시되며, App Store에서 앱 시장 가격을 자동으로 가져올 수 있습니다.

::: info
앱 속성 구성은 멤버십 기능으로, 수정하려면 AppBox Pro 구독이 필요합니다. 비멤버십 사용자는 기본적으로 이러한 속성이 활성화되어 있습니다.
:::
