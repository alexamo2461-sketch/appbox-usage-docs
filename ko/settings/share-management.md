# 공유 관리

공유 관리 페이지는 공유한 컬렉션 링크를 관리하는 데 사용됩니다.

**접근 방법**: 설정 → 컬렉션 → 공유 관리

## 개요

"컬렉션 공유" 기능을 통해 공유 링크를 생성한 후, 여기에서 모든 활성 공유 링크를 한 곳에서 관리할 수 있습니다.

## 관리 작업

### 공유 링크 보기

목록에 현재 활성 상태인 모든 공유 링크가 표시되며, 컬렉션 이름과 공유 상태가 포함됩니다.

### 개별 공유 비활성화

공유 링크를 탭하여 해당 공유를 비활성화할 수 있습니다. 비활성화 후 다른 사람은 해당 링크를 통해 컬렉션을 가져올 수 없습니다.

### 모든 공유 비활성화

한 번의 탭으로 모든 활성 공유 링크를 비활성화합니다.

### 컬렉션 삭제 시 자동 비활성화

이 옵션을 활성화하면 컬렉션을 삭제할 때 연관된 공유 링크가 자동으로 비활성화되어 유효하지 않은 링크가 남는 것을 방지합니다.

## 공유 옵션

공유 시 포함될 내용을 설정합니다:

- **앱 설명 포함**: 공유 시 각 앱의 사용자 정의 설명을 포함
- **컬렉션 설명 포함**: 공유 시 컬렉션 설명 텍스트를 포함
- **구독 정보 포함**: 공유 시 구독 관련 속성을 포함
- **앱 태그 포함**: 공유 시 앱 태그 정보를 포함

::: info
공유 관리는 멤버십 기능으로, AppBox Pro 구독이 필요합니다.
:::
