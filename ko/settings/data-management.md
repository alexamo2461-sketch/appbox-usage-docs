# 데이터 관리

데이터 관리 페이지에서는 앱 정보 새로고침, 아이콘 다운로드, 캐시 정리, 데이터 초기화 등의 기능을 제공합니다.

**접근 방법**: 설정 → 데이터 → 데이터 관리

## 오프라인 아이콘 다운로드

모든 앱 아이콘을 로컬 기기에 다운로드하여 네트워크 연결이 없는 환경에서도 앱 아이콘이 정상적으로 표시됩니다.

네트워크 환경이 좋은 상태에서 이 작업을 수행하는 것이 좋습니다. 앱 수에 따라 다운로드 과정에 시간이 걸릴 수 있습니다.

## 앱 정보 새로고침

App Store에서 앱의 이름, 아이콘, 스크린샷, 소개, 가격 등 최신 정보를 다시 가져옵니다.

새로고침 대기 중인 앱 목록이 표시되며, 일괄 새로고침을 지원합니다. 새로고침 과정은 백그라운드에서 실행되어 정상적인 사용에 영향을 주지 않습니다.

> **팁**: 새로고침 작업은 직접 편집한 평점, 설명, 태그 내용을 덮어쓰지 않습니다.

## 캐시 정리

### 잘못된 아이콘 캐시 정리

존재하지 않거나 잘못된 아이콘 캐시 파일을 삭제하여 저장 공간을 확보합니다. 아이콘 표시 이상이나 캐시가 많은 공간을 차지할 때 유용합니다.

### 잘못된 앱 데이터 정리

고립된 앱 데이터 기록을 정리합니다. 데이터 이상 발생이나 공간 확보가 필요할 때 유용합니다.

## 데이터 초기화

> **주의**: 다음 작업은 되돌릴 수 없습니다. 신중하게 진행해 주세요.

**로컬 데이터 삭제**: 기기에서 모든 AppBox 데이터를 삭제합니다(컬렉션, 앱 정보, 평점, 설명 등 포함). 실행 전에 데이터가 백업되었거나 iCloud에 동기화되었는지 반드시 확인해 주세요.
