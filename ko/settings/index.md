# ⚙️ 설정

AppBox의 설정 페이지에는 사용 환경 개인화와 데이터 관리를 위한 다양한 구성 옵션이 있습니다.

## 일반

- [테마 설정 (색상 및 모드)](/ko/settings/theme): 테마 모드와 테마 색상 설정
- **언어**: 시스템 설정으로 이동하여 앱 언어 변경
- [표시 설정](/ko/settings/display-configuration): 컬렉션 페이지와 앱 상세 페이지의 표시 옵션 구성

## 컬렉션

- [컬렉션 관리](/ko/collection-management/): 모든 컬렉션 보기 및 관리, 다중 선택 삭제 지원
- [빈 컬렉션 감지](/ko/collection-management/empty-detect): 빈 컬렉션을 자동으로 감지하고 삭제 안내
- [공유 관리](/ko/settings/share-management): 공유된 컬렉션 링크 관리

## 앱

- **전체 앱**: 수집한 모든 앱 보기(중복 제거), App Store 이동 지원
- [앱 지역](/ko/region/): App Store 쿼리 지역 목록 관리
- [태그 관리](/ko/tags/): 모든 앱 태그 관리
- [앱 속성](/ko/settings/app-properties): 구독 속성 및 가격 속성 표시 구성

## 데이터

- [데이터 동기화](/ko/sync/): iCloud 데이터 동기화
- [데이터 가져오기](/ko/backup-restore/data-import): AppBox 데이터 또는 Apple 데이터 가져오기
- [데이터 내보내기](/ko/backup-restore/export): 데이터를 JSON 또는 ZIP 파일로 내보내기
- [데이터 관리](/ko/settings/data-management): 앱 정보 새로고침, 아이콘 다운로드, 캐시 정리, 데이터 초기화

## 기타

- **사용 가이드**: 온라인 도움말 문서 열기
- **자주 묻는 질문**: 앱 내 FAQ 페이지
- **피드백**: 이메일로 피드백 보내기
- **AppBox 평가**: App Store에서 평가하기
- **AppBox 정보**: 앱 버전 및 개발자 정보 보기
