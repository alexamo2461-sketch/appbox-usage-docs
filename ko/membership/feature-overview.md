# 멤버십 기능 설명

> 관련 내용: [구매 관련 설명](/ko/membership/purchase)

이 제품은 계속해서 진지하게 개발될 것이며, 여러분의 지원이 제가 시간과 노력을 계속 투자하는 이유입니다.

AppBox의 일부 고급 기능은 AppBox Pro(이하 "멤버십")를 구독해야 사용할 수 있습니다. 현재 멤버십은 일회성 구매제로, 한 번 구매하면 영구적으로 사용할 수 있으며 향후 추가되는 더 많은 고급 기능도 포함됩니다. 멤버십 기능은 다음과 같습니다:

::: info
- **데이터 동기화**: 데이터를 iCloud에 업로드하고(유효한 iCloud 계정 필요) 클라우드 동기화 기능을 제공합니다.
- **앱 컬렉션 공유**: 앱 컬렉션을 이미지 및 QR 코드 링크로 공유하고, 공유된 링크/이미지를 통해 자신의 앱으로 가져오는 기능.
- **앱 속성 기록**: 구독 관련 속성(구독 설명, 가격, 통화, 구독 유형 및 날짜) 및 앱 가격 속성 기록을 지원합니다.
- **사용자 정의 앱 추가**: 아이콘 업로드, 앱 설명, 출처 등의 정보를 입력하여 사용자 정의 앱 정보를 만들고, 사용자 정의 앱의 가져오기 및 내보내기 기능을 지원합니다.
- **일괄 가져오기**: 여러 링크가 포함된 긴 텍스트에서 앱을 일괄 인식하여 앱 컬렉션으로 가져오기를 지원합니다.
- **데이터 통계**: 평점 분포, 구독 지출, 플랫폼 분포, 지역 분포, 카테고리 분포 등 풍부한 데이터 통계 차트를 제공합니다.
- **앱 태그 기능**: 앱에 사용자 정의 태그를 추가하고, 태그 관리, 필터링 및 동기화를 지원합니다.
- **카드 보기**: 앱 컬렉션 상세 페이지에 카드 보기 추가 — 카드를 통해 앱 평점, 설명, 태그 등 더 많은 필드 정보를 표시합니다.
- **데이터 내보내기**: 데이터를 JSON 또는 ZIP 형식 파일로 내보내는 것을 지원합니다.
- **데이터 가져오기**: AppBox에서 내보낸 데이터와 Apple의 데이터 및 개인 정보 다운로드의 App Store 기록을 가져오는 것을 지원합니다.
- **앱 표시 설정**: 앱 설명의 표시/숨김 및 태그 표시 방식을 사용자 정의합니다.
:::

위에 "개발 중"으로 표시된 기능은 현재는 없지만 향후 버전에 반드시 추가될 기능입니다.

멤버십 가격은 기능 업데이트에 따라 지속적으로 인상될 수 있습니다(특별 프로모션 제외). 소프트웨어가 마음에 드신다면 조기에 저렴하게 구매하시는 것을 추천합니다 🥰~
