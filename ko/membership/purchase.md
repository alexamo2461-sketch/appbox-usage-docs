# 구매 관련 설명

> 관련 링크: [멤버십 기능 설명](/ko/membership/feature-overview)

## 구매须知

- 기능이 지속적으로 개선됨에 따라 가격이 조정될 수 있습니다. 개발자는 구매 사용자를 구독으로 전환하지 않을 것을 약속하며, 구매 후 추가 비용이 발생하지 않습니다.
- 멤버십 기간 동안 모든 기능을 사용할 수 있습니다. 구매 후 환불은 지원되지 않으므로 신중히 고려하신 후 구매해 주세요.
- Apple ID 계정 간의 구매/구독 이전은 지원되지 않습니다. 또한 여러 App ID 간의 멤버십 공유도 불가능합니다.

## 구매 복원

이미 멤버십을 구매했지만 사용 중이거나 재설치 후 멤버십 기능을 사용할 수 없는 경우, 설정 - AppBox Pro 페이지로 이동하여 '구매 복원' 버튼을 수동으로 탭하면 이전 멤버십이 복원됩니다(구매 시 사용한 Apple ID와 동일해야 합니다). AppBox Pro 페이지에 '구매 복원' 버튼이 없다면 현재 멤버십 기능이 정상적으로 활성화되어 있는 것입니다.
