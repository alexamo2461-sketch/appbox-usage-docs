# 검색 기능

AppBox는 저장한 앱과 컬렉션을 빠르게 찾을 수 있는 전역 검색 기능을 제공합니다.

## 개요

하단 내비게이션 바의 **검색** 탭을 눌러 검색 페이지로 이동합니다. 저장한 모든 앱과 컬렉션을 검색할 수 있으며, 이름, 설명 등 키워드 매칭을 지원합니다.

## 사용 방법

1. 하단 내비게이션 바의 **검색** 탭을 누릅니다
2. 검색창에 키워드를 입력합니다
3. 검색 결과가 실시간으로 표시됩니다 (앱 및 컬렉션 포함)
4. 검색 결과를 눌러 앱 상세 또는 컬렉션 상세 페이지로 이동합니다

## 검색 범위

- **앱 이름**: 앱의 이름과 일치
- **앱 설명**: 앱에 추가한 사용자 정의 설명과 일치
- **컬렉션 이름**: 컬렉션의 이름과 일치

## 검색 결과 작업

검색 결과에서 다음 작업을 수행할 수 있습니다:

- **앱**: 눌러서 앱 상세 페이지 열기
- **컬렉션**: 눌러서 컬렉션 상세 페이지 열기
- **앱 길게 누르기**: 설명 편집, 복사/이동, 삭제 등 메뉴 표시
- **컬렉션 길게 누르기**: 편집, 삭제 등 메뉴 표시

## 팁

- 검색은 실시간으로 필터링됩니다
- 더 넓은 결과를 얻으려면 짧은 키워드를 사용하세요
- 앱을 찾을 수 없으면 설명의 키워드를 검색해 보세요
