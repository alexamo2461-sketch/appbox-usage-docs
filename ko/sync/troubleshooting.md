# 동기화를 사용할 수 없나요?

데이터 동기화 기능을 사용하려면 현재 기기에서 iCloud에 로그인하고 iCloud 동기화를 활성화해야 합니다. 먼저 AppBox의 **데이터 동기화** 페이지에서 iCloud 상태가 **사용 가능**으로 표시되는지 확인하세요.

![iCloud 상태 확인](/sync-icloud-status-en.png)

**사용 불가**로 표시되거나 동기화가 작동하지 않는 경우, 다음 2가지 설정이 모두 **켜짐**으로 되어 있는지 확인하세요:

### 1. 설정 → [사용자 이름] → iCloud → 모두 보기 → iCloud를 사용하는 앱 → AppBox

![AppBox iCloud 설정](/sync-appbox-en.png)

### 2. 설정 → [사용자 이름] → iCloud → iCloud Drive → "iCloud Drive" 켜기

![iCloud Drive 설정](/sync-icloud-drive.png)
