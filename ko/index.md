# 📖 AppBox 사용 가이드

AppBox는 이름 그대로 "앱을 담는 상자"로, 앱을 수집하고 관리하기 위한 도구입니다. "컬렉션"을 만들어 좋아하는 앱을 기록하고, 컬렉션 설명, 앱 설명, 사용자 정의 속성 정보 기록 등의 기능을 제공합니다.
