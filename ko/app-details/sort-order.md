# 표시 순서 정렬 기능

이 기능은 앱 상세 페이지의 다음 섹션 표시 순서를 조정하는 데 사용됩니다:

- **스크린샷**: 앱 스크린샷 표시, 여러 플랫폼 동시 표시 가능
- **앱 정보**: AppStore에서 가져온 최신 앱 정보(App ID, 개발자, 가격, 크기 등)
- **앱 소개**: AppStore에서 가져온 앱 설명
- **업데이트 기록**: AppStore에서 가져온 최신 업데이트 내역
- **추가 정보**: 현재 앱의 AppStore 지역, 컬렉션에 추가된 시간 및 소스 링크

**사용 방법**: 설정 → 앱 표시 순서 → 목록을 드래그하여 순서 변경
