# AppBox 내에서 직접 추가

다음 진입점을 통해 「앱 추가」 인터페이스를 열 수 있습니다：

+ **앱 세트** 홈페이지：오른쪽 하단의 **앱 추가** 버튼 사용。표시되지 않는 경우 오른쪽 상단 메뉴에서 **「앱 추가」** 클릭。
+ 특정 **앱 세트 상세** 페이지：**앱 추가** 클릭（현재 목록만 정리하는 경우 대상 앱 세트가 자동으로 현재 앱 세트로 설정됩니다）。

![앱 추가 진입](/assets/how-to-add-apps/entry-screenshot.png)

연 후 상단 탭을 필요에 따라 전환할 수 있습니다：**앱 이름**、**앱 링크**、**사용자 정의**。미리보기 영역에서 설명 편집을 클릭하면 평점, 설명 등의 속성 정보를 빠르게 기록할 수 있는 설명 편집 페이지가 표시됩니다。

![앱 추가 인터페이스](/assets/how-to-add-apps/add-app-interface.png)

# 이름으로 검색하여 추가 (App 내에서 스토어 검색)

## 기능 소개
**앱 이름** 방식으로 키워드를 입력하고 App Store에서 검색하여 앱을 선택하고 컬렉션에 추가합니다.

![이름으로 검색](/assets/how-to-add-apps/search-by-name.png)

## 사용 시나리오
+ 앱 이름만 있고 링크가 없는 경우。
+ 동명의 앱을 비교하고 아이콘을 확인한 후 추가하려는 경우。

## 작업 단계
1. **앱 추가**를 열고 **앱 이름**을 선택。
2. 입력 상자에 이름 또는 키워드를 입력하고 **App Store 검색**을 클릭。
3. **검색 결과**에서 **지역**을 전환하여 다시 검색 가능（필요한 경우）。
4. 해당 행의 **추가**를 탭하여 선택；여러 개 선택 가능。
5. 선택 후 오른쪽 상단의 확인을 클릭하여 이전 페이지로 돌아가기。
6. **대상 앱 세트**를 선택；미리보기 영역에서 설명이나 태그를 편집 가능。
7. 하단의 **추가** 또는 **계속 추가**를 클릭。

## 기능 설명
+ 검색 결과는 선택한 지역의 App Store에서 제공됩니다；지역에 따라 목록이 다를 수 있습니다。
+ 미리보기 영역에 선택한 앱이 표시되며, 확인 후 저장됩니다。

::: info
스크린샷이나 이미지에서 텍스트를 인식하여 가능한 **앱 이름**을 검색 상자에 입력합니다。인식 완료 후 결과 페이지에서 인식된 텍스트를 확인하거나 수정할 수 있습니다。
:::

## 주의사항
> **참고**：앱을 찾을 수 없는 경우 현재 선택된 **App Store 지역**과 관련된 경우가 많습니다。이 페이지 또는 설정에서 지역을 변경한 후 다시 검색하세요。

# App Store 링크를 입력하여 인식하고 추가

## 기능 소개
App Store 앱 페이지의 링크를 붙여넣어 AppBox가 아이콘과 이름 등의 정보를 가져오고 선택한 앱 세트에 추가합니다。

![링크로 추가](/assets/how-to-add-apps/add-by-link.png)

## 사용 시나리오
+ 커뮤니티, 웹페이지, 메모에서 App Store 링크를 보고 바로 저장하고 싶은 경우。
+ 이미 링크를 복사했고 스토어에서 이름을 검색하고 싶지 않은 경우。

## 작업 단계
1. **앱 추가** 페이지를 엽니다。
2. 상단 세그먼트의 **앱 링크**를 클릭。
3. 링크를 입력 상자에 붙여넣기（붙여넣기 후 일반적으로 **자동 인식이 시작**됩니다），또는 **클립보드에서 인식**을 클릭하여 클립보드 전체 내용을 사용。
4. 저장 위치를 아직 선택하지 않은 경우 **대상 앱 세트**에서 하나 이상의 세트를 선택。
5. 특정 지역 스토어를 검색하려면 이 페이지에서 **지역**을 조정（「설정 → 앱 → App Store 지역」과 연동）。
6. **앱 미리보기**에서 항목이 올바른지 확인；여기서 설명을 편집하거나 태그를 선택할 수 있습니다。
7. 하단의 **추가**를 클릭하여 저장하고 닫기；또는 **계속 추가**를 클릭하여 이 페이지에 머물며 작업을 계속。

::: info
**여러 링크** 지원：동일한 입력 상자에서 **줄 바꿈** 또는 **영문 세미콜론** `;`으로 여러 App Store 링크를 구분합니다。내용이 변경되면 자동으로 인식을 시도합니다。**클립보드에서 인식**도 사용할 수 있습니다。
:::

## 기능 설명
+ 인식 성공 후 미리보기 목록이 표시됩니다；실패한 경우 페이지에 간단한 이유가 표시되므로 링크가 완전한지 확인할 수 있습니다。
+ 링크에 지역 정보가 포함된 경우 일반적으로 해당 지역에 따라 인식됩니다；수동으로 지역을 전환하여 다시 시도할 수도 있습니다。링크 인식 규칙에 대한 자세한 내용：[앱 지역 및 링크 인식](/ko/region/ko)

## 권장 사용법
+ 먼저 기본 앱 세트에 넣은 후 나중에 분류 앱 세트로 정리하면 반복 작업이 줄어듭니다。
+ 기사의 「앱 목록」을 일괄 수집할 때 여러 링크를 한 번에 붙여넣고 함께 확인할 수 있습니다。

# 사용자 정의 앱 추가 (수동 정보 입력)

## 기능 소개
앱 이름, 아이콘, 소스 링크 등의 정보를 수동으로 입력합니다。스토어에서 찾을 수 없거나 표시 방식을 완전히 사용자 정의하려는 항목에 사용합니다。

![사용자 정의 추가](/assets/how-to-add-apps/custom-add.png)

## 사용 시나리오
+ 아직 출시되지 않았거나, 이미 내려갔거나, 특정 채널에서만 배포되는 앱이지만 목록에 기록해두고 싶은 경우。
+ App Store가 아닌 앱/소프트웨어에 사용자 정의 아이콘과 메모를 남기고 싶은 경우。

## 작업 단계
1. **앱 추가**를 열고 **사용자 정의**를 선택。
2. 아이콘 영역을 클릭하고 프롬프트에 따라 **사진 라이브러리**, **파일** 또는 **이미지 링크**（`http`/`https`, PNG/JPG 권장）에서 아이콘을 가져오기。
3. **앱 이름** 입력（필수）。
4. 필요에 따라 **소스 링크** 입력（웹페이지 또는 설명 주소）。
5. **대상 앱 세트** 선택。
6. 앱 미리보기 영역에서 설명, 평점, 구독, 태그 등의 관련 정보를 편집。
7. 하단의 **추가**를 클릭하여 저장。

## 기능 설명
+ 소스 링크는 공식 웹사이트나 신뢰할 수 있는 페이지를 권장합니다。추후 확인이 더 편리합니다。
+ 사용자 정의 항목의 표시는 입력한 내용에 따라 달라집니다；스토어 앱처럼 자동으로 스토어 상세 페이지와 동기화되지 않습니다。
+ 앱 내에서 이 기능에 멤버십 제한이 표시되는 경우, 잠금 해제되지 않았을 때 프롬프트에 따라 멤버십 설명 페이지로 이동하세요。

## 주의사항
+ 사용자 정의 항목은 스토어에서 추가한 항목과 업데이트 방식이 다릅니다；스토어 앱은 상세 페이지에서 새로고침할 수 있지만 사용자 정의 항목은 수동으로 정보를 수정해야 합니다。
+ 해상도가 높은 정사각형 아이콘을 선택하는 것이 좋습니다；작은 스크린샷을 확대하지 마세요。

# 스크린샷으로 앱 이름 인식

## 기능 소개
스크린샷이나 이미지에서 텍스트를 인식하여 가능한 **앱 이름**을 검색 상자에 입력하고 [이름으로 검색하여 추가 (App 내에서 스토어 검색)](#이름으로-검색하여-추가-app-내에서-스토어-검색)와 결합하여 추가를 완료합니다。

![스크린샷 인식1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## 사용 시나리오
+ 앱 스크린샷만 있고 복사 가능한 링크가 없는 경우。이미지에서 제목을 검색 키워드로 빠르게 추출하려는 경우。

![스크린샷 인식2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## 작업 단계
1. **앱 추가** → **앱 이름**을 엽니다。
2. 이름 입력 상자 오른쪽의 **이미지에서 앱 인식**（뷰파인더 스타일 아이콘）을 클릭。
3. **사진에서 선택** 또는 **파일에서 선택**을 선택。
4. 인식 완료 후 결과 페이지에서 인식된 텍스트를 확인하거나 수정한 후 검색을 확인。

## 기능 설명
+ 인식의 목적은 입력을 줄이는 것입니다。스크린샷의 모든 텍스트를 인식하며, 대부분의 경우 검색 전에 사용자의 2차 확인이 필요합니다。
