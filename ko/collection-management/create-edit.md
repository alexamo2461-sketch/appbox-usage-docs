# 컬렉션 생성 및 편집

## 새 컬렉션 생성

컬렉션은 "목록" 또는 "폴더"와 같습니다. 홈 화면의 컬렉션 페이지에서 오른쪽 상단의 컬렉션 추가 아이콘을 탭하면 새 컬렉션 생성 페이지가 나타납니다. 컬렉션 이름, 색상, 설명을 입력하여 새 컬렉션을 만들 수 있습니다.

![컬렉션 생성](/collection-management/create-collection-en.png)

## 컬렉션 편집

컬렉션을 길게 눌러 컨텍스트 메뉴를 표시하거나 컬렉션 상세 페이지에서 "컬렉션 편집" 버튼을 탭하면 편집 페이지가 열립니다. 여기서 컬렉션의 이름, 색상, 설명을 수정할 수 있습니다.

![컬렉션 편집](/collection-management/edit-collection-en.png)

## 컬렉션 색상

컬렉션을 추가하거나 편집할 때 색상을 설정할 수 있습니다. 이 색상은 주로 컬렉션 상세 페이지의 설명 배경, 추가 버튼, 오른쪽 상단의 작업 메뉴 아이콘, 그리고 해당 컬렉션에서 접근하는 앱 상세 페이지의 강조 색상에 반영됩니다.

![컬렉션 색상](/collection-management/collection-color.png)
