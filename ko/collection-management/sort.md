# 컬렉션 정렬

앱 홈 화면에서 오른쪽 상단의 메뉴 버튼(점 세 개 아이콘)을 탭하고 "정렬" 옵션을 선택하여 원하는 정렬 방식을 설정할 수 있습니다. 현재 세 가지 정렬 방식을 제공합니다:

- **이름순 정렬**: 알파벳순 오름차순(A-Z) 또는 내림차순(Z-A)으로 정렬합니다.
- **생성 시간순 정렬**: 최신순 또는 오래된 순으로 정렬합니다.
- **사용자 지정 정렬**: 컬렉션의 순서를 수동으로 조정하여 개인 취향에 맞게 정렬합니다.

![정렬 옵션](/collection-management/sort-options.png)

## 사용자 지정 정렬

"정렬 시작"을 탭하여 사용자 지정 정렬을 시작합니다. 현재 목록 보기와 카드 보기만 사용자 지정 정렬을 지원합니다. 그리드 보기에서는 사용자 지정 정렬을 할 수 없으며 "정렬 시작" 버튼도 표시되지 않지만, 사용자 지정 정렬 순서에 따라 항목이 표시됩니다.

![사용자 지정 정렬](/collection-management/custom-sort.png)
