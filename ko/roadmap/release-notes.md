## V1.5.1 (App Store 미등록)

> 빌드일: 2026-01-18

**1. 변경사항**

- 데이터 업그레이드 로직 재작성. 업데이트 후 데이터 업그레이드 프롬프트가 표시되면 안심하고 진행 가능. 소요 시간은 앱 수에 따라 몇 분 정도 걸릴 수 있음
- 컬렉션 상세 페이지 오른쪽 아래 플로팅 추가 버튼 제거, 일괄 추가와 통합하여 오른쪽 위 "추가/일괄 추가" 메뉴로 이동
- 홈페이지 컬렉션이 너무 많을 때 전환 끊김 및 프레임 드롭 문제 수정
- 시스템 공유 확장 페이지 앱 설명 글자 수 제한을 2000자로 변경

**2. 추가사항**

- 홈페이지에서 앱 추가: 컬렉션 선택 페이지에서 컬렉션 생성 가능
- 홈페이지에서 앱 추가: 추가 성공 후 피드백 프롬프트 표시
- 홈페이지에서 앱 추가: 앱 링크 탭에서 단일/일괄 링크 인식 및 인식 기록 확인 지원
- 데이터 가져오기/내보내기: 컬렉션 사용자 정의 정렬 순서 필드 가져오기 및 내보내기 지원
- 데이터 가져오기: 가져오기 문제 해결을 위한 기록 확인 기능
- 컬렉션 설명 및 앱 설명이 너무 길면 자동 접기
- 앱 상세 페이지의 앱 소개 등 본문 텍스트 복사 지원

## V1.5

> 날짜: 2025-12-26

**0. 주의사항:**

- V1.4와 비교하여 데이터 모델이 업그레이드되었으므로 데이터 업데이트 작업이 필요합니다. 프롬프트가 자동으로 표시되니 확인 후 업데이트를 진행하세요
- 업데이트 후 설정 → 데이터 업데이트 → 업데이트 기록에서 상태를 확인할 수 있습니다. 실패한 데이터는 수동으로 삭제 후 다시 추가하세요
- 아직 이전 데이터를 복구하지 못한 분들은 개발자 도구를 사용하여 복구를 시도하세요. 사용 방법은 설정 → 사용자 가이드 → 자주 묻는 질문을 참조하세요

**1. 변경사항:**

- Mac 전용 소프트웨어 링크 가져오기 지원
- 앱 설명 글자 수 제한을 200자에서 2000자로 변경
- 홈페이지 레이아웃 조정, 하단 작업 표시줄 추가, 정렬 및 보기 전환을 오른쪽 위 작업 메뉴로 이동
- 앱 복사/이동 시 구독 정보 동기화

**2. 새로운 기능:**

- 컬렉션 정렬: 이름(A-Z 및 Z-A), 생성 시간(최신순 및 오래된순)으로 정렬 지원
- 사용자 정의 가져오기: 아이콘, 이름, 출처 등의 정보를 사용자가 입력 가능
- AppBox 내에서 앱 이름을 직접 검색하여 추가 가능
- 앱 상세 페이지에 "추가 정보" 섹션 추가, 가져온 시간·지역·출처 링크 표시
- 데이터 내보내기 시 앱 아이콘 파일과 JSON 파일이 포함된 전체 압축 패키지 출력
- 앱 상세 페이지에 앱 App ID 표시, 앱 소개 및 업데이트 기록 섹션에 번역 버튼 추가
- 앱 지역 선택: 새 앱 추가 시 지역 선택 지원, 지역 정렬 지원(설정 → 앱 지역)
- 검색 결과 페이지에서 컬렉션 및 앱의 길게 누르기 메뉴(편집, 복사/이동, 삭제) 지원
- 완전한 템플릿 및 필드 설명 제공, 템플릿 파일 일괄 가져오기 지원
- 아이콘 캐싱 기능: 앱 아이콘을 로컬에 다운로드하여 오프라인에서도 표시 가능
- 가져오기 시 앱 설명 편집 지원(홈페이지 추가 모듈 및 컬렉션 상세 페이지 모두 지원)
- 이전 버전 데이터베이스 복구용 개발자 도구 추가

**3. 기타:**

- 앱 가져오기 로직 전체 최적화: AppBox는 링크에서 `id1234567890` 형식의 숫자 ID를 추출하여 App Store에 앱 정보를 요청합니다. 지역 선택 전략: 링크에 명시적인 지역 코드(`/cn/`, `/us/` 등)가 있으면 우선 사용하고, 지역 코드가 없으면 설정 → 앱 지역의 목록을 위에서부터 순서대로 요청합니다. "일반"은 특정 국가/지역이 아닌 Apple 서버가 요청 환경에 따라 자동으로 추론한 결과입니다(대부분 미국). 자세한 내용은 설정 → 사용자 가이드 → 자주 묻는 질문 → 앱 링크 인식 규칙 및 지역 기능 사용법을 참조하세요

## V1.0

> 날짜: 2025-10-28

**1. 새로운 기능**

첫 번째 공식 릴리스, 현재 지원하는 기능:

1. 컬렉션을 만들어 앱 분류 및 저장
2. 컬렉션 내에서 App Store 링크 가져오기 시 자동 앱 인식, 목록 보기 및 그리드 보기 지원
3. 컬렉션 및 앱에 사용자 정의 메모 및 사용자 정의 평점 추가
4. 컬렉션 정렬, 색상 설정, 여러 카드 보기 전환
5. 컬렉션 간 앱 복사 및 이동
6. 앱 링크 일괄 가져오기
7. iCloud를 통한 컬렉션, 메모, 평점 동기화, JSON 파일로 데이터 가져오기/내보내기
8. 앱 내에서 App Store 앱 정보 확인, 한 번의 탭으로 해당 App Store 페이지로 이동
9. 카드 생성하여 컬렉션 공유(현재 3가지 스타일)
10. 테마 모드(라이트, 다크, 시스템) 및 강조 색상 전환

**2. 버그 수정**

1. 컬렉션 상세 페이지에서 앱이 생성 시간순으로 정렬되는 문제 수정
2. iCloud 동기화 문제 수정: 자동 동기화에서 수동 덮어쓰기 동기화로 방식 변경
3. 테마 모드 전환 후 즉시 응답하지 않는 문제 수정
4. macOS 설정 페이지에서 팝업 창 높이 문제 수정
5. 시스템 공유 확장에서 다중 선택하여 여러 컬렉션에 추가하는 기능 추가
6. 컬렉션 상세 페이지에서 앱 길게 누르기 메뉴(복사, 이동, 편집) 추가
7. 데이터 초기화 작업 추가, 로컬/클라우드 데이터 재설정 및 삭제 지원
8. 로컬/클라우드 데이터 기록 백업 추가, 최근 10개 전체 기록 저장 및 로컬 복원 지원
9. macOS 아이콘 보기에서 창 너비에 따른 적응형 레이아웃 지원
10. 앱 상세 페이지에서 지원 플랫폼 및 인앱 구매 정보 표시 추가
