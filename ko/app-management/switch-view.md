# 앱 보기 전환

컬렉션 상세 페이지에서는 앱을 표시하는 3가지 보기를 제공하여 다양한 사용 시나리오에 대응합니다.

## 세 가지 보기

| 보기 | 설명 |
| --- | --- |
| **목록 보기** | 앱을 컴팩트한 목록 형식으로 표시하며, 각 행에 아이콘, 이름, 설명을 표시합니다. 앱이 많을 때 빠르게 둘러보기에 적합합니다 |
| **아이콘 보기** | 앱 아이콘을 그리드 형식으로 표시합니다. 직관적이고 아름답며, 앱이 적거나 아이콘 인식을 중시하는 장면에 적합합니다 |
| **카드 보기** | 앱을 카드 형식으로 평점, 설명, 태그 등 더 많은 정보를 표시합니다. 앱을 상세하게 관리하기에 적합합니다 |

## 빠른 전환

컬렉션 상세 페이지에서 오른쪽 상단 작업 메뉴의 **보기 전환** 버튼을 탭하면 세 가지 보기 사이를 빠르게 전환할 수 있습니다.

## 기본 보기 설정

컬렉션에 들어갈 때마다 동일한 보기를 사용하려면 설정에서 고정할 수 있습니다:

**설정 → 일반 → 표시 설정 → 컬렉션 페이지**에서 선호하는 기본 보기를 선택합니다.

> **팁**: 오른쪽 상단의 전환 버튼은 "임시" 전환이며, 설정의 구성이 "고정" 보기입니다.

::: info
카드 보기는 멤버십 기능으로, AppBox Pro 구독이 필요합니다. 사용자 정의 정렬은 목록 보기와 아이콘 보기에서만 드래그 앤 드롭을 지원하며, 카드 보기와 그리드 보기는 사용자 정의 정렬 순서대로 표시되지만 드래그 앤 드롭은 지원하지 않습니다.
:::
