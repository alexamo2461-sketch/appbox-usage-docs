# 컬렉션 내 필터링

AppBox의 컬렉션 상세 페이지에서는 필요한 앱을 빠르게 찾을 수 있도록 강력한 필터링 기능을 제공합니다.

## 개요

컬렉션 상세 페이지에서 오른쪽 상단의 **필터** 아이콘을 탭하면 필터 패널이 열리며, 다양한 조건으로 현재 컬렉션의 앱을 필터링할 수 있습니다.

## 필터 조건

| 조건 | 설명 |
| --- | --- |
| **키워드** | 앱 이름, 설명, 구독 설명에서 키워드 검색 (최대 50자) |
| **평점** | 평점으로 필터링, "평점 없음" 및 1~5성 포함 |
| **태그** | 앱 태그로 필터링, 다중 선택 지원 |
| **카테고리** | App Store 주요 카테고리로 필터링 |
| **출처** | 앱 출처로 필터링: App Store 앱 또는 사용자 정의 앱 |
| **플랫폼** | 지원 플랫폼으로 필터링: iPhone, iPad, Mac |
| **지역** | App Store 지역으로 필터링 (현재 컬렉션에 실제로 존재하는 지역만 표시) |

## 사용 방법

1. 컬렉션 열기
2. 오른쪽 상단의 **필터** 아이콘 탭하기
3. 필터 패널에서 필요한 조건 설정
4. 여러 조건은 "AND" 관계(모두 동시에 만족해야 함)
5. 설정 완료 후 앱 목록이 자동으로 업데이트됩니다

## 필터 초기화

필터 패널의 **초기화** 버튼을 탭하면 모든 필터 조건이 재설정되어 전체 앱이 표시됩니다.

## 팁

- 지역 필터는 현재 컬렉션에 실제로 존재하는 지역만 표시되며, 빈 옵션은 나타나지 않습니다
- 여러 조건을 조합하여 정확한 필터링이 가능합니다. 예: "태그: 생산성 + 플랫폼: iPhone"
- 키워드 검색은 앱 이름과 설명 내용을 모두 검색합니다
