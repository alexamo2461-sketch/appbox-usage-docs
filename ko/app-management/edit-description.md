# 앱 설명 편집

컬렉션 내 앱에 사용자 정의 평가와 메모를 추가할 수 있습니다. 평가와 메모는 앱 정보에서 앱 아이콘과 제목 아래에 표시됩니다.

**접근 방법**: 여러 진입점이 있습니다:

1. 앱 상세 페이지에서 왼쪽 상단의 편집 버튼 탭
2. 하단 도구 모음의 추가 모듈에서 앱 추가 후 미리보기 영역
3. 컬렉션 상세 페이지의 추가 버튼으로 앱 인식 후 미리보기 영역

![앱 설명 편집](/app-management/edit-description.png)

> **참고**: 다른 컬렉션 간의 (같은 이름의) 앱 메모는 서로 독립적입니다. 예를 들어 컬렉션 A에 "TikTok"이 있고 컬렉션 B에도 "TikTok"이 있는 경우, 평가, 메모 및 구독 속성은 서로 독립적이며 동기화되지 않습니다. 이는 기능 사양이며 버그가 아닙니다. 두 메모를 동일하게 하려면 복사 기능을 사용하여 수동으로 앱을 다른 컬렉션에 복사하세요. 이후 한 컬렉션에서 메모를 편집해도 다른 컬렉션에는 동기화되지 않습니다.
