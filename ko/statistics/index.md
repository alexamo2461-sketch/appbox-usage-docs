# 통계 기능

AppBox는 앱 컬렉션 현황을 종합적으로 파악할 수 있는 풍부한 통계 기능을 제공합니다.

## 개요

하단 내비게이션 바의 **통계** 탭을 눌러 다양한 데이터 차트와 분석 결과를 확인합니다.

::: info
통계 기능은 Pro 기능으로, AppBox Pro 구독이 필요합니다. 미구독 시 샘플 데이터 미리보기가 표시됩니다.
:::

## 핵심 지표

통계 페이지 상단에 4개의 핵심 지표 카드가 표시됩니다:

| 지표 | 설명 |
| --- | --- |
| **저장한 앱** | 중복 제거된 앱 총 수 (눌러서 전체 목록 보기) |
| **컬렉션 수** | 생성한 컬렉션 총 수 |
| **구독 총 지출** | 모든 구독 앱의 총 비용 (눌러서 상세 보기) |
| **앱 총 수** | 중복 포함 앱 총 항목 수 (눌러서 원본 목록 보기) |

## 통계 차트

### 평점 분포
앱에 매긴 평점의 분포를 표시하여 평점 선호도를 파악합니다.

### 구독 데이터
현재 구독 수, 통화별 월 지출, 연간 비용 예상 등을 표시합니다. 눌러서 상세 페이지로 이동합니다.

### 설명 커버리지
설명이 추가된 앱의 수와 비율을 표시합니다.

### 추가 추이
월별 앱 저장 수의 변화를 통계로 표시하여 컬렉션 습관을 파악합니다.

### 플랫폼 분포
지원 플랫폼(iPhone, iPad, Mac)의 분포를 표시합니다.

### 지역 분포
App Store 국가/지역 분포를 표시합니다.

### 카테고리 분포
App Store 주요 카테고리별 분포를 표시합니다.

## 통계 범위

기본적으로 모든 컬렉션의 데이터를 통계합니다. 범위를 사용자 정의할 수 있습니다:

1. 통계 페이지 오른쪽 상단의 **범위** 버튼을 누릅니다
2. **전체 컬렉션** 또는 특정 컬렉션을 선택합니다
3. **컬렉션 간 중복 제거**를 활성화하여 다른 컬렉션의 동일한 앱을 통합합니다

## 사용자 정의 통계

통계 카드의 표시 순서와 표시 여부를 사용자 정의할 수 있습니다:

1. 통계 페이지 오른쪽 상단의 **사용자 정의** 버튼을 누릅니다
2. 드래그하여 카드 표시 순서를 조정합니다
3. 눈 아이콘을 눌러 카드 표시/숨기기를 전환합니다
4. **기본값 복원**을 눌러 기본 레이아웃으로 재설정합니다

## 구독 상세

"구독 총 지출" 또는 "구독 데이터 통계" 카드를 눌러 상세 페이지로 이동합니다:

- 월별 지출 통계
- 연별 지출 통계
- 총 지출 추이
- 구독 구성 세부 항목
- 비용 분포 차트
- 기간 및 갱신 분석
