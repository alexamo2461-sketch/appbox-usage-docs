# 태그

AppBox는 앱에 사용자 정의 태그를 추가하여 유연한 분류와 빠른 검색을 지원합니다.

## 개요

태그는 유연한 분류 방법입니다. 컬렉션과 달리 하나의 앱에 여러 태그를 추가할 수 있으며, 같은 태그를 여러 앱에 사용할 수 있습니다. 태그를 통해 컬렉션을 넘어 앱을 빠르게 필터링하고 찾을 수 있습니다.

## 태그 추가

앱 설명 편집 페이지에서 하나 이상의 태그를 추가할 수 있습니다.

**방법**: 앱 상세 열기 → 설명 편집 누르기 → 태그 영역에서 태그 입력 또는 선택

## 태그 관리

설정에서 모든 태그를 관리할 수 있습니다:

**방법**: 설정 → 앱 → 태그 관리

태그 관리 페이지에서:

- 사용 중인 모든 태그 보기
- 태그 검색
- 태그 이름 변경
- 불필요한 태그 삭제

## 태그로 앱 필터링

### 홈 페이지 태그 영역

홈 페이지 하단에 모든 태그가 표시됩니다. 태그를 눌러 해당 태그가 있는 앱 목록을 봅니다.

### 컬렉션 내 필터링

컬렉션 상세 페이지의 필터 패널에서 태그로 앱을 필터링할 수 있습니다. 자세한 내용은 [컬렉션 내 필터링](/app-management/filtering)을 참조하세요.

## 태그 표시 설정

**방법**: 설정 → 일반 → 기능 구성 → 앱 상세 페이지

앱 상세 페이지에서 태그 표시 방법을 구성할 수 있습니다:

- **태그 표시**: 앱 상세 페이지에서 태그 표시 전환
- **아이콘 표시**: 태그 앞에 아이콘 표시 전환
- **한 줄 표시**: 태그를 한 줄로 표시 전환

::: info
태그 데이터는 동기화와 가져오기/내보내기를 지원합니다. 기기를 변경해도 태그가 손실되지 않습니다.
:::
