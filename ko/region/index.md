# 앱 지역 기능 사용 방법
**앱 지역**이란 AppBox가 App Store에서 **소개, 아이콘 등의 정보를 조회할 때** 사용하는 **국가 또는 지역 스토어**를 의미합니다.

이 기능을 통해 다음과 같은 작업을 할 수 있습니다:
**해당 지역에 출시된 앱 검색**, **지역에 맞는 이름 및 아이콘 표시**, 그리고 **여러 앱의 지역 정보를 일괄 조회**할 수 있습니다.

:::info
**주의:** 앱 출시 여부, 이름 번역 등은 모두 해당 지역의 App Store 기준으로 제공됩니다. 특정 지역에서 앱을 찾을 수 없다는 안내가 표시되는 경우, 이는 스토어 측 결과이며 즐겨찾기 데이터가 삭제된 것은 아닙니다.
:::

## 이런 경우에 사용합니다
+ **앱 이름으로 검색되지 않는 경우** → 지역을 변경한 뒤 다시 검색해 보세요 (일부 앱은 특정 스토어에서만 제공됩니다).  
+ **동일한 이름의 앱을 구분하기 어려운 경우** → 지역 정보를 통해 표시 내용을 구분할 수 있습니다.  
+ **링크에 지역 정보가 포함된 경우** → AppBox는 **링크의 지역 정보를 우선적으로 인식**합니다 (아래 설명 참고).  
+ **여러 국가의 앱 목록 관리** → **필터 · 지역**으로 확인하거나, 먼저 **지역 일괄 변경** 후 새로고침할 수 있습니다.

## 「설정」에서 앱 지역 관리하기
**설정 → 앱 → 앱 지역**

이곳은 **「지역 조회 목록」**입니다. 활성화된 국가 및 지역이 표시되며, **위에서 아래 순서대로** 우선순위를 의미합니다 (상단에 있는 지역이 먼저 조회되며, 여러 지역을 시도할 때도 이 순서가 적용됩니다).

| 작업 | 설명 |
| --- | --- |
| **지역 추가** | 「지역 추가」를 눌러 목록에서 선택합니다. **최대 10개 지역**까지 추가할 수 있으며, 제한에 도달하면 안내가 표시됩니다. |
| **삭제** | 항목을 **왼쪽으로 스와이프**하여 삭제할 수 있습니다. 단, **최소 1개의 지역은 유지되어야 합니다**. |
| **정렬** | 우측 상단의 **정렬**을 눌러 순서를 변경한 뒤 **확인**하여 저장합니다. 일반적으로 **가장 위의 지역**이 기본 우선순위로 사용됩니다 (특히 링크에서 지역을 알 수 없는 경우). |
| **목록이 비어 있는 경우** | 「지역 추가」를 통해 지역을 선택하라는 안내가 표시됩니다. |

### 「지역 선택」 목록과의 차이점
**앱 추가**, **앱 상세 정보** 등의 화면에서 표시되는 **「지역 선택」** 목록에는 일반적으로 설정에서 이미 활성화한 지역만 표시됩니다 (즉, 위의 「지역 조회 목록」). 이를 통해 빠르게 지역을 전환할 수 있습니다.

반면 설정의 **지역 추가** 기능은 **전체 지역 목록**에서 선택하여 활성화 목록을 확장하는 용도로 사용됩니다.

## App Store 링크와 지역: 인식 규칙
App Store 앱 링크를 붙여넣거나 공유하면, AppBox는 가능한 한 링크에서 **국가 또는 지역 정보**를 자동으로 읽어옵니다. 예를 들어:

+ 링크 주소에 `…/cn/app/…`, `…/us/app/…` 와 같은 **두 글자 코드**(일반적으로 소문자)가 포함된 경우, 해당 지역으로 인식됩니다 (예: cn → 중국 본토 스토어, us → 미국 스토어).

| 상황 | 동작 방식 |
| --- | --- |
| **링크에서 지역을 확인할 수 있는 경우** | **앱 추가 → 앱 링크** 화면에서 「국가 또는 지역」 항목이 일반적으로 **표시되지 않습니다** (이미 링크에 지역 정보가 포함되어 있기 때문입니다). 설정에서 지역 순서를 변경해도, 링크 우선 인식 방식은 **변경되지 않습니다**. |
| **링크에서 지역을 확인할 수 없는 경우** | 「국가 또는 지역」 항목이 표시되며 (예: 「중국 본토 (cn)」), 현재 설정에서 선택된 지역이 사용됩니다. |
| **여러 링크를 한 번에 붙여넣는 경우** | 전체 내용이 **하나의 지역 포함 링크**로 해석되지 않는 경우, 일반적으로 「국가 또는 지역」 항목이 **표시됩니다**. 여러 링크는 이번에 선택한 동일한 지역 전략을 함께 사용합니다. |

**한마디로:** 링크에 지역 정보가 명확히 포함되어 있으면 링크 기준으로 처리하고, 그렇지 않으면 AppBox에서 선택한 지역 기준으로 처리합니다.

## 앱 상세 페이지에서 지역 확인 및 변경
<!-- 이미지 OCR 내용: -->
![](https://cdn.nlark.com/yuque/0/2026/png/462556/1779116920932-fc735b67-36dd-451c-bb7f-2669ec7ad928.png)

### 지역 확인
앱 상세 페이지에서 **「추가 정보」**를 열면, **「지역」** 항목에서 현재 저장된 스토어 코드에 해당하는 지역 이름을 확인할 수 있습니다.

### 지역 변경 (스토어 기반 앱만 지원)
1. 앱 상세 페이지 우측 상단의 **「⋯」** 메뉴에서 **「지역 변경」**을 선택합니다.  
2. **「지역 선택」**에서 원하는 지역을 선택하고 확인합니다.  
3. AppBox가 새로운 지역 스토어에서 해당 앱이 존재하는지 다시 확인합니다.  
    - **성공:** 앱 이름, 아이콘 등의 정보가 업데이트되며(스토어에서 제공하는 경우), **변경 완료** 메시지가 표시됩니다.  
    - **실패:** 예를 들어 **「선택한 지역 스토어에 해당 앱이 없습니다」**라는 메시지가 표시되면, 잘못된 상태를 방지하기 위해 이전 지역으로 자동 복원됩니다.

> **사용자 정의 앱**은 현재 **「지역 변경」** 기능이 표시되지 않습니다. 관련 정보가 사용자가 직접 입력한 데이터이기 때문입니다.
>

## 앱 컬렉션 내에서 지역 관리하기

### 지역 일괄 변경
동일한 **앱 컬렉션** 안에서 여러 개의 스토어 기반 앱을 선택한 경우, 한 번에 같은 지역으로 변경하고 표시 정보를 갱신할 수 있습니다.

#### 사용 방법
1. 특정 **앱 컬렉션**을 엽니다.  
2. 우측 상단의 **「⋯」** → **「앱 선택」**을 누릅니다.  
3. 여러 앱을 선택합니다.  
4. 하단 툴바의 **「지역」**(지구본 아이콘)을 누릅니다.  
5. **「지역 선택」**에서 대상 지역을 선택하면, AppBox가 각 앱의 스토어 정보를 순차적으로 다시 가져옵니다.  
6. 완료 후 **「지역 일괄 변경 결과」** 화면에서 성공, 실패 또는 건너뛴 앱 목록을 각각 확인할 수 있습니다.

### 필터링 (특정 지역만 표시)
앱 컬렉션 상세 페이지 우측 상단의 **필터** 아이콘 → **「지역」** 항목 → 여러 지역 선택 가능. 현재 컬렉션에서 조건에 맞는 앱만 표시됩니다. 선택 가능한 지역은 **현재 컬렉션에 실제 존재하는 지역**만 표시됩니다.

## 데이터 가져오기 기능의 「Apple Data」

**설정 → 데이터 가져오기 → Apple Data**  
가져오기 전에 1~10개의 지역을 선택할 수 있으며, 목록 순서대로 앱 정보를 자동 조회합니다. 앱 정보를 찾거나 모든 전략을 시도할 때까지 계속 진행됩니다.

주의: 너무 많은 지역을 선택하면 가져오기 속도가 크게 느려질 수 있습니다. 일반적으로 1~3개의 지역만 선택하는 것을 권장합니다.
