# 在 AppBox 内直接添加

你可以通过如下入口打开「新增应用」界面：

+ 在 **应用集** 主页：使用右下角 **新增应用** 按钮；若未显示，请点右上角菜单中的 **「新增应用」**。
+ 在某个 **应用集详情** 页：点 **新增应用**（若仅整理当前清单，目标应用集会自动指向当前应用集）。

![新增应用入口](/assets/how-to-add-apps/entry-screenshot.png)

打开后，顶部可按需切换：**应用名称**、**应用链接**、**自定义**。在预览应用区域点击编辑说明可以弹出应用说明编辑页面，用以快速记录评分、说明等属性信息。

![新增应用界面](/assets/how-to-add-apps/add-app-interface.png)

# 按名称搜索并添加（在 App 内搜索商店）

## 功能简介
在 **应用名称** 方式下输入关键字，从 App Store 搜索并勾选应用，加入收藏。

![按名称搜索](/assets/how-to-add-apps/search-by-name.png)

## 使用场景
+ 只有应用名字，没有链接。
+ 想对比同名应用，核对图标再添加。

## 操作步骤
1. 打开 **新增应用**，选择 **应用名称**。
2. 在输入框输入名称或关键字，点 **搜索 App Store**。
3. 在 **搜索结果** 中可切换 **地区** 后重新搜索（如需）。
4. 轻点某一行的 **添加** 进行选择；可勾选多个。
5. 选好以后点右上角确认，返回上一页。
6. 选择 **目标应用集**，在预览区可编辑说明或标签。
7. 点底部 **添加** 或 **继续添加**。

## 功能说明
+ 搜索结果来自所选地区的 App Store；地区不同，列表可能不同。
+ 预览区会显示已选中的应用，确认无误后再保存。

::: info
支持从截图或图片中识别文字，把可能的 **应用名称** 填入搜索框，识别完成后，可在结果页确认或修改识别出的文字。
:::

## 注意事项
> **注意**：搜索不到某应用，常与当前所选 **应用商店地区** 有关，可在本页或设置里更换地区后再搜。

# 输入并识别 App Store 链接添加

## 功能简介
通过粘贴 App Store 应用页面的链接，让 AppBox 获取图标与名称等信息，并把应用加入所选应用集。

![通过链接添加](/assets/how-to-add-apps/add-by-link.png)

## 使用场景
+ 在社区、网页或备忘录里看到一串 App Store 链接，想马上收藏。
+ 已经复制了链接，不想再去商店里搜索名称。

## 操作步骤
1. 打开 **新增应用** 页面。
2. 点顶部分段中的 **应用链接**。
3. 将链接粘贴到输入框（粘贴后一般会 **自动开始识别**），也可点 **从剪贴板识别** 使用剪贴板全文。
4. 若尚未选好存放位置，在 **目标应用集** 中选择一个或多个应用集。
5. 如需按特定地区商店查询，可在本页调整 **地区**（与「设置 → 应用 → 应用商店地区」一致）。
6. 在 **应用预览** 中确认条目是否正确，可在此编辑说明或选择标签。
7. 点底部 **添加** 保存并关闭；或点 **继续添加** 保留在本页继续操作。

::: info
支持 **多条链接**：在同一输入框中，用 **换行** 或 **英文分号** `;` 分隔多条 App Store 链接；内容变化后会自动尝试识别，也可使用 **从剪贴板识别**。
:::

## 功能说明
+ 识别成功后会出现预览列表；失败时页面会给出简短原因提示，可检查链接是否完整。
+ 若链接带地区信息，通常会按链接中的商店区域识别；也可手动切换地区后再试。关于链接识别规则：[应用地区与APP链接识别](/region/zh-CN)

## 推荐用法
+ 先放进默认应用集，之后再整理到分类应用集，减少重复操作。
+ 批量收藏文章里的「应用清单」时，可一次性粘贴多条链接再统一确认预览。

# 自定义添加应用（手动填写信息）

## 功能简介
手动填写应用名称、图标与来源链接等信息，用于商店暂时搜不到、或你希望完全自定义展示方式的条目。

![自定义添加](/assets/how-to-add-apps/custom-add.png)

## 使用场景
+ 尚未上架、已下架或仅限特定渠道分发的应用，但仍想在清单里占位记录。
+ 需要为某个非 AppStore 应用/软件保留自定义图标与备注。

## 操作步骤
1. 打开 **新增应用**，选择 **自定义**。
2. 点图标区域，按提示从 **照片图库**、**文件** 或通过 **图片链接**（`http`/`https`，建议 PNG/JPG）获取图标。
3. 填写 **应用名称**（必填）。
4. 按需填写 **链接来源**（网页或说明地址）。
5. 选择 **目标应用集**。
6. 应用预览区域可编辑说明、评分、订阅、标签等相关信息。
7. 点底部 **添加** 保存。

## 功能说明
+ 来源链接建议填官网或可信页面，日后复查更方便。
+ 自定义条目的展示依赖你填写的内容；不会像商店应用那样自动同步商店详情页。
+ 若 App 内对本功能显示会员限制，未解锁时按提示前往会员说明页。

## 注意事项
+ 自定义条目与从商店添加的条目在更新方式上不同；商店应用可在详情页执行刷新，自定义条目需自行修改信息。
+ 尽量选择分辨率较高的正方形图标；避免过小截图放大。

# 通过截图识别应用名称

## 功能简介
从截图或图片中识别文字，把可能的 **应用名称** 填入搜索框，再结合[按名称搜索并添加（在 App 内搜索商店）](#按名称搜索并添加在-app-内搜索商店)完成添加。

![截图识别1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## 使用场景
+ 只有应用截图，没有可复制链接，想快速提取图上标题作为搜索关键词。

![截图识别2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## 操作步骤
1. 打开 **新增应用** → **应用名称**。
2. 在名称输入框右侧，点 **识别图片中的应用**（取景框样式图标）。
3. 选择 **从照片中选择** 或 **从文件中选择**。
4. 识别完成后，可在结果页确认或修改识别出的文字，再确认搜索。

## 功能说明
+ 识别目的是减少打字，会识别截图中的全部文字，大多数场景下都需要用户二次确认后再搜索。
