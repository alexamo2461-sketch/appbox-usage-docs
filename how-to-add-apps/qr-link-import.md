# 从二维码或链接导入

AppBox 支持通过扫描他人分享的二维码或粘贴分享链接，快速导入整个应用集到自己的收藏中。

## 功能简介

当其他人通过"分享应用集"功能生成了二维码或链接后，你可以通过扫描或粘贴的方式，将该应用集完整导入到你的 AppBox 中。

> 相关内容：[分享应用集](/collection-management/share)

## 操作步骤

1. 在 AppBox 首页点击右上角的 **菜单** 按钮（三点图标）
2. 选择 **从二维码或链接导入**
3. 根据你获得的方式：
   - **二维码**：使用相机扫描对方分享的二维码
   - **链接**：将对方分享的链接粘贴到输入框
4. AppBox 会自动识别并解析应用集内容
5. 确认导入后，应用集会出现在你的首页中

## 使用场景

- 朋友分享了一个精选应用清单，你想一键收藏
- 在社区或社交媒体上看到别人分享的应用集链接
- 从自己的另一台设备迁移应用集数据

## 注意事项

> **提示**：导入的应用集会作为新的应用集添加到你的收藏中，不会影响已有的应用集。
