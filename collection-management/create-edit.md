# 新建与编辑应用集

## 新建应用集

将应用集想象成一个"清单"或者"文件夹"，在首页应用集页面中点击右上角新增应用集图标按钮弹出新增应用集页面，可以输入应用名称、颜色和说明来新增应用集。

![新建应用集](/collection-management/create-collection.png)

## 编辑应用集

长按应用集弹出快捷菜单或在应用详情页面中点击编辑应用集按钮弹出应用集编辑页面，可以修改应用集的名称、颜色和应用集说明。

![编辑应用集](/collection-management/edit-collection.png)

## 应用集颜色

在新增/编辑应用集时可以设置该应用集的颜色，这个颜色主要表现在应用集详情页面中应用集说明背景、新增按钮、右上角操作菜单图标以及在该应用集详情页面中点击进入的应用详情页面高亮颜色。如下图所示：
