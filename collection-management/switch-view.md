# 切换应用集视图

应用集详情页面提供了 3 种视图方式，满足不同场景下的浏览需求。

## 三种视图

| 视图 | 说明 |
| --- | --- |
| **列表视图** | 以列表形式展示应用图标和名称，信息紧凑，适合快速浏览 |
| **图标视图** | 以网格形式展示应用图标，直观美观，适合应用较少时使用 |
| **卡片视图** | 以卡片形式展示应用评分、说明、标签等更多信息，适合详细管理 |

## 快速切换

在应用集详情页面，点击右上角操作菜单中的 **切换视图** 按钮，可以在三种视图之间快速切换。

## 设置默认视图

如果你希望每次进入应用集详情时都使用同一种视图，可以在设置中固定：

**设置 → 通用 → 功能配置 → 应用集页**，选择你偏好的默认视图。

> **提示**：右上角的切换按钮是"临时"切换，设置中的配置才是"固定"视图。

::: info
卡片视图为会员功能，需订阅 AppBox Pro 后使用。
:::
