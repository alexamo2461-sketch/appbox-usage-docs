# 应用标签

AppBox 支持为应用添加自定义标签，帮助你更灵活地分类和查找应用。

## 功能简介

标签是一种灵活的分类方式。与应用集不同，一个应用可以添加多个标签，同一个标签也可以用于多个应用。通过标签，你可以跨应用集快速筛选和查找应用。

## 添加标签

在编辑应用说明页面中，可以为应用添加一个或多个标签。

**操作方式**：进入应用详情 → 点击编辑说明 → 在标签区域输入或选择标签

## 标签管理

在设置中可以统一管理所有标签：

**操作方式**：设置 → 应用 → 标签管理

在标签管理页面中，你可以：

- 查看所有已使用的标签
- 搜索标签
- 修改标签名称
- 删除不需要的标签

## 通过标签筛选应用

### 首页标签区域

首页底部会显示所有已使用的标签。点击某个标签，可以查看所有使用该标签的应用列表。

### 应用集内筛选

在应用集详情页面的筛选面板中，可以按标签筛选应用。详见 [应用集内筛选](/app-management/filtering)。

## 标签显示设置

**操作方式**：设置 → 通用 → 功能配置 → 应用详情页

可以配置标签在应用详情页的显示方式：

- **开启标签显示**：控制是否在应用详情页显示标签
- **显示图标**：控制标签前是否显示标签图标
- **单行显示**：控制标签是否以单行方式显示

::: info
标签数据支持同步和导入导出，换设备后标签不会丢失。
:::
