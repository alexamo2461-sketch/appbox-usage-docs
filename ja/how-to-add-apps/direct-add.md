# AppBox内で直接追加

以下の入口から「アプリ追加」画面を開くことができます：

+ **アプリセット** ホームページ：右下の **アプリ追加** ボタンを使用。表示されていない場合は、右上のメニューから **「アプリ追加」** をクリック。
+ 特定の **アプリセット詳細** ページ：**アプリ追加** をクリック（現在のリストを整理するだけの場合、ターゲットアプリセットは自動的に現在のアプリセットに設定されます）。

![アプリ追加エントリ](/assets/how-to-add-apps/entry-screenshot.png)

開いた後、上部タブを必要に応じて切り替えられます：**アプリ名**、**アプリリンク**、**カスタム**。プレビューエリアで「説明を編集」をクリックすると、評価や説明などの属性情報をすばやく記録できる説明編集ページが表示されます。

![アプリ追加画面](/assets/how-to-add-apps/add-app-interface.png)

# 名前で検索して追加（App内でストアを検索）

## 機能紹介
**アプリ名** 方式でキーワードを入力し、App Store から検索してアプリを選択し、コレクションに追加します。

![名前で検索](/assets/how-to-add-apps/search-by-name.png)

## 使用シーン
+ アプリ名のみでリンクがない場合。
+ 同名アプリを比較し、アイコンを確認してから追加したい場合。

## 操作手順
1. **アプリ追加** を開き、**アプリ名** を選択。
2. 入力ボックスに名前またはキーワードを入力し、**App Store を検索** をクリック。
3. **検索結果** で **地域** を切り替えて再検索可能（必要に応じて）。
4. 該当行の **追加** をタップして選択；複数選択可能。
5. 選択後、右上の確認をクリックして前のページに戻る。
6. **ターゲットアプリセット** を選択；プレビューエリアで説明やタグを編集可能。
7. 下部の **追加** または **続けて追加** をクリック。

## 機能説明
+ 検索結果は選択した地域の App Store からのものです；地域によってリストが異なる場合があります。
+ プレビューエリアには選択したアプリが表示され、確認後に保存されます。

::: info
スクリーンショットや画像からテキストを認識し、可能性のある **アプリ名** を検索ボックスに入力します。認識完了後、結果ページで認識されたテキストを確認または修正できます。
:::

## 注意事項
> **注意**：アプリが見つからない場合、現在選択されている **App Store 地域** が原因であることが多いです。このページまたは設定で地域を変更して再検索してください。

# App Store リンクを入力して認識し追加

## 機能紹介
App Store アプリページのリンクを貼り付けることで、AppBox がアイコンや名前などの情報を取得し、選択したアプリセットに追加します。

![リンクで追加](/assets/how-to-add-apps/add-by-link.png)

## 使用シーン
+ コミュニティ、ウェブページ、メモで App Store リンクを見つけてすぐに保存したい場合。
+ リンクをすでにコピーしており、ストアで名前を検索したくない場合。

## 操作手順
1. **アプリ追加** ページを開く。
2. 上部セグメントの **アプリリンク** をクリック。
3. リンクを入力ボックスに貼り付け（貼り付け後、通常 **自動認識が開始** されます）、または **クリップボードから認識** をクリックしてクリップボードの全文を使用。
4. 保存場所をまだ選択していない場合、**ターゲットアプリセット** で1つ以上のセットを選択。
5. 特定の地域ストアを検索するには、このページで **地域** を調整（「設定 → アプリ → App Store 地域」と連動）。
6. **アプリプレビュー** でエントリが正しいか確認；ここで説明を編集したりタグを選択したりできます。
7. 下部の **追加** をクリックして保存して閉じる；または **続けて追加** をクリックしてこのページに留まり操作を続ける。

::: info
**複数リンク** に対応：同じ入力ボックスで **改行** または **英数字のセミコロン** `;` で複数の App Store リンクを区切ります。内容が変更されると自動的に認識を試みます。**クリップボードから認識** も使用できます。
:::

## 機能説明
+ 認識成功後、プレビューリストが表示されます；失敗した場合、ページに簡単な理由が表示されるので、リンクが完全かどうかを確認できます。
+ リンクに地域情報が含まれている場合、通常その地域に従って認識されます；手動で地域を切り替えて再試行することもできます。リンク認識ルールについて：[アプリ地域とリンク認識](/ja/region/ja)

## 推奨用法
+ まずデフォルトのアプリセットに入れ、後で分類アプリセットに整理すると、繰り返し操作が減ります。
+ 記事の「アプリリスト」を一括収集する際、複数のリンクを一度に貼り付けてから一括確認できます。

# カスタムアプリ追加（手動情報入力）

## 機能紹介
アプリ名、アイコン、ソースリンクなどの情報を手動で入力します。ストアで見つからない場合や、表示方法を完全にカスタマイズしたい場合に使用します。

![カスタム追加](/assets/how-to-add-apps/custom-add.png)

## 使用シーン
+ 未上架、已下架、または特定のチャネルでのみ配布されているアプリだが、リストに記録しておきたい場合。
+ App Store 以外のアプリ/ソフトウェアにカスタムアイコンとメモを残したい場合。

## 操作手順
1. **アプリ追加** を開き、**カスタム** を選択。
2. アイコンエリアをクリックし、プロンプトに従って **写真ライブラリ**、**ファイル**、または **画像リンク**（`http`/`https`、PNG/JPG推奨）からアイコンを取得。
3. **アプリ名** を入力（必須）。
4. 必要に応じて **ソースリンク** を入力（ウェブページまたは説明アドレス）。
5. **ターゲットアプリセット** を選択。
6. アプリプレビューエリアで説明、評価、サブスクリプション、タグなどの関連情報を編集。
7. 下部の **追加** をクリックして保存。

## 機能説明
+ ソースリンクは公式サイトや信頼できるページを推奨します。後日の確認が容易になります。
+ カスタムエントリの表示は入力した内容に依存します；ストアアプリのように自動的にストア詳細ページと同期されることはありません。
+ アプリ内でこの機能にメンバーシップ制限が表示される場合、ロック解除されていないときはプロンプトに従ってメンバーシップ説明ページに移動してください。

## 注意事項
+ カスタムエントリはストアから追加したエントリと更新方法が異なります；ストアアプリは詳細ページで更新できますが、カスタムエントリは手動で情報を変更する必要があります。
+ 解像度の高い正方形のアイコンを選ぶようにしてください；小さなスクリーンショットを拡大しないでください。

# スクリーンショットでアプリ名を認識

## 機能紹介
スクリーンショットや画像からテキストを認識し、可能性のある **アプリ名** を検索ボックスに入力し、[名前で検索して追加（App内でストアを検索）](#名前で検索して追加app内でストアを検索)と組み合わせて追加を完了します。

![スクリーンショット認識1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## 使用シーン
+ アプリのスクリーンショットのみでコピー可能なリンクがない場合。画像からタイトルを検索キーワードとしてすばやく抽出したい場合。

![スクリーンショット認識2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## 操作手順
1. **アプリ追加** → **アプリ名** を開く。
2. 名前入力ボックスの右側にある **画像内のアプリを認識**（ファインダースタイルのアイコン）をクリック。
3. **写真から選択** または **ファイルから選択** を選択。
4. 認識完了後、結果ページで認識されたテキストを確認または修正してから、検索を確認。

## 機能説明
+ 認識の目的は入力を減らすことです。スクリーンショット内のすべてのテキストを認識します。ほとんどの場合、検索前にユーザーによる二次確認が必要です。
