# アプリ説明の編集

コレクション内のアプリにカスタム評価やメモを追加できます。評価とメモは、アプリ情報のアプリアイコンとタイトルの下に表示されます。

**操作方法**：以下の複数の入口からアクセスできます：

1. アプリ詳細ページで左上の編集ボタンをタップ
2. 下部ツールバーの追加モジュールでアプリ追加後のプレビューエリア
3. コレクション詳細ページの追加ボタンでアプリ認識後のプレビューエリア

![アプリ説明の編集](/app-management/edit-description.png)

> **注意**：異なるコレクション間での（同じ名前の）アプリのメモは独立しています。例えば、コレクションAに「TikTok」があり、コレクションBにも「TikTok」がある場合、評価、メモ、サブスクリプション属性は互いに独立しており同期されません。これは機能仕様であり、バグではありません。両方のメモを同じにしたい場合は、コピー機能を使用して手動でアプリを別のコレクションにコピーしてください。その後、一方のコレクションでメモを編集しても、もう一方には同期されません。
