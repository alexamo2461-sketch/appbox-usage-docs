# アプリビューの切り替え

コレクション詳細ページでは、アプリを表示するための3つのビューを提供しており、さまざまな利用シーンに対応します。

## 3つのビュー

| ビュー | 説明 |
| --- | --- |
| **リストビュー** | アプリをコンパクトなリスト形式で表示し、各行にアイコン、名前、説明を表示。アプリが多い場合の素早い閲覧に適しています |
| **アイコンビュー** | アプリアイコンをグリッド形式で表示。視覚的にわかりやすく、アプリが少ない場合やアイコン認識を重視するシーンに適しています |
| **カードビュー** | アプリの評価、説明、タグなどの詳細情報をカード形式で表示。アプリの詳細管理に適しています |

## クイック切り替え

コレクション詳細ページで、右上の操作メニューの **ビュー切り替え** ボタンをタップすると、3つのビューをすばやく切り替えることができます。

## デフォルトビューの設定

コレクションに入るたびに同じビューを使用したい場合は、設定で固定できます：

**設定 → 一般 → 表示設定 → コレクションページ**で、お好みのデフォルトビューを選択します。

> **ヒント**：右上の切り替えボタンは「一時的」な切り替えで、設定での構成が「固定」ビューです。

::: info
カードビューはメンバーシップ機能です。AppBox Pro のサブスクリプションが必要です。カスタムソートのドラッグ＆ドロップはリストビューとアイコンビューでのみサポートされており、カードビューとグリッドビューではカスタムソート順に表示されますがドラッグ＆ドロップはサポートされていません。
:::
