# コレクション内フィルター

AppBox のコレクション詳細ページには、必要なアプリを素早く見つけるための強力なフィルター機能が用意されています。

## 概要

コレクション詳細ページで右上の **フィルター** アイコンをタップすると、フィルターパネルが開き、現在のコレクション内のアプリをさまざまな条件で絞り込むことができます。

## フィルター条件

| 条件 | 説明 |
| --- | --- |
| **キーワード** | アプリ名、説明、サブスクリプション説明からキーワード検索（最大50文字） |
| **評価** | 評価で絞り込み、「評価なし」と1～5つ星を含む |
| **タグ** | アプリタグで絞り込み、複数選択に対応 |
| **カテゴリ** | App Store のメインカテゴリで絞り込み |
| **ソース** | アプリのソースで絞り込み：App Store アプリまたはカスタムアプリ |
| **プラットフォーム** | 対応プラットフォームで絞り込み：iPhone、iPad、Mac |
| **地域** | App Store の地域で絞り込み（現在のコレクションに実際に存在する地域のみ表示） |

## 操作方法

1. コレクションを開く
2. 右上の **フィルター** アイコンをタップ
3. フィルターパネルで必要な条件を設定
4. 複数の条件は「かつ」の関係（同時にすべて満たす必要があります）
5. 設定完了後、アプリリストは自動的に更新されます

## フィルターのクリア

フィルターパネルの **クリア** ボタンをタップすると、すべてのフィルター条件がリセットされ、すべてのアプリが表示されます。

## ヒント

- 地域フィルターには現在のコレクションに実際に存在する地域のみ表示され、空のオプションは表示されません
- 複数の条件を組み合わせて正確な絞り込みが可能です。例：「タグ：効率化 + プラットフォーム：iPhone」
- キーワード検索はアプリ名と説明の両方を対象に検索します
