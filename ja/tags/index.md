# タグ

AppBoxでは、アプリにカスタムタグを追加して柔軟な分類と素早い検索ができます。

## 概要

タグは柔軟な分類方法です。コレクションとは異なり、1つのアプリに複数のタグを付けられ、同じタグを複数のアプリに使用できます。タグを使えば、コレクションを越えてアプリをすばやく絞り込んで検索できます。

## タグの追加

アプリ説明の編集ページで、1つ以上のタグを追加できます。

**手順**：アプリ詳細を開く → 説明を編集をタップ → タグエリアでタグを入力または選択

## タグ管理

設定で全てのタグを管理できます：

**手順**：設定 → アプリ → タグ管理

タグ管理ページでは：

- 使用中のすべてのタグを表示
- タグを検索
- タグ名を変更
- 不要なタグを削除

## タグでアプリを絞り込む

### ホームページのタグエリア

ホームページ下部にすべてのタグが表示されます。タグをタップすると、そのタグが付けられたアプリ一覧を表示します。

### コレクション内フィルタリング

コレクション詳細ページのフィルターパネルで、タグでアプリを絞り込めます。詳細は [コレクション内フィルタリング](/app-management/filtering) を参照。

## タグ表示設定

**手順**：設定 → 一般 → 表示設定 → アプリ詳細ページ

アプリ詳細ページでのタグ表示方法を設定できます：

- **タグを表示**：アプリ詳細ページでのタグ表示を切り替え
- **アイコンを表示**：タグの前にアイコンを表示するか切り替え
- **1行表示**：タグを1行で表示するか切り替え

::: info
タグデータは同期とインポート/エクスポートに対応しています。デバイスを変更してもタグは失われません。
:::
