# 統計機能

AppBoxは、アプリコレクションの状況を包括的に把握できる豊富な統計機能を提供します。

## 概要

下部ナビゲーションバーの **統計** タブをタップして、さまざまなデータチャートと分析結果を表示します。

::: info
統計機能はPro機能です。AppBox Proのサブスクリプションが必要です。未登録時はサンプルデータがプレビュー表示されます。
:::

## 主要指標

統計ページの上部に4つの主要指標カードが表示されます：

| 指標 | 説明 |
| --- | --- |
| **保存したアプリ** | 重複を除いたアプリ総数（タップで全リストを表示） |
| **コレクション数** | 作成したコレクションの総数 |
| **サブスクリプション支出** | すべてのサブスクリプションアプリの合計費用（タップで詳細表示） |
| **アプリ総数** | 重複を含むアプリ総数（タップで元リストを表示） |

## 統計チャート

### 評価分布
アプリにつけた評価の分布を表示し、評価の傾向を把握できます。

### サブスクリプションデータ
現在のサブスクリプション数、通貨別の月間支出、年間コスト推定などを表示します。タップすると詳細ページに移動します。

### 説明カバレッジ
説明が追加されているアプリの数と割合を表示します。

### 追加傾向
月ごとに保存したアプリ数の推移を統計表示し、コレクションの習慣を把握できます。

### プラットフォーム分布
対応プラットフォーム（iPhone、iPad、Mac）の分布を表示します。

### 地域分布
App Storeの国/地域の分布を表示します。

### カテゴリ分布
App Storeのメインカテゴリ別の分布を表示します。

## 統計範囲

デフォルトではすべてのコレクションのデータを集計します。範囲をカスタマイズできます：

1. 統計ページの右上の **範囲** ボタンをタップ
2. **すべてのコレクション** または特定のコレクションを選択
3. **コレクション間重複排除** を有効にして、異なるコレクションの同じアプリを統合

## カスタム統計

統計カードの表示順序と表示/非表示をカスタマイズできます：

1. 統計ページの右上の **カスタマイズ** ボタンをタップ
2. ドラッグしてカードの表示順序を調整
3. 目のアイコンをタップしてカードの表示/非表示を切り替え
4. **デフォルトに戻す** をタップしてデフォルトレイアウトにリセット

## サブスクリプション詳細

「サブスクリプション支出」または「サブスクリプションデータ」カードをタップすると、詳細ページに移動します：

- 月間支出統計
- 年間支出統計
- 総支出トレンド
- サブスクリプション内訳
- 費用分布チャート
- 期間と更新分析
