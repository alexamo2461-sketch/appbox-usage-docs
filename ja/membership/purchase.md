# 購入に関する説明

> 関連：[メンバーシップ機能の説明](/ja/membership/feature-overview)

## 購入についての注意事項

- 機能の改善に伴い、価格が変更される場合があります。開発者は、買い切りユーザーをサブスクリプションに変更しないことをお約束します。購入後の追加料金は一切発生しません。
- メンバーシップ期間中はすべての機能をご利用いただけます。購入後の返金はサポートしておりませんので、ご購入前に十分ご検討ください。
- Apple ID アカウント間での購入・サブスクリプションの移行はサポートしておりません。また、複数の App ID 間でのメンバーシップ共有もできません。

## 購入の復元

既にメンバーシップを購入済みであるにもかかわらず、ご利用中または再インストール後にメンバーシップ機能がご利用いただけない場合は、設定 → AppBox Pro 画面に移動し、「購入を復元」ボタンを手動でタップしてください。これにより以前のメンバーシップが復元されます（購入時に使用した Apple ID と同じである必要があります）。AppBox Pro 画面に「購入を復元」ボタンが表示されない場合は、メンバーシップは既に有効になっています。
