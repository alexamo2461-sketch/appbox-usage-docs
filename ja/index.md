# 📖 AppBox ユーザーガイド

AppBoxはその名の通り「アプリを入れるための箱」であり、アプリを収集・管理するためのツールです。「コレクション」を作成してお気に入りのアプリを整理し、コレクションの説明、アプリの説明、カスタム属性情報の記録などの機能を提供します。
