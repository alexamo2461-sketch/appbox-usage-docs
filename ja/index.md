# アプリをお気に入りに追加する方法

現在、AppBox は3つの方法を提供しており、それぞれ異なるインポートシーンに対応しています：

- [AppBox 内で直接追加](https://www.yuque.com/u291034/fz7nr2/rtasb6rnnqshtula)（名前検索、リンク認識、カスタム追加、一括追加に対応）
- [共有拡張機能でアプリを追加](https://www.yuque.com/u291034/fz7nr2/grvxkrxqxwpzuafi)（システム共有画面からすばやくインポート）
- QRコードまたはリンクから「他の人が共有したコレクションリスト」をインポート
- [データインポート：AppBox からエクスポートしたデータ](https://www.yuque.com/u291034/fz7nr2/gmco3thciffi8gbe)
- データインポート：Apple data
