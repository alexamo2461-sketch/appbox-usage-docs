# アプリ地域の使い方
**アプリ地域**とは、AppBox が App Store から **アプリ説明やアイコンなどの情報を取得する際に使用する国または地域のストア** を指します。

この機能を利用することで、
**特定地域で配信されているアプリを検索したり**、**地域ごとの名前やアイコンを表示したり**、さらに **複数アプリの地域情報をまとめて取得したり** できます。

:::info
**注意：** アプリの配信状況や翻訳された名称などの情報は、すべて該当する地域の App Store に基づきます。特定地域でアプリが利用できないと表示される場合、それはストア側の検索結果であり、コレクションが失われたことを意味するものではありません。
:::

## この機能が役立つ場面
+ **アプリ名で検索しても見つからない場合** → 地域を切り替えて再検索してください（特定のストアでのみ配信されているアプリがあります）。  
+ **同名アプリの区別が難しい場合** → 地域情報によって表示内容を区別できます。  
+ **リンク自体に地域情報が含まれている場合** → AppBox は **リンク内の地域情報を優先して認識** します（詳細は下記参照）。  
+ **複数国のアプリ一覧を管理したい場合** → **フィルター · 地域** を利用するか、先に **地域を一括変更** してから更新できます。

## 「設定」からアプリ地域を管理する
**設定 → アプリ → アプリ地域**

<!-- これは画像です。OCR 内容: -->
![](../../assets/region/region-settings.png)

ここは **「地域検索リスト」** です。有効化されている国・地域が表示され、**上から下へ** の順番が優先順位を表します（上位の地域ほど先に検索され、複数地域を試す場合にもこの順序が使用されます）。

| 操作 | 説明 |
| --- | --- |
| **地域を追加** | 「地域を追加」をタップし、一覧から地域を選択します。追加できるのは **最大 10 地域** までで、上限に達すると通知が表示されます。 |
| **削除** | 項目を **左へスワイプ** すると削除できます。最低でも **1 つの地域を残す必要があります**。 |
| **並べ替え** | 右上の **並べ替え** をタップし、順序をドラッグで変更してから **完了** を押して保存します。通常は **最上部の地域** がデフォルト優先として使用されます（特にリンクから地域を判別できない場合）。 |
| **リストが空の場合** | 「地域を追加」から地域を選択するよう案内が表示されます。 |

### 「地域を選択」リストとの違い
**アプリ追加** や **アプリ詳細ページ** などで表示される **「地域を選択」** の一覧には、通常「設定」で有効化済みの地域のみが表示されます（つまり上記の「地域検索リスト」）。これにより、地域を素早く切り替えることができます。

一方、「設定」の **地域を追加** は、**すべての地域一覧** から選択して、有効化リストを拡張するための機能です。

## App Store リンクと地域：認識ルール
App Store のアプリリンクを貼り付けたり共有したりすると、AppBox は可能な限りリンクから **国または地域情報** を解析します。例えば：

+ リンク内に `…/cn/app/…` や `…/us/app/…` のような **2 文字コード**（通常は小文字）が含まれている場合、対応する地域として認識されます（例：cn → 中国本土ストア、us → アメリカストア）。

| 状況 | システムの動作 |
| --- | --- |
| **リンクから地域を判別できる場合** | **アプリ追加 → アプリリンク** では、「国または地域」の項目は通常 **表示されません**。これはリンク内ですでに地域が指定されているためです。設定内の地域順序を変更しても、このリンク優先の判定ロジックは **変わりません**。 |
| **リンクから地域を判別できない場合** | **「国または地域」** の選択項目が表示されます（例：「中国本土 (cn)」）。この場合、設定で現在選択されている地域が使用されます。 |
| **複数リンクを同時に貼り付けた場合** | 内容全体が **単一地域付きリンク** として解釈できない場合、「国または地域」項目が通常 **表示されます**。複数リンクは今回選択した同じ地域設定を共有します。 |

**簡単に言うと：** リンクに地域情報が明確に含まれている場合はリンクを優先し、判別できない場合は AppBox の設定地域を使用します。

<!-- これは画像です。OCR 内容: -->
![](../../assets/region/app-detail-region.png)

### 地域を確認する
アプリ詳細ページで **「その他の情報」** を開くと、**「地域」** の項目に現在保存されているストアコードに対応する地域名が表示されます。

### 地域を変更する（App Store アプリのみ対応）
1. アプリ詳細ページ右上の **「⋯」** メニューから **「地域を変更」** を選択します。  
2. **「地域を選択」** から任意の地域を選び、確定します。  
3. AppBox が新しい地域の App Store に対して、アプリが存在するか再検索を行います。  
    - **成功した場合：** アプリ名、アイコンなどの情報が更新され（ストア側で提供されている場合）、**「変更完了」** が表示されます。  
    - **失敗した場合：** 例えば **「選択した地域の App Store では利用できません」** と表示された場合、誤った状態を防ぐため地域は自動的に変更前へ戻されます。

> **カスタムアプリ** には現在 **「地域を変更」** 機能は表示されません。これは情報がユーザーによって手動入力されているためです。
>

## アプリコレクション内で地域を管理する
<!-- これは画像です。OCR 内容: -->
![](../../assets/region/collection-region.png)

### 地域を一括変更する
同じ **アプリコレクション** 内で複数の App Store アプリを選択した場合、まとめて同じ地域へ切り替え、表示情報を更新できます。

#### 手順
1. 任意の **アプリコレクション** を開きます。  
2. 右上の **「⋯」** → **「アプリを選択」** をタップします。  
3. 複数のアプリを選択します。  
4. 下部ツールバーの **「地域」**（地球アイコン）をタップします。  
5. **「地域を選択」** から対象地域を選ぶと、AppBox が各アプリのストア情報を順番に再取得します。  
6. 完了後、**「地域一括変更結果」** ページで成功・失敗・スキップされたアプリをそれぞれ確認できます。

### フィルター（特定地域のみ表示）
アプリコレクション詳細ページ右上の **フィルター** アイコン → **「地域」** 項目 → 複数地域を選択可能。現在のコレクション内で条件に一致するアプリのみ表示されます。選択可能な地域は、**そのコレクション内に実際に存在する地域のみ** に限定されます。

## データインポートの「Apple Data」

**設定 → データインポート → Apple Data**  
インポート開始前に 1〜10 個の地域を選択できます。アプリ情報は一覧順に自動取得され、一致する情報が見つかるか、すべての戦略を試し終えるまで続行されます。

注意：地域を多く選択しすぎると、インポート速度が大幅に低下します。通常は 1〜3 地域程度の選択を推奨します。
