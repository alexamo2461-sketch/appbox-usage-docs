# ⚙️ 設定

AppBoxの設定ページには、使い方のカスタマイズやデータ管理のための豊富な設定オプションがあります。

## 一般

- [テーマ設定（色とモード）](/ja/settings/theme)：テーマモードとテーマカラーを設定
- **言語**：システム設定に移動してアプリ言語を変更
- [表示設定](/ja/settings/display-configuration)：コレクションページとアプリ詳細ページの表示オプションを設定

## コレクション

- [コレクション管理](/ja/collection-management/)：すべてのコレクションを表示・管理、複数選択削除に対応
- [空のコレクション検出](/ja/collection-management/empty-detect)：空のコレクションを自動検出し、削除を促す
- [共有管理](/ja/settings/share-management)：共有したコレクションリンクを管理

## アプリ

- **すべてのアプリ**：収集したすべてのアプリを表示（重複なし）、App Store への移動に対応
- [アプリ地域](/ja/region/)：App Store のクエリ地域リストを管理
- [タグ管理](/ja/tags/)：すべてのアプリタグを管理
- [アプリ属性](/ja/settings/app-properties)：サブスクリプション属性と価格属性の表示を設定

## データ

- [データ同期](/ja/sync/)：iCloud データ同期
- [データインポート](/ja/backup-restore/data-import)：AppBox データまたは Apple データをインポート
- [データエクスポート](/ja/backup-restore/export)：データを JSON または ZIP ファイルとしてエクスポート
- [データ管理](/ja/settings/data-management)：アプリ情報の更新、アイコンのダウンロード、キャッシュのクリア、データのリセット

## その他

- **ユーザーガイド**：オンラインヘルプドキュメントを開く
- **よくある質問**：アプリ内 FAQ ページ
- **フィードバック**：メールでフィードバックを送信
- **AppBox を評価**：App Store で評価
- **AppBox について**：アプリバージョンと開発者情報を表示
