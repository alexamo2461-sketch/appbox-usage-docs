# アプリ属性

アプリ属性設定は、アプリ説明を編集する際に表示される属性フィールドを制御します。

**アクセス方法**：設定 → アプリ → アプリ属性

## 設定可能な属性

### サブスクリプション属性

有効にすると、アプリ説明の編集時にサブスクリプション関連の入力項目が表示されます：

- サブスクリプション説明
- サブスクリプション価格
- 通貨
- サブスクリプションタイプ（月額、年額など）
- サブスクリプション開始/終了日

### 価格属性

有効にすると、アプリ説明の編集時に価格関連の入力項目が表示され、App Store からアプリの市場価格を自動取得できます。

::: info
アプリ属性の設定はメンバーシップ機能です。変更には AppBox Pro のサブスクリプションが必要です。メンバーシップ以外のユーザーはデフォルトでこれらの属性が有効になっています。
:::
