# 表示設定

表示設定ページでは、コレクションページとアプリ詳細ページの表示オプションをカスタマイズできます。

**アクセス方法**：設定 → 一般 → 表示設定

## コレクションページ設定

### アプリ表示モード

アプリをタップしたときのデフォルト動作を設定します：

| モード | 説明 |
| --- | --- |
| **App Store を開く** | アプリアイコンをタップすると App Store のアプリページに直接移動 |
| **AppBox でプレビュー** | アプリアイコンをタップすると AppBox 内でアプリ詳細プレビューを表示 |

### アプリビュー

コレクション詳細ページのデフォルトビュー（リスト、アイコン、またはカード）を設定します。

## アプリ詳細ページ設定

### 詳細の並べ替え

アプリ詳細ページの各セクションの表示順序をカスタマイズします：

- アプリのスクリーンショット
- アプリ情報
- 追加情報
- アプリ紹介
- 更新履歴

ドラッグして順序を調整するだけです。

### アプリ説明

- **説明がない場合は非表示**：アプリに説明が追加されていない場合、説明セクションを非表示にします（メンバーシップ機能）

### アプリタグ

- **タグを表示**：アプリ詳細ページでタグを表示するかどうかを制御
- **アイコンを表示**：タグ名の前にタグアイコンを表示するかどうかを制御
- **1行表示**：タグを1行で配置するかどうかを制御
