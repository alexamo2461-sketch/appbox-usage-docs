## V1.5

> 日付：2025-12-26

**0. 注意事項：**

- V1.4 と比較してデータモデルがアップグレードされているため、データ更新操作が必要です。プロンプトが自動表示されるので、確認して更新を実行してください
- 更新後は設定 → データ更新 → 更新履歴で状況を確認できます。失敗したデータは手動で削除して再追加してください
- まだ旧データを復元できていない方は、開発者ツールを使用して復元を試みてください。操作方法は設定 → ユーザーガイド → よくある質問をご参照ください

**1. 変更点：**

- Mac 専用ソフトウェアのリンクインポートに対応
- アプリ説明の文字数制限を 200 文字から 2000 文字に変更
- ホーム画面のレイアウトを調整、下部アクションバーを追加し、並べ替えとビュー切替を右上のアクションメニューに移動
- アプリのコピー/移動時にサブスクリプション情報を同期

**2. 新機能：**

- コレクションの並べ替え：名前（A-Z および Z-A）、作成日時（新しい順および古い順）でソート可能
- カスタムインポート：アイコン、名前、ソースなどの情報をユーザーが入力可能
- AppBox 内でアプリ名を直接検索して追加可能
- アプリ詳細ページに「詳細情報」セクションを追加、インポート日時・地域・ソースリンクを表示
- データエクスポート時にアプリアイコンファイルと JSON ファイルを含む完全な圧縮パッケージを出力
- アプリ詳細ページにアプリの App ID を表示、アプリ紹介と更新履歴セクションに翻訳ボタンを追加
- アプリ地域選択：新規アプリ追加時に地域を選択可能、地域の並べ替えにも対応（設定 → アプリ地域）
- 検索結果ページでコレクションとアプリの長押しメニュー（編集、コピー/移動、削除）に対応
- 完全なテンプレートとフィールド説明を提供、テンプレートファイルの一括インポートに対応
- アイコンキャッシュ機能：アプリアイコンをローカルにダウンロード、オフラインでも表示可能
- インポート時のアプリ説明編集に対応（ホーム画面追加モジュール、コレクション詳細ページの両方で対応）
- 旧バージョンデータベース復元用の開発者ツールを追加

**3. その他：**

- アプリインポートロジック全体を最適化：AppBox はリンクから `id1234567890` 形式の数値 ID を抽出し、App Store に問い合わせてアプリ情報を取得します。地域選択戦略：リンクに明示的な地域コード（`/cn/`、`/us/` など）がある場合はそれを優先使用；地域コードがない場合は、設定 → アプリ地域のリストを上から順にリクエストします。「共通」は特定の国/地域ではなく、Apple サーバーがリクエスト環境に基づいて自動推測する結果です（大部分は米国）。詳細は設定 → ユーザーガイド → よくある質問 → アプリリンク認識ルールと地域機能の使い方をご参照ください
