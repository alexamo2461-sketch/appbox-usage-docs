# 应用地区怎么用
**应用地区**指：AppBox 向 App Store **查询介绍、图标等信息**时，使用的 **哪一个国家或地区的商店**。

它能帮你：**搜到该地区上架的应用**、**按该地区展示名称与图标**、**批量统一查询地区**。

:::info
**注意：** 是否上架、名称翻译等 **以该地区 App Store 为准**；提示该地区无此应用是商店侧结果，不是收藏丢失。

:::

## 何时会用到
+ **名字搜不到** → 换地区再搜（有的应用只在特定商店上架）。  
+ **同名分不清** → 用地区区分展示信息。  
+ **链接里自带地区** → AppBox **优先按链接**识别（见下）。  
+ **多国清单** → 用 **筛选 · 地区** 查看，或 **批量修改地区** 后再刷新。

## 在「设置」中管理应用地区
**设置 → 应用 → 应用地区**

<!-- 这是一张图片，ocr 内容为： -->
![](/assets/region/region-settings.png)

这里是 **「地区查询列表」**：已启用的国家或地区，**从上到下**表示优先顺序（排前面的会先用来查；需要多地区尝试时也会参考这一顺序）。

| 操作 | 说明 |
| --- | --- |
| **添加地区** | 点「添加地区」，从目录里选；**最多 10 个**，满了会有提示。 |
| **删除** | 行上 **左滑** 删除；**至少保留 1 个**。 |
| **排序** | 右上角 **排序**，拖好后 **勾选** 保存。**最上面**的一般作默认优先（尤其链接里看不出地区时）。 |
| **列表为空** | 页面会提示：请通过「添加地区」选择。 |


### 与「选择地区」列表的区别
在 **新增应用**、**应用详情** 等地方弹出的 **「选择地区」** 里，一般只出现你在设置里 **已经启用** 的地区（即上面的「地区查询列表」），方便快速切换。

设置里的 **添加地区** 则从 **完整目录** 里挑选，用来扩充这份启用列表。

## App Store 链接与地区：识别规则
当你粘贴或分享 **App Store 应用链接** 时，AppBox 会尽量从链接里读出 **国家或地区**，例如：

+ 链接地址里带有类似 `…/cn/app/…`、`…/us/app/…` 这样的 **两位字母**（常见为小写），通常会被识别为对应地区（如 cn → 中国大陆店面、us → 美国店面等）。

| 情况 | 你怎么操作 |
| --- | --- |
| **链接里能看出地区** | **新增应用 → 应用链接** 里往往 **不出现**「国家或地区」行（已由链接指明）。改设置里的列表顺序，**不改变**这类链接优先按链接解析的习惯。 |
| **链接里看不出地区** | 会出现 **「国家或地区」**（例如「中国大陆 (cn)」），用的是你在设置里维护的当前选择。 |
| **一次粘贴多条链接** | 若整段 **没法** 当成「单条带地区的链接」解析，通常会 **显示**「国家或地区」；多条 **共用** 这一次选的地区策略。 |


**一句话：** 链接里写清了就跟链接走；写不清就跟你在 AppBox 里选的地区走。

### 查看地区
在应用详情中打开 **「更多信息」**，其中一行 **「地区」** 展示本条收藏当前对应的店面代码所对应的名称。

### 修改地区（仅商店来源应用）
1. 在应用详情右上角 **「⋯」** 菜单中，点 **「修改地区」**。  
2. 在 **「选择地区」** 中任选一项并确认。  
3. AppBox 会 **向商店重新询问** 该款应用在新区是否存在；  
    - **成功**：会更新名称、图标等信息（若商店提供），并提示 **修改成功**；  
    - **失败**：例如提示 **「当前所选地区商店无此应用」**，地区会 **恢复为修改前**，避免留下错误状态。

> **自定义应用** 目前不会出现 **「修改地区」**，因其信息由你自行填写。
>

### 批量修改地区
**同一应用集**里已 **多选** 多条商店来源的应用，希望一次性切换到同一地区并尝试更新展示信息。

#### 操作步骤
1. 打开某个 **应用集**。  
2. 点右上角 **「⋯」** → **「选择应用」**。  
3. 勾选多条应用。  
4. 点底部工具栏 **「地区」**（地球图标）。  
5. 在 **「选择地区」** 里点选目标地区；App 会逐条尝试拉取商店信息。  
6. 完成后可查看 **「批量修改地区结果」**：成功与失败或跳过的应用会分列说明。

### 筛选（只看某些地区）
应用集详情右上角 **筛选** 图标 → 表单 **「地区」** → 可多选，只显示当前应用集中匹配的应用。可选地区为 **本应用集里实际出现过的地区**。

## 数据导入里的「Apple Data」


**设置 → 数据导入 → Apple Data** 在导准备导入时可选择1-10个地区，按照列表顺序进行自动获取应用信息，直到命中或用尽策略。

注意，当地区选择个数过多时，导入时的速度会明显变慢，建议勾选1-3个为宜。
