# Informations d'achat

> Connexe : [Fonctionnalités d'abonnement](/fr/membership/feature-overview)

## Notes d'achat

- À mesure que les fonctionnalités s'améliorent, le prix peut être ajusté. Le développeur promet : les acheteurs uniques ne seront pas convertis en abonnement — aucun paiement supplémentaire n'est nécessaire après l'achat.
- Toutes les fonctionnalités sont disponibles pendant la période d'abonnement. Aucun remboursement n'est possible après l'achat, veuillez donc réfléchir attentivement avant d'acheter.
- Les achats/abonnements ne peuvent pas être transférés entre différents comptes Apple ID. L'abonnement ne peut pas être partagé entre plusieurs App ID.

## Restaurer l'achat

Si vous avez déjà acheté l'abonnement mais que vous ne pouvez pas utiliser ses fonctionnalités pendant l'utilisation ou après une réinstallation, allez dans Réglages → AppBox Pro et appuyez manuellement sur le bouton « Restaurer l'achat » pour restaurer votre statut d'abonnement précédent (vous devez utiliser le même Apple ID que celui utilisé lors de l'achat). Si le bouton « Restaurer l'achat » n'apparaît pas sur la page AppBox Pro, votre abonnement est déjà actif.
