# Ajout direct dans AppBox

Vous pouvez ouvrir l'interface "Ajouter une app" via les entrées suivantes :

+ Sur la page d'accueil des **Collections d'apps** : utilisez le bouton **Ajouter une app** en bas à droite ; s'il n'est pas affiché, cliquez sur **"Ajouter une app"** dans le menu en haut à droite.
+ Sur une page de **Détails d'une collection d'apps** : cliquez sur **Ajouter une app** (si vous organisez uniquement la liste actuelle, la collection cible sera automatiquement définie sur la collection actuelle).

![Entrée Ajouter une app](/assets/how-to-add-apps/entry-screenshot.png)

Après ouverture, vous pouvez basculer les onglets supérieurs selon vos besoins : **Nom de l'app**, **Lien de l'app**, **Personnalisé**. Dans la zone d'aperçu, cliquez sur "Modifier la description" pour ouvrir une page d'édition permettant d'enregistrer rapidement les notes, descriptions et autres attributs.

![Interface Ajouter une app](/assets/how-to-add-apps/add-app-interface.png)

# Rechercher et ajouter par nom (Rechercher dans l'App Store)

## Présentation
Sous la méthode **Nom de l'app**, saisissez des mots-clés pour rechercher et sélectionner des applications depuis l'App Store, puis ajoutez-les à votre collection.

![Rechercher par nom](/assets/how-to-add-apps/search-by-name.png)

## Cas d'utilisation
+ Vous avez seulement le nom de l'application, pas le lien.
+ Vous souhaitez comparer des applications portant le même nom et vérifier l'icône avant d'ajouter.

## Étapes
1. Ouvrez **Ajouter une app** et sélectionnez **Nom de l'app**.
2. Saisissez le nom ou un mot-clé dans la zone de saisie et cliquez sur **Rechercher dans l'App Store**.
3. Dans les **Résultats de recherche**, vous pouvez changer de **Région** et rechercher à nouveau (si nécessaire).
4. Appuyez sur **Ajouter** sur une ligne spécifique pour la sélectionner ; la sélection multiple est possible.
5. Une fois la sélection effectuée, cliquez sur Confirmer en haut à droite pour revenir à la page précédente.
6. Sélectionnez la **Collection d'apps cible** ; dans la zone d'aperçu, vous pouvez modifier les descriptions ou les tags.
7. Cliquez sur **Ajouter** ou **Continuer à ajouter** en bas.

## Notes
+ Les résultats de recherche proviennent de l'App Store de la région sélectionnée ; les listes peuvent varier selon la région.
+ La zone d'aperçu affiche les applications sélectionnées ; vérifiez avant d'enregistrer.

::: info
Prend en charge la reconnaissance de texte à partir de captures d'écran ou d'images. Il remplit les **noms d'applications** potentiels dans le champ de recherche. Une fois la reconnaissance terminée, vous pouvez confirmer ou modifier le texte reconnu sur la page des résultats.
:::

## Précautions
> **Remarque** : Si une application est introuvable, cela est souvent lié à la **Région de l'App Store** actuellement sélectionnée. Vous pouvez changer de région sur cette page ou dans les paramètres et rechercher à nouveau.

# Ajouter en saisissant et reconnaissant un lien App Store

## Présentation
En collant un lien vers une page d'application de l'App Store, AppBox récupère des informations telles que l'icône et le nom, et ajoute l'application à la collection sélectionnée.

![Ajouter par lien](/assets/how-to-add-apps/add-by-link.png)

## Cas d'utilisation
+ Vous voyez une série de liens App Store dans une communauté, une page Web ou une note et souhaitez les sauvegarder immédiatement.
+ Vous avez déjà copié le lien et ne souhaitez pas rechercher le nom dans le magasin.

## Étapes
1. Ouvrez la page **Ajouter une app**.
2. Cliquez sur **Lien de l'app** dans le segment supérieur.
3. Collez le lien dans la zone de saisie (après collage, la **reconnaissance automatique** commence généralement), ou cliquez sur **Reconnaître depuis le presse-papiers** pour utiliser le texte complet du presse-papiers.
4. Si un emplacement de stockage n'a pas été choisi, sélectionnez une ou plusieurs collections dans **Collection d'apps cible**.
5. Pour interroger un magasin régional spécifique, ajustez la **Région** sur cette page (cohérente avec "Paramètres → Application → Région de l'App Store").
6. Confirmez si l'entrée est correcte dans **Aperçu de l'application** ; vous pouvez modifier les descriptions ou sélectionner des tags ici.
7. Cliquez sur **Ajouter** en bas pour enregistrer et fermer ; ou cliquez sur **Continuer à ajouter** pour rester sur cette page et poursuivre les opérations.

::: info
Prend en charge **plusieurs liens** : dans la même zone de saisie, utilisez des **sauts de ligne** ou des **points-virgules anglais** `;` pour séparer plusieurs liens App Store. Il tente automatiquement la reconnaissance lorsque le contenu change ; vous pouvez également utiliser **Reconnaître depuis le presse-papiers**.
:::

## Notes
+ Une liste d'aperçu apparaît après une reconnaissance réussie ; en cas d'échec, la page fournit une brève raison, vous permettant de vérifier si le lien est complet.
+ Si le lien contient des informations régionales, il est généralement reconnu selon cette région ; vous pouvez également changer manuellement de région et réessayer. Règles de reconnaissance des liens : [Régions d'app & reconnaissance de liens](/fr/region/fr)

## Utilisation recommandée
+ Placez d'abord les éléments dans une collection d'applications par défaut, puis organisez-les plus tard dans des collections classifiées pour réduire les opérations répétitives.
+ Lors de la collecte en masse de "listes d'applications" à partir d'articles, vous pouvez coller plusieurs liens à la fois, puis confirmer les aperçus ensemble.

# Ajout personnalisé d'application (Saisie manuelle)

## Présentation
Remplissez manuellement des informations telles que le nom de l'application, l'icône et le lien source. Ceci est utilisé pour les entrées qui ne peuvent pas être trouvées dans le magasin ou pour lesquelles vous souhaitez un contrôle total sur l'affichage.

![Ajout personnalisé](/assets/how-to-add-apps/custom-add.png)

## Cas d'utilisation
+ Applications non encore répertoriées, retirées ou distribuées uniquement via des canaux spécifiques, mais que vous souhaitez tout de même conserver dans votre liste.
+ Vous devez conserver une icône personnalisée et des notes pour une application/logiciel non App Store.

## Étapes
1. Ouvrez **Ajouter une app** et sélectionnez **Personnalisé**.
2. Cliquez sur la zone d'icône et suivez les instructions pour obtenir une icône depuis la **Photothèque**, les **Fichiers** ou via un **Lien d'image** (`http`/`https`, PNG/JPG recommandé).
3. Remplissez le **Nom de l'application** (obligatoire).
4. Remplissez le **Lien source** si nécessaire (adresse Web ou d'instructions).
5. Sélectionnez la **Collection d'apps cible**.
6. Modifiez les informations connexes telles que la description, l'évaluation, l'abonnement et les tags dans la zone d'aperçu.
7. Cliquez sur **Ajouter** en bas pour enregistrer.

## Notes
+ Il est recommandé de remplir le lien source avec le site officiel ou une page de confiance pour faciliter les vérifications futures.
+ L'affichage des entrées personnalisées dépend du contenu que vous fournissez ; il ne se synchronisera pas automatiquement avec les pages de détail du magasin comme le font les applications du magasin.
+ Si l'application affiche des restrictions d'abonnement pour cette fonctionnalité, suivez les instructions vers la page de description de l'abonnement si elle n'est pas déverrouillée.

## Précautions
+ Les entrées personnalisées diffèrent des entrées ajoutées depuis le magasin en termes de méthode de mise à jour ; les applications du magasin peuvent être actualisées sur la page de détails, tandis que les entrées personnalisées doivent être modifiées manuellement.
+ Essayez de choisir des icônes carrées de haute résolution ; évitez d'agrandir de petites captures d'écran.

# Reconnaître le nom de l'application via une capture d'écran

## Présentation
Reconnaissez le texte à partir de captures d'écran ou d'images, remplissez les **noms d'applications** potentiels dans le champ de recherche, puis terminez l'ajout en combinant avec [Rechercher et ajouter par nom (Rechercher dans l'App Store)](#rechercher-et-ajouter-par-nom-rechercher-dans-lapp-store).

![Reconnaissance par capture d'écran 1](/assets/how-to-add-apps/screenshot-recognize-1.png)

## Cas d'utilisation
+ Vous avez seulement une capture d'écran d'application sans lien copiable. Vous souhaitez extraire rapidement le titre de l'image comme mot-clé de recherche.

![Reconnaissance par capture d'écran 2](/assets/how-to-add-apps/screenshot-recognize-2.png)

## Étapes
1. Ouvrez **Ajouter une app** → **Nom de l'app**.
2. À droite du champ de saisie du nom, cliquez sur **Reconnaître l'app dans l'image** (icône de viseur).
3. Sélectionnez **Choisir dans les photos** ou **Choisir dans les fichiers**.
4. Une fois la reconnaissance terminée, vous pouvez confirmer ou modifier le texte reconnu sur la page des résultats avant de confirmer la recherche.

## Notes
+ Le but de la reconnaissance est de réduire la saisie. Il reconnaît tout le texte dans la capture d'écran ; dans la plupart des cas, une confirmation secondaire de l'utilisateur est nécessaire avant la recherche.
