# Comment ajouter des applications aux favoris

AppBox propose actuellement 3 méthodes, chacune adaptée à différents scénarios d'importation :

- [Ajout direct dans AppBox](https://www.yuque.com/u291034/fz7nr2/rtasb6rnnqshtula) (recherche par nom, reconnaissance de lien, ajout personnalisé, importation groupée)
- [Ajout via l'extension de partage](https://www.yuque.com/u291034/fz7nr2/grvxkrxqxwpzuafi) (importation rapide depuis la feuille de partage système)
- Importer une « liste de collections partagée » via QR code ou lien
- [Importation de données : données exportées depuis AppBox](https://www.yuque.com/u291034/fz7nr2/gmco3thciffi8gbe)
- Importation de données : Apple data
