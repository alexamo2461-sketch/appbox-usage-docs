# Tags

AppBox prend en charge l'ajout de tags personnalisés aux applications pour une catégorisation flexible et une recherche rapide.

## Aperçu

Les tags offrent une méthode de catégorisation flexible. Contrairement aux collections, une application peut avoir plusieurs tags, et le même tag peut être appliqué à plusieurs applications. Les tags vous permettent de filtrer et trouver rapidement des applications dans toutes vos collections.

## Ajouter des tags

Dans la page d'édition de la description de l'application, vous pouvez ajouter un ou plusieurs tags.

**Étapes** : Ouvrir les détails de l'app → Appuyer sur modifier la description → Saisir ou sélectionner des tags dans la zone de tags

## Gérer les tags

Vous pouvez gérer tous les tags dans les paramètres :

**Étapes** : Paramètres → Apps → Gestion des tags

Dans la page de gestion des tags, vous pouvez :

- Voir tous les tags utilisés
- Rechercher des tags
- Renommer des tags
- Supprimer les tags indésirables

## Filtrer par tags

### Zone de tags sur la page d'accueil

La page d'accueil affiche tous les tags en bas. Appuyez sur un tag pour voir toutes les apps avec ce tag.

### Filtrage dans une collection

Dans le panneau de filtrage des détails de collection, vous pouvez filtrer par tags. Voir [Filtrage dans une collection](/app-management/filtering) pour plus de détails.

## Paramètres d'affichage des tags

**Étapes** : Paramètres → Général → Configuration de l'affichage → Page de détails

Vous pouvez configurer l'affichage des tags sur la page de détails :

- **Afficher les tags** : Activer/désactiver l'affichage des tags
- **Afficher l'icône** : Afficher une icône avant chaque tag
- **Affichage sur une ligne** : Afficher les tags sur une seule ligne

::: info
Les données de tags prennent en charge la synchronisation et l'import/export — vos tags ne seront pas perdus lors du changement d'appareil.
:::
