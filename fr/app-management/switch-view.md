# Changer la vue de l'application

La page de détails de la collection propose 3 vues pour afficher les applications, adaptées à différents scénarios d'utilisation.

## Trois vues

| Vue | Description |
| --- | --- |
| **Vue en liste** | Affiche les apps dans un format de liste compacte, avec icône, nom et description par ligne — idéal pour parcourir rapidement avec de nombreuses apps |
| **Vue en icônes** | Affiche les icônes d'apps dans une grille — visuellement attrayant et idéal pour peu d'apps ou une reconnaissance par icône |
| **Vue en cartes** | Affiche les apps sous forme de cartes avec notes, descriptions, étiquettes et plus — idéal pour une gestion détaillée des apps |

## Basculement rapide

Sur la page de détails de la collection, appuyez sur le bouton **Changer la vue** dans le menu d'actions en haut à droite pour basculer rapidement entre les trois vues.

## Définir la vue par défaut

Si vous souhaitez utiliser la même vue à chaque fois que vous entrez dans une collection, vous pouvez la définir dans les réglages :

**Réglages → Général → Configuration de l'affichage → Page de collection**, choisissez votre vue par défaut préférée.

> **Astuce** : Le bouton de basculement en haut à droite est un basculement « temporaire » ; le réglage dans la configuration est la vue « permanente ».

::: info
La vue en cartes est une fonctionnalité Pro et nécessite un abonnement AppBox Pro. Le tri personnalisé prend en charge le glisser-déposer uniquement en vue liste et vue icônes ; la vue cartes et les dispositions en grille affichent les éléments dans l'ordre de tri personnalisé mais ne prennent pas en charge le glisser-déposer.
:::
