# Changer la vue de l'application

La page de détails de la collection propose 2 vues pour afficher les applications : « Vue en icônes » et « Vue en liste ».

Le bouton de changement de vue dans le menu d'actions en haut à droite est un bouton « temporaire » — vous pouvez basculer librement entre les deux vues. Pour définir une vue par défaut fixe, allez dans Réglages → Général → Vue de l'application. Ainsi, la disposition des applications utilisera toujours votre vue préférée lorsque vous entrez dans la page de détails de la collection.
