# Copier/Déplacer une application

Sur la page de détails de la collection, appuyez longuement sur une application et appuyez sur le bouton « Copier/Déplacer » dans le menu contextuel pour copier ou déplacer l'application vers une autre collection. Vous pouvez sélectionner plusieurs collections de destination lors de la copie, mais une seule lors du déplacement.

Vous pouvez également utiliser la sélection multiple pour copier/déplacer plusieurs applications à la fois : [Opérations multi-sélection](/fr/app-management/multi-select)
