# Modifier la description de l'application

Vous pouvez ajouter des évaluations personnalisées et des notes aux applications d'une collection. Les évaluations et les notes s'affichent sous l'icône et le titre de l'application dans la section des informations.

**Comment y accéder** : Il existe plusieurs points d'entrée :

1. Appuyez sur le bouton d'édition dans le coin supérieur gauche sur la page de détails de l'application
2. La zone d'aperçu après l'ajout d'une application via le module d'ajout de la barre d'outils inférieure
3. La zone d'aperçu après la reconnaissance d'une application via le bouton d'ajout sur la page de détails de la collection

![Modifier la description de l'application](/app-management/edit-description.png)

> **Remarque** : Les notes d'une même application dans différentes collections sont indépendantes. Par exemple, si "TikTok" existe à la fois dans la collection A et la collection B, leurs évaluations, notes et attributs d'abonnement sont indépendants et ne se synchronisent pas. Il s'agit d'une fonctionnalité, pas d'un bug. Pour rendre les notes identiques, utilisez la fonction de copie pour copier manuellement l'application dans une autre collection. Après cela, la modification des notes dans une collection ne sera pas synchronisée avec l'autre.
