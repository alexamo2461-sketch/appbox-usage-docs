# Filtrage dans les collections

La page de détails de collection dans AppBox offre de puissantes fonctionnalités de filtrage pour vous aider à localiser rapidement les applications dont vous avez besoin.

## Aperçu

Sur la page de détails de la collection, appuyez sur l'icône **Filtrer** en haut à droite pour ouvrir le panneau de filtrage, où vous pouvez filtrer les applications de la collection actuelle selon divers critères.

## Critères de filtrage

| Critère | Description |
| --- | --- |
| **Mot-clé** | Rechercher des mots-clés dans le nom de l'app, la description et les notes d'abonnement (jusqu'à 50 caractères) |
| **Note** | Filtrer par votre note, y compris « Aucune note » et 1 à 5 étoiles |
| **Étiquettes** | Filtrer par étiquettes d'app, avec sélection multiple |
| **Catégorie** | Filtrer par catégorie principale de l'App Store |
| **Source** | Filtrer par source d'app : apps de l'App Store ou apps personnalisées |
| **Plateforme** | Filtrer par plateforme prise en charge : iPhone, iPad, Mac |
| **Région** | Filtrer par région de l'App Store (affiche uniquement les régions présentes dans la collection actuelle) |

## Étapes

1. Ouvrir une collection
2. Appuyer sur l'icône **Filtrer** en haut à droite
3. Définir les critères souhaités dans le panneau de filtrage
4. Plusieurs critères sont combinés avec « ET » (tous doivent être satisfaits simultanément)
5. Une fois défini, la liste des apps se met à jour automatiquement

## Effacer les filtres

Appuyez sur le bouton **Effacer** dans le panneau de filtrage pour réinitialiser tous les critères et afficher toutes les applications.

## Astuces

- Le filtre par région n'affiche que les régions présentes dans la collection actuelle — aucune option vide
- Combinez plusieurs critères pour un filtrage précis, par ex. « Étiquette : Productivité + Plateforme : iPhone »
- La recherche par mot-clé correspond à la fois aux noms d'apps et au contenu des descriptions
