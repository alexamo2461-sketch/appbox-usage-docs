# Opérations multi-sélection

Sur la page de détails de la collection, appuyez sur le bouton d'action (Menu contextuel) dans le coin supérieur droit → Sélectionnez « Sélectionner des applications » pour entrer en mode de sélection, où vous pouvez copier, déplacer ou supprimer plusieurs applications à la fois.
