# Fonction de traduction

La page de détails de l'application offre une fonction de traduction pour le contenu récupéré depuis l'App Store, y compris les sections de description et d'historique des mises à jour.

**Comment faire** : Ouvrez la page de détails de l'application → Appuyez sur le bouton de traduction dans le coin supérieur droit de la section description ou historique des mises à jour pour ouvrir la page de traduction système.

> **Remarque** : Cette fonction utilise l'API de traduction intégrée au système iOS. Si la traduction n'est pas disponible, veuillez vérifier si votre appareil a installé d'autres logiciels ou plugins de traduction (tiers).
>
> Documentation de l'API associée : [Translation | Apple Developer Documentation](https://developer.apple.com/documentation/translation/)

## Remplacer par la traduction

Cette fonction permet d'insérer le texte traduit pour remplacer le contenu original dans la section. Veuillez noter qu'actuellement (V1.5), il s'agit d'un remplacement temporaire — fermer et rouvrir la page de détails de l'application actualisera et affichera le contenu original.
