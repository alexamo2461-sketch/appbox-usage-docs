# Page de détails de l'application

La page de détails de l'application comprend le contenu suivant :

- **Informations de base** : Icône de l'application, nom de l'application et bouton de navigation
- **Notes de l'application** : Affiche votre évaluation personnalisée, vos notes et les attributs liés à l'abonnement.
- **Captures d'écran** : Affiche les captures d'écran de l'application, pouvant montrer plusieurs plates-formes simultanément.
- **Informations sur l'application** : Dernières informations de l'application récupérées depuis l'App Store, y compris l'ID de l'application, le développeur, le prix, la taille, etc.
- **Description** : Description de l'application récupérée depuis l'App Store.
- **Historique des mises à jour** : Les dernières notes de mise à jour récupérées depuis l'App Store.
- **Plus d'informations** : Région App Store de l'application, date d'ajout à la collection et lien source.
