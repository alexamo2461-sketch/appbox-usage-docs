# Fonction de tri de l'ordre d'affichage

Cette fonction permet d'ajuster l'ordre d'affichage des sections suivantes sur la page de détails de l'application :

- **Captures d'écran** : Affiche les captures d'écran de l'application, pouvant montrer plusieurs plates-formes simultanément.
- **Informations sur l'application** : Dernières informations de l'application récupérées depuis l'App Store.
- **Description** : Description de l'application récupérée depuis l'App Store.
- **Historique des mises à jour** : Les dernières notes de mise à jour récupérées depuis l'App Store.
- **Plus d'informations** : Région App Store de l'application, date d'ajout à la collection et lien source.

**Comment faire** : Réglages → Ordre d'affichage de l'application → Faites glisser la liste pour réorganiser.
