# Récupération des données perdues

:::: info
**Conditions préalables importantes pour la récupération des données :**

+ L'application ne doit **pas** avoir été désinstallée et réinstallée.
+ Les données doivent encore être présentes sous **Réglages > Général > Stockage iPhone > AppBox > Documents & Données**.

Si vous rencontrez des problèmes, veuillez aller dans **Réglages > Commentaires** pour me contacter à tout moment.
::::

Appuyez sur **Réglages** → **FAQ** → **Perte de données** → **Appuyer pour réparer** → ouvrez la page **Résultats d'analyse** → vérifiez combien de bases de données sont détectées. Si deux bases de données sont affichées, cela signifie que l'ancienne base de données existe encore. Appuyez sur le bouton **Fusionner toutes les données disponibles dans la base de données principale** en bas pour restaurer les données.
