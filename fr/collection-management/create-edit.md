# Créer et modifier une collection

## Créer une nouvelle collection

Considérez une collection comme une « liste » ou un « dossier ». Sur la page d'accueil, appuyez sur l'icône **Ajouter une collection** en haut à droite pour ouvrir la page de création. Vous pouvez saisir un nom, une couleur et une description pour créer votre nouvelle collection.

![Créer une collection](/collection-management/create-collection-en.png)

## Modifier une collection

Appuyez longuement sur une collection pour afficher le menu contextuel, ou appuyez sur le bouton **Modifier la collection** dans la page des détails de la collection pour ouvrir l'éditeur. Vous pouvez modifier le nom, la couleur et la description de la collection.

![Modifier une collection](/collection-management/edit-collection-en.png)

## Couleurs des collections

Lors de l'ajout ou de la modification d'une collection, vous pouvez définir une couleur personnalisée. Cette couleur se reflète principalement dans l'arrière-plan de la description de la collection, le bouton d'ajout, les icônes du menu d'action en haut à droite et les accents de mise en évidence dans les pages de détails des applications accessibles depuis cette collection.

![Couleur de collection](/collection-management/collection-color.png)
