# ⚙️ Réglages

La page de réglages d'AppBox offre de nombreuses options de configuration pour personnaliser votre expérience et gérer vos données.

## Général

- [Réglages du thème (couleur et mode)](/fr/settings/theme) : Définir le mode et la couleur du thème
- **Langue** : Accéder aux réglages système pour changer la langue de l'app
- [Configuration de l'affichage](/fr/settings/display-configuration) : Configurer les options d'affichage des pages de collection et de détails

## Collections

- [Gestion des collections](/fr/collection-management/) : Voir et gérer toutes les collections, avec suppression par sélection multiple
- [Détection des collections vides](/fr/collection-management/empty-detect) : Détecter automatiquement les collections vides et proposer leur suppression
- [Gestion des partages](/fr/settings/share-management) : Gérer les liens de collection partagés

## Apps

- **Toutes les apps** : Voir toutes les apps collectées (dédoublonnées), avec accès à l'App Store
- [Régions d'app](/fr/region/) : Gérer la liste des régions de requête App Store
- [Gestion des étiquettes](/fr/tags/) : Gérer toutes les étiquettes d'app
- [Propriétés de l'app](/fr/settings/app-properties) : Configurer l'affichage des propriétés d'abonnement et de prix

## Données

- [Synchronisation](/fr/sync/) : Synchronisation des données iCloud
- [Importation de données](/fr/backup-restore/data-import) : Importer des données AppBox ou Apple
- [Exportation de données](/fr/backup-restore/export) : Exporter les données au format JSON ou ZIP
- [Gestion des données](/fr/settings/data-management) : Rafraîchir les infos, télécharger les icônes, nettoyer le cache, réinitialiser

- **Noter AppBox** : Noter sur l'App Store
