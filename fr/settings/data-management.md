# Gestion des données

La page de gestion des données offre des fonctionnalités pour rafraîchir les informations des apps, télécharger les icônes, nettoyer les caches et réinitialiser les données.

**Accès** : Réglages → Données → Gestion des données

## Télécharger les icônes hors ligne

Téléchargez toutes les icônes d'app sur votre appareil local afin qu'elles s'affichent correctement même sans connexion Internet.

Il est recommandé d'effectuer cette opération avec une bonne connexion réseau. Le processus de téléchargement peut prendre un certain temps selon le nombre d'apps.

## Rafraîchir les informations des apps

Récupérez les dernières informations des apps depuis l'App Store, y compris le nom, l'icône, les captures d'écran, la description, le prix, etc.

Vous verrez une liste des apps en attente de rafraîchissement, avec la possibilité de les rafraîchir par lots. Le processus s'exécute en arrière-plan et n'affecte pas l'utilisation normale.

> **Astuce** : Le rafraîchissement n'écrase pas vos propres notes, descriptions ou étiquettes.

## Nettoyer le cache

### Nettoyer le cache d'icônes invalide

Supprimez les fichiers de cache d'icônes qui ne sont plus valides ou utilisés, libérant ainsi de l'espace de stockage. Utile lorsque les icônes s'affichent incorrectement ou que le cache occupe trop d'espace.

### Nettoyer les données d'app invalides

Nettoyez les enregistrements de données d'app orphelins. Utile en cas d'anomalies de données ou pour libérer de l'espace.

## Réinitialisation des données

> **Attention** : Les opérations suivantes sont irréversibles. Veuillez procéder avec prudence.

**Supprimer les données locales** : Effacez toutes les données AppBox sur l'appareil, y compris les collections, les informations d'app, les notes, les descriptions, etc. Assurez-vous que vos données sont sauvegardées ou synchronisées sur iCloud avant de continuer.
