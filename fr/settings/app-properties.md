# Propriétés de l'app

Les paramètres des propriétés de l'app contrôlent quels champs d'attributs sont affichés lors de l'édition des descriptions d'application.

**Accès** : Réglages → Apps → Propriétés de l'app

## Propriétés configurables

### Propriétés d'abonnement

Lorsqu'activé, les champs liés aux abonnements sont affichés lors de l'édition des descriptions d'app :

- Description de l'abonnement
- Prix de l'abonnement
- Devise
- Type d'abonnement (mensuel, annuel, etc.)
- Date de début/fin de l'abonnement

### Propriétés de prix

Lorsqu'activé, les champs liés aux prix sont affichés lors de l'édition des descriptions d'app, avec la possibilité de récupérer automatiquement les prix depuis l'App Store.

::: info
La configuration des propriétés de l'app est une fonctionnalité Pro et nécessite un abonnement AppBox Pro pour être modifiée. Les utilisateurs non-Pro ont ces propriétés activées par défaut.
:::
