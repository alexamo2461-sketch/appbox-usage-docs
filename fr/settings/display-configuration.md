# Configuration de l'affichage

La page de configuration de l'affichage vous permet de personnaliser les options d'affichage des pages de collection et des pages de détails d'application.

**Accès** : Réglages → Général → Configuration de l'affichage

## Configuration de la page de collection

### Mode de visualisation des apps

Définissez le comportement par défaut lors de l'appui sur une app :

| Mode | Description |
| --- | --- |
| **Ouvrir l'App Store** | Appuyer sur une icône d'app ouvre directement la page App Store de l'app |
| **Aperçu dans AppBox** | Appuyer sur une icône d'app affiche un aperçu des détails dans AppBox |

### Vue des apps

Définissez la vue par défaut des pages de détails de collection (Liste, Icônes ou Cartes).

## Configuration de la page de détails

### Ordre des détails

Personnalisez l'ordre d'affichage des sections sur la page de détails de l'app :

- Captures d'écran
- Informations de l'app
- Plus d'informations
- Description de l'app
- Historique des mises à jour

Faites simplement glisser pour réorganiser.

### Description de l'app

- **Masquer si vide** : Lorsqu'une app n'a pas de description, masquer la section description (fonctionnalité Pro)

### Étiquettes de l'app

- **Afficher les étiquettes** : Contrôler si les étiquettes sont affichées sur la page de détails
- **Afficher les icônes** : Contrôler si les icônes d'étiquettes sont affichées avant les noms d'étiquettes
- **Affichage sur une ligne** : Contrôler si les étiquettes sont disposées sur une seule ligne
