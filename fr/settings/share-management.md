# Gestion des partages

La page de gestion des partages sert à gérer vos liens de collection partagés.

**Accès** : Réglages → Collections → Gestion des partages

## Aperçu

Après avoir généré des liens de partage via la fonctionnalité « Partager une collection », vous pouvez gérer ici tous les liens de partage actifs en un seul endroit.

## Opérations de gestion

### Voir les liens de partage

La liste affiche tous les liens de partage actuellement actifs, y compris le nom de la collection et l'état du partage.

### Désactiver un partage individuel

Appuyez sur un lien de partage pour le désactiver. Une fois désactivé, les autres ne pourront plus importer la collection via ce lien.

### Désactiver tous les partages

Désactivez tous les liens de partage actifs en un seul appui.

### Désactivation automatique lors de la suppression

Lorsque cette option est activée, la suppression d'une collection désactive automatiquement ses liens de partage associés, évitant ainsi les liens invalides.

## Options de partage

Configurez le contenu à inclure lors du partage :

- **Inclure les descriptions d'app** : Inclure la description personnalisée de chaque app lors du partage
- **Inclure la description de collection** : Inclure le texte de description de la collection lors du partage
- **Inclure les informations d'abonnement** : Inclure les attributs liés aux abonnements lors du partage
- **Inclure les étiquettes d'app** : Inclure les informations d'étiquettes des apps lors du partage

::: info
La gestion des partages est une fonctionnalité Pro et nécessite un abonnement AppBox Pro.
:::
