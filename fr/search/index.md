# Recherche

AppBox offre une fonction de recherche globale pour retrouver rapidement vos applications et collections enregistrées.

## Aperçu

Appuyez sur l'onglet **Recherche** dans la barre de navigation inférieure pour ouvrir la page de recherche. Vous pouvez rechercher parmi toutes vos applications et collections enregistrées. La recherche prend en charge la correspondance par nom, description et autres mots-clés.

## Étapes

1. Appuyez sur l'onglet **Recherche** dans la barre de navigation inférieure
2. Saisissez des mots-clés dans le champ de recherche
3. Les résultats s'affichent en temps réel (applications et collections)
4. Appuyez sur un résultat pour ouvrir les détails de l'application ou de la collection

## Portée de la recherche

- **Nom de l'application** : Correspond au nom de l'application
- **Description de l'application** : Correspond aux descriptions personnalisées ajoutées
- **Nom de la collection** : Correspond aux noms des collections

## Actions sur les résultats

Dans les résultats de recherche, vous pouvez effectuer les actions suivantes :

- **Application** : Appuyez pour ouvrir la page de détails
- **Collection** : Appuyez pour ouvrir la page de détails de la collection
- **Appui long sur une application** : Menu contextuel avec options d'édition, copie/déplacement, suppression
- **Appui long sur une collection** : Menu contextuel avec options d'édition et de suppression

## Astuces

- La recherche filtre en temps réel — les résultats apparaissent pendant la saisie
- Utilisez des mots-clés courts pour des résultats plus larges
- Si vous ne trouvez pas une application, essayez de chercher des mots-clés dans sa description
