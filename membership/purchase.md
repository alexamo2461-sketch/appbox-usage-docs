# 购买相关说明

> 相关链接：[会员功能说明](/membership/feature-overview)

## 购买须知

- 随着功能的不断改善，价格可能会有所调整。开发者同时承诺：不会把买断用户转为订阅，买断之后不再需要二次付费；
- 在会员期内，所有功能都可以使用；购买后，不支持退款操作，请谨慎思考后再购买。
- 不支持 Apple ID 账户之间的购买/订阅迁移；也不支持多个 App ID 共享会员。

## 恢复购买

如果使用过程或重新安装时已经购买了会员但是不能使用会员功能，可以前往设置 - AppBox Pro 页面，手动点击恢复购买的按钮，即可恢复之前的会员身份（需要和购买时使用的 Apple ID 保持一致）。如果 AppBox Pro 页面没有"恢复购买"的按钮，则说明当前会员功能是生效的。
