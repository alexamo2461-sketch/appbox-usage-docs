# 会员功能说明

> 相关内容：[购买相关说明](/membership/purchase)

这款产品会持续被认真对待，而你的支持，是我继续投入时间和精力的理由。

AppBox 部分高级功能需要订阅 AppBox Pro（以下简称为"会员"）才能使用。当前会员为一次性买断制，一次买断后可以永久使用，包括后续增加的更多高级功能。会员功能包括：

::: info
- **数据同步**：将数据上传到 iCloud（需要用户有可用的 iCloud 账号）并实现数据的云同步功能。
- **分享应用集**：将应用集分享为图片和二维码链接功能，以及通过分享的链接/图片导入到自己的软件中。
- **记录应用属性**：支持记录订阅相关属性（包括订阅说明、价格、币种、订阅类型和日期）。
- **添加自定义应用**：支持通过上传图标、填写应用说明、来源等信息来自定义应用信息，以及自定义应用的导入和导出功能。
- **批量导入**：支持多个链接长文本批量识别和导入应用到应用集中。
- **自定义属性字段** <Badge type="warning" text="开发中" />：编辑应用说明时支持自定义属性字段配置，包括文本、时间、数字、单选、多选等类型。
- **应用自定义标签功能**
- **应用卡片视图**：应用集详情页面增加卡片视图：通过卡片展示应用评分、说明、是否已购等更多字段信息。
:::

上面开发中的功能代表当前暂时没有，但是后续版本一定会有的功能。
