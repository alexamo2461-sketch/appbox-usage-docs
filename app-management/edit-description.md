# 编辑应用说明

可以为应用集中的应用自定义评分和添加备注说明文字，评分和说明文字将显示在应用信息中应用图标和标题的下方。

**操作方式**：该页面可以有多个入口触发：

1. 在应用详情页面点击左上角编辑按钮
2. 底部操作栏新增模块的新增应用后的应用预览区域
3. 应用集详情页面新增按钮识别应用后的应用预览区域

![编辑应用说明](/app-management/edit-description.png)

> **注意**：不同应用集之间的（相同名字的）说明内容是相互独立的。例如在应用集 A 中有个"抖音"，在应用集 B 中也有个"抖音"，这两者的评分、应用说明以及订阅等属性都是互相独立且不会同步的。这是功能特性，而不是软件 Bug。如果要实现两者的应用说明相同，可以使用复制功能手动将应用复制到另一个应用集中。当然，此后编辑任意一个应用集中的该应用说明，另一个也不会同步。
