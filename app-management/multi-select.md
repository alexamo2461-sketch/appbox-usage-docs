# 应用多选操作

应用集详情页面支持多选模式，可以同时对多个应用执行批量操作。

## 进入多选模式

在应用集详情页面，点击右上角操作菜单（三点图标）→ **选择应用** 按钮，进入选择模式。

## 可选操作

进入选择模式后，底部工具栏会显示以下操作：

| 操作 | 说明 |
| --- | --- |
| **复制** | 将选中的应用复制到其他应用集（可选多个目标应用集） |
| **移动** | 将选中的应用移动到其他应用集（只能选择一个目标应用集） |
| **删除** | 删除选中的应用 |
| **地区** | 批量修改选中应用的 App Store 地区 |

## 批量修改地区

1. 进入选择模式，勾选多条应用
2. 点击底部工具栏的 **地区** 按钮（地球图标）
3. 在弹出的地区列表中选择目标地区
4. 系统会逐条尝试获取新区的应用信息，完成后显示批量修改结果

## 退出选择模式

完成操作后，点击 **完成** 或再次点击选择按钮退出选择模式。

::: info
结合 [应用集内筛选](/app-management/filtering) 功能，可以先筛选出符合条件的应用，再进入多选模式批量操作，效率更高。
:::
