# 应用集内筛选

AppBox 的应用集详情页面提供强大的筛选功能，帮助你快速定位需要的应用。

## 功能简介

在应用集详情页面，点击右上角的 **筛选** 图标，可以打开筛选面板，按多种条件过滤当前应用集中的应用。

## 筛选条件

| 条件 | 说明 |
| --- | --- |
| **关键词** | 在应用名称、说明、订阅说明中搜索关键词（最多 50 字） |
| **评分** | 按你给出的评分筛选，包括"无评分"和 1～5 星 |
| **标签** | 按应用标签筛选，支持多选 |
| **分类** | 按 App Store 主分类筛选 |
| **来源** | 按应用来源筛选：App Store 应用或自定义应用 |
| **平台** | 按支持平台筛选：iPhone、iPad、Mac |
| **地区** | 按 App Store 地区筛选（仅显示当前应用集中实际出现的地区） |

## 操作步骤

1. 打开某个应用集
2. 点击右上角的 **筛选** 图标
3. 在筛选面板中设置你需要的条件
4. 多个条件之间为"且"的关系（同时满足）
5. 设置完成后，应用列表会自动过滤

## 清除筛选

点击筛选面板中的 **清除** 按钮，可以重置所有筛选条件，显示全部应用。

## 使用技巧

- 地区筛选只显示当前应用集中实际存在的地区，不会出现空选项
- 可以组合多个条件进行精确筛选，例如"标签为效率 + 平台为 iPhone"
- 关键词搜索会同时匹配应用名称和说明内容
